# 事件工坊

项目已启用此 Godot EditorPlugin。入口位于顶部「事件工坊」，使用说明见 [事件工坊使用说明](../../docs/事件工坊使用说明.md)。

配方保存在 `res://data/events/*.tres`；地图工坊可选择绑定工坊事件。运行时使用独立 EventSession 固定候选和保护一次结算。编辑器预览与试玩只模拟奖励。

UI 使用左侧聚焦插画、右侧剧情与双行选项条，插画外围淡入明亮的浅色底。正式事件已配置各自的手绘 PNG，详见 [事件插画说明](../../assets/ui/events/illustrations/README.md)。编辑器预览和游戏共用同一套显示逻辑。
