# 关卡 UI 预览

打开战斗场景、战斗模板或继承关卡，在 **2D 工具栏**点击 **隐藏关卡 UI**，或按 **Ctrl+Alt+U** 切换。

默认隐藏 `CardUI` 和 `GameOver`，需要调整界面时取消勾选。开关会记住本机偏好，切换关卡继续生效；单独打开 UI 场景时保持正常显示。

插件只修改编辑器实例的 RenderingServer 绘制状态，不改写 `visible` 属性。隐藏期间可以直接保存、F5 或 F6，游戏 UI 按原有逻辑显示，无需重新打开节点的小眼睛。禁用插件后恢复原来的绘制状态。

项目已启用插件。如果当前编辑器还没有出现按钮，可在 **项目 → 项目设置 → 插件**启用 **关卡 UI 预览**，或重新打开项目。
