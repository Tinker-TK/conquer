# Godot 地图工坊

项目已启用插件。重新载入项目后，在顶部与“波次编辑器”并列的“地图工坊”页签打开。
若没有出现，进入项目设置 → 插件，启用“地图工坊”。

## 编辑与保存

宝箱可从左侧“＋ 宝箱”添加，也可修改现有节点类型。无需事件或关卡配置；打开时自动随机给予一件未拥有的有效遗物，结果展示后继续推进。第五层示例已提供宝箱。

- 顶部地图菜单列出 `data/levels/` 的 JSON，也可“打开…”任意位置的旧 HTML 工坊配置。
- 初次打开会载入项目已有路线；没有路线时提供十层示例。新建空地图或载入示例前会保护未保存修改。
- 左侧选择节点类型，再点击画布空白处添加；第 1 层默认设为出发点。选择模式可拖动节点，自动吸附层级。
- 新编号为 `floor_03_01`，移动和修改类型不自动改名。手动改名会同步出发点和路线引用。
- 连线模式先点源节点，再点更高层目标。可分叉、汇合、跨层。选择模式点击路线后 Delete 可删除；右侧也可删除出边。
- 右侧编辑节点名称、层级、出发点。战斗/Boss 从项目 `level_*.tres` 列表选择关卡，“在检查器打开关卡”可编辑资源本身。
- 事件和篝火直接编辑描述、2–8 个选项的文字、固定回血、最大生命回复百分比、金币奖励，以及训练 / 强化效果，规则与 HTML 工坊一致。新篝火预填休憩整备、训练、强化、离开四个选项。
- 事件和篝火节点的“事件工坊已配置事件”下拉框可选择 `data/events/` 中已保存的事件，绑定完整标题、描述、选项、插图及奖励池。切回地图工坊或点击“刷新事件列表”会同步最新配置；变化可撤销，保存地图后供新局使用。“在检查器打开绑定事件”可查看资源，选择“节点内编辑”可保留快照后独立调整。
- Ctrl+Z / Ctrl+Shift+Z 撤销/重做，Delete 删除，Esc 返回选择模式。文本框保留自己的文字快捷键。
- “保存”写回当前 JSON，“另存为…”保存新文件，建议放在 `data/levels/`。未完成路线也可保存为草稿，右侧显示第一项游戏校验问题。

编辑好路线后，在顶部选择“应用到第1幕 / 第2幕 / 第3幕”，再点击“应用到游戏”。三幕分别保存，应用其中一幕不会覆盖另外两幕。工坊会先检查路线、关卡、事件和奖励配置，成功后写入项目正式路线：第一幕 `data/run/game_map.json`（兼容之前的路径）、第二幕 `data/run/game_map_act_2.json`、第三幕 `data/run/game_map_act_3.json`。

正常运行游戏并点击“开始征途”即可从第一幕开始，不需要再经过主菜单的路线工坊。击败本幕终点 Boss 并结束奖励领取后，自动进入下一幕；完成第三幕后显示“征途通关”面板。跨幕保留生命、金币、牌组、训练和永久强化、遗物、药水，只清除当前幕的地点进度与商店访问缓存。顶部标题同步当前幕编号。

开始新征途时读取并冻结三幕路线，继续存档恢复存档中的幕编号、三幕快照及进度。已配置的后续幕不会受工坊后续修改影响。若下一幕尚未配置，则停留在当前幕完成面板并显示具体原因，可保存返回主菜单，或在工坊补齐缺失幕后点击“进入下一幕”重试。缺失的幕不会提前算作整局通关。

三幕正式路线随项目打包导出，优先于用户目录中旧的导入路线。未应用正式路线的项目仍兼容主菜单 JSON 导入及内置十层地图。旧单幕存档按原路线继续，不把新配置的三幕插入旧局。

“应用到游戏”包含当前未保存的输入和拖动结果，但不会把草稿标为已保存；原始地图仍可另外“保存”或“另存为…”。后续修改完成后需再次点击“应用到游戏”。校验或写入失败时保留上次正式路线。HTML 工坊可以继续导入和编辑原始文件，游戏格式仍为 v1 fixed。

## 试玩与实战

“路线试玩”点击金色节点向上前进，验证分叉和终点。它不会结算事件奖励或修改配置；“重新出发”回到起点。

“启动此路线实战”先用游戏校验器检查路线，成功后把当前草稿写入独立的 `user://map_editor_playtest.json`，再启动真实 GameSession。使用新的初始牌组和进度，不需要先保存 JSON，也不改变玩家主菜单持久保存的地图选择。已有游戏运行时先按 F8 停止。

## 文件保护

替换当前地图前可保存、放弃或取消；磁盘文件被其他工具修改时拒绝覆盖，可另存为或重新打开。编辑操作自动保留 `user://map_editor_recovery.json`，关闭或禁用插件后未保存草稿下次会自动恢复。保存成功时清除恢复副本；撤销历史不跨编辑器重启。

恢复副本和实战快照位于 Godot 项目用户目录，不会写进发行资源。“应用到游戏”写入项目正式路线，现有导出配置包含 `data/**/*.json`，会将其随游戏打包。插件仅在编辑器启用；实战入口仅在手动点击时运行。

回归命令：`Godot --headless --path . --script res://tests/map_editor_test.gd`。建议用独立 APPDATA/LOCALAPPDATA 测试目录，避免与编辑器同时修改恢复副本。检查覆盖节点编辑、引用、撤销、拖动、JSON 回读、保存冲突、草稿恢复及实战快照。
