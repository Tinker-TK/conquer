# 弓箭手穿刺射击

| 强化等级 | 伤害倍率 | 单箭最多命中人数 |
| --- | --- | --- |
| 未强化 | 1.0 | 沿路线先遇到的2名敌人 |
| 强化一次 | 1.2 | 射击路线上的所有敌人 |

基础与强化弓箭手均装配穿刺射击。强化版替换基础版，保留原普通射击；穿刺射击仍使用4秒冷却、600施法距离、attack_02第9帧和原有强力箭矢。

强化箭沿发射时锁定的方向继续飞行，命中目标后不会因穿透次数耗尽而停止，同一敌人每颗箭只结算一次；路线外敌人和友军不受伤害。箭矢仍受原有飞行寿命限制，离开交锋时清除。伤害沿用攻击力倍率、防御及逐目标楼层加成。

穿透判定检查每一物理步的整段路径，避免高速箭跳过敌人；同一步遇到多人时按路径前后顺序处理。死亡、待删除、错误阵营及非单位节点不会消耗两人上限。

基础资源为 `data/skills/archer_power_shoot.tres`，只在强化等级 `[0]` 生效；强化资源为 `data/skills/archer_power_shoot_upgraded.tres`，只在 `[1]` 生效。远程技能新增 `pierce_all` 开关，仅用于直线弹；开启后忽略 `pierce_count` 人数限制。

运行 `tools/maintenance/run_checks.py --checks archer-piercing skeleton-archer card-description floors status-effects sword-arrow monster-test skill-unlock`。专项使用真实训练及独立 monster_test 自动动画发箭，验证基础只伤前2人、强化穿透5人、伤害倍率、路线外排除、每人仅一次和高速整段命中。
