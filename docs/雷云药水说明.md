# 雷云药水

在自动战斗阶段，点击顶部的雷云药水，再点击战场选择落点。首次有效施放消耗一瓶，不消耗能量；施放前可右键或 Esc 取消，战场外点击不消耗。

雷云停留在该世界位置，每0.4秒轮流锁定圆形范围内一个敌军，发出一道雷电，命中时对该目标造成6点伤害，不造成范围群伤。没有目标时只显示翻滚的乌云，不出雷、不闪光；敌人进入范围后恢复攻击，空范围期间的攻击不补发。

每次攻击随机选择底部四块云团之一作为出雷点，对应云块同步闪光。雷云本身不跟随目标，单次雷线的起点保持在选中的云内出雷点，终点实时跟随锁定单位的身体位置。单位场景可添加 `ThunderHitPoint` 标记指定命中点；没有标记时使用 `AnimatedSprite2D` 的世界位置。目标在命中前死亡、退场或移出范围时取消该击。

乌云复用 `scenes/effects/pixel_thunder_cloud.tscn`，云团宽高在药水实例上放大两倍（224×116），悬浮高度保持156。独立雷电实例复用 `pixel_lightning.tscn`，每道雷单独连接云团与单位，原雷云和落雷资源保持不变。

## 三回合期限

- 施放当回合算第 1 回合。例如第 5 回合施放，第 5、6、7 回合生效，第 7 回合交锋结束时消失。
- 准备与回合结算阶段保留雷云及固定落点，暂停视觉时钟和伤害；下一轮交锋继续，不补发等待期间的雷击。
- 战场清兵、生成下一轮敌军不会清除雷云。暂停地图、卡组、牌堆查看时也暂停放电。
- 整场胜负或退出战场立即清理，不带到下一关。
- 沿用已有药水规则：雷云效果结束后才能使用下一瓶，施放后不能移动或取消返还。

## 配置与获得

资源：`data/potions/thunder_cloud.tres`。在 Inspector 或「游戏配置 → 药水效果」调整。

| 属性 | 默认值 | 含义 |
| --- | --- | --- |
| Kind | THUNDER_CLOUD | 新增类型，保留原三种药水的枚举编号 |
| Targets | ENEMIES | 只伤害敌军 |
| Damage | 6 | 每次雷击只对一个锁定单位造成的直接效果伤害 |
| Radius | 85 | 固定落点的世界像素半径 |
| Interval | 0.4 | 相邻两次索敌和放电的间隔秒数 |
| Rounds | 3 | 包括施放当回合的持续回合数 |
| Effect Scene | pixel_thunder_cloud.tscn | 复用现有像素雷云 |
| Effect Scale / Offset | (1,1) / (0,0) | 视觉缩放、偏移，不改变伤害中心或半径 |

有目标时默认在施放后0.4秒释放第一道雷，约0.055秒后雷线到达目标并造成伤害，此后每0.4秒选择一个目标放电。多个敌人按稳定顺序轮流受击；只有一个敌人时持续攻击该敌人。Description 留空，HUD 自动使用实际数值生成说明。

正式旅途商队的药水池已加入雷云药水，价格80金币。随机药水奖励按目录扫描，也可抽到雷云；正式开局库存仍由 `data/run/run_start_data.tres` 的 Starting Potions 配置。脚本获得入口：

```gdscript
RunManager.add_potion(preload("res://data/potions/thunder_cloud.tres"))
```

## 直接试玩

打开 `examples/scenes/thunder_cloud_potion_demo.tscn` 按 F6。场景提供雷云与闪电各一瓶，自动进入首轮交锋。点击顶部雷云图标，在右侧靠近的两名兽人之间选择落点，可以看到两名范围内敌人轮流受到雷击，右侧较远兽人不受伤。在空白区域施放则只出现乌云。

演示目标保持原地，方便观察；左侧「结束本轮交锋，查看下一回合」通过真实单位死亡与回合结算推进，下一轮重新生成目标。连续推进三轮可查看剩余回合、固定位置和到期消失。这个场景只重置测试局，不改正式开局配置。
