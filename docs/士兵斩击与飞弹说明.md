# 士兵强化分支

基础士兵拥有弓箭和近战普通攻击。篝火训练、进化均要求玩家明确选择斩击或飞弹，选择按具体卡牌保存；同名其它牌不受影响。原有攻防能力点分配保留。临时进化使用后恢复原分支。

| 分支 | 普通攻击 | 强化技能 |
| --- | --- | --- |
| 斩击 | 仅近战，范围80 | 350范围内飞跃斩击，倍率1.3，冷却2秒。每名士兵对每个敌人仅使用一次；已斩目标继续用普攻，换到新目标后再次斩击，优先飞弹标记目标。 |
| 飞弹 | 弓箭范围300、近战范围80，共用普攻冷却 | 飞弹范围300，倍率0.8，冷却2秒；命中存活敌人后标记。 |

斩击曾使用过的目标死亡时，即使由其他友军击杀，该士兵也获得攻击力+1。

每次飞弹命中时统计正在攻击该目标的存活己方士兵数量N，并让这N名士兵各获得攻击力+N。例如3名士兵正在攻击该目标，3名士兵各+3；不奖励攻击其他敌人的士兵或其它兵种。每次飞弹命中单独结算，标记视觉不重复生成。

以上攻击成长持续本场战斗，不写回卡牌、不继承到复制单位；单位退场或战斗结束后清理。标记持续本场战斗，目标死亡时清理。

特效直接复用 Eslabong 实验室：

- 斩击采用 `wild_boar_bite`（Wild Boar Gore）原突进与白色残影流程。实战突进由原0.12秒调为0.28秒，在0.3秒命中帧前落地；残影显示在地形上方，截取生成时的真实士兵帧并连续渐隐。落点检查地形和碰撞。
- 飞弹采用 `archer_wounding_arrow` 原箭矢与命中；目标上的持续标记使用实验室“减速”（`SlowVFX`）原特效，持续到本场结束，仅作视觉标记。

打开 `scenes/testing/monster_test.tscn`，左侧士兵下有“飞弹1次”和“斩击1次”按钮。普通“+士兵”直接生成未强化的远近双能士兵；强化按钮仍按训练规则把能力点全部加到攻击。

回归：`python tools/maintenance/run_checks.py --checks soldier-branches sword-arrow campfire strategy-cards monster-test skill-unlock`。追加图形参数 `--soldier-branches-regression --capture` 可保存 `.maintenance/soldier-branches/` 中的训练与战斗截图。
