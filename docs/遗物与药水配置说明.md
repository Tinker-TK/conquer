# 遗物与药水

遗物已扩充为60件流派遗物加6件旧遗物，正式掉落、商店、三选一、图鉴与测试入口见[遗物流派实装说明](遗物流派实装说明.md)。下方遗物表格保留旧效果的配置示例。

药水已扩充到40瓶，完整能力与F6实验场见[药水效果实现说明](药水效果实现说明.md)。下方4瓶表格描述保留的原有药水；新增药水读取`effects`列表。

## 直接试玩

打开 `res://examples/scenes/items_demo.tscn`，按 F6。
这个独立演示场景会开启一局测试，提供三件有效遗物和三瓶药水（旧城防遗物停用），不修改正式初始配置。
它使用 `res://examples/data/run_items_example.tres`。

正式游戏仍使用 `res://data/run/run_start_data.tres`，默认没有初始遗物或药水。
在该资源的 Inspector 中往 Starting Relics、Starting Potions 数组拖入对应资源，即可指定开局物品。
同种药水可以放入多次，代表多瓶；相同 ID 的遗物只获得一次。

## 遗物资源

目录：`res://data/relics/`。

| 文件 | 效果 |
| --- | --- |
| draw_engine.tres | 实际抽到10张牌获得1点本回合额外能量，可超过能量上限 |
| base_heart.tres | 玩家生命上限+20，获得时当前生命也+20 |
| base_armour.tres | 已停用，主堡移除后无法获得此遗物 |
| opening_armour.tres | 每场首次开始自动战斗时，已上场己方士兵防御+2，持续3轮 |

十抽引擎按实际抽入手牌数量计算，跨回合、跨战斗保留余数。
禁抽、空牌堆、直接随机打出抽牌堆的牌、收回单位均不增加抽牌计数。
开局护甲只作用于正式己方士兵，不每轮重复施加；第二轮及以后新召唤的士兵不补发。
遗物属于当前整局，开始新游戏清空；现有征途存档保存持有遗物与跨战斗抽牌余数。每场、每轮计数留在战斗运行器中。图鉴发现记录另存于本机用户数据目录，不随新局清空。

获得遗物的统一入口为 `RunManager.add_relic(遗物资源)`，返回是否首次成功获得。
宝箱、事件或奖励脚本以后调用此入口即可，无须自己修改血量和护甲。

## 药水资源

目录：`res://data/potions/`。

| 文件 | 默认效果 |
| --- | --- |
| tornado.tres | 速度90，持续6秒，半径70，落地及每0.5秒造成8点伤害 |
| lightning.tres | 依次点击4次，间隔0.4秒，半径65，每次20点伤害 |
| fire.tres | 半径85，落地及每0.5秒造成6点伤害，直到当前自动战斗回合结束 |
| thunder_cloud.tres | 雷云固定，半径85，每0.4秒轮流锁定一个敌人造成6点伤害，空范围不出雷；持续3回合（含施放当回合） |

只在自动战斗阶段使用：左键点击药水，再左键点击战场落点。
第一次有效落点消耗一瓶；无效落点不扣库存或次数，也不消耗能量。
首次施放前右键或 Esc 可取消。闪电首次落地后需要继续释放剩余次数，不能取消返还。
同一时间只有一个持续/多段药水占用场地槽：闪电全部释放并结束间隔、龙卷风消失、火焰回合结束或雷云到期后，才能使用下一瓶场地药水。其间可以连续使用即时药水。
普通药水在回合结束清理，未释放的闪电次数作废；尚未首次施放的瓶子保留。雷云保留固定落点跨回合生效，准备与结算期间暂停，最后一个有效回合结束时消失；整场结束立即清理。
暂停地图、卡组或牌堆查看时，药水效果同步暂停。

默认只伤害敌军。Targets 可以改为 Allies 或 Both；此处“单位”只包含正式战斗单位。
药水伤害是直接法术伤害，走单位的 take_effect_damage，不触发普通攻击和反击。
龙卷风沿“战场左侧中央指向落点”的方向移动，战场矩形边缘反弹，可以越过地形。
落点限制使用战场脚本的 Battlefield Rect，不修改导航和部署规则。
参数 Duration、Speed 仅龙卷风使用；Casts、Cast Delay 主要用于闪电；火焰始终以回合结束为终点。
Rounds 仅雷云使用，施放当回合计入期限。雷云首次伤害等到雷击触地，之后按 Interval 循环；完整玩法、配置和专用试玩见 [雷云药水说明](雷云药水说明.md)。

获得药水的统一入口为 `RunManager.add_potion(药水资源)`。
入口返回是否成功；仙女之泪和生命果实按本局限量过滤，其它药水仍可拥有多瓶。
每次获得产生一瓶独立库存，使用完不会在下一场战斗恢复。

## 药水使用特效配置

选中 `data/potions/` 下的药水 `.tres`，在 Inspector 的「使用特效」分组把特效 `.tscn` 拖入 Effect Scene 即可，不需要填写动画名称。

| 属性 | 用途 |
| --- | --- |
| Effect Scene | 普通药水使用 AnimatedSprite2D 根节点场景；雷云使用 PixelThunderCloud 根节点场景，默认复用 pixel_thunder_cloud.tscn |
| Effect Scale | 在场景原始缩放上乘以此倍率，默认 `(1, 1)` |
| Effect Offset | 相对伤害中心的世界像素偏移，默认 `(0, 0)`；场景自身的 Sprite Offset 也会保留 |

闪电每次有效点击生成一个单次动画，播完删除；释放间隔结束或开始使用下一瓶不会截断已有动画。火焰生成固定位置的循环动画，持续到本轮交锋结束；龙卷风生成循环动画并跟随伤害中心移动，持续时间结束时删除。运行器按药水类型设置实例的循环模式，不改动共享场景或 SpriteFrames。查看地图、卡组或牌堆时，动画随战斗暂停；离开交锋或销毁战场时清理全部药水视觉。

特效只控制画面，缩放、偏移和动画时长均不改变伤害、范围、施放次数或扣瓶时机。未配置场景时保留原有占位显示；场景根节点不符合要求或所有动画均没有帧时，提示配置警告并回退到占位显示，药水仍正常生效。成功配置后仍保留施放前的瞄准圈，施放后的占位图形由配置动画替换。

雷云使用独立实例的 `seek()`，云团宽高放大两倍；自身的固定落点循环雷关闭，由药水每0.4秒选择一个目标并创建独立落雷实例。雷线准确连接云内出雷点和目标身体，命中只结算该单位伤害，空范围不出雷、不闪光。保留地面范围圈和剩余回合标记，准备、结算及暂停时不推进；Effect Scene 留空或根节点不符合雷云类型时回退到默认像素雷云，不改动共享特效资源。

如果一个场景有多个动画，先在该场景的 AnimatedSprite2D 上选中你想播放的动画并保存，药水会自动读取；建议每个独立特效场景只保留一个主要动画。当前动画没有帧时，运行器自动选择动画列表中第一个有帧的动画。例如 `fx_yellow_flash.tscn` 拖入后直接播放其 `vertical_flash` 动画。

## 界面与美术

`res://scenes/ui/run_items_hud.tscn`：

- Relics：顶部左侧下方的遗物区；物品过多时可横向滚动。
- Potions：金币右侧的药水区；物品过多时可横向滚动。
- Hint：瞄准、连发剩余次数和效果进行中的提示。

现在使用两字按钮和简单绘制的法术作为占位。鼠标移到物品上方会立即显示深色说明框：金色名称、效果介绍、亮色关键数字，以及相关规则的第二个说明框。
说明文字读取资源的 Description；留空时按物品实际参数生成效果介绍。十抽引擎还显示当前抽牌进度，计数变化后，即使鼠标不动也会更新。
地图和暂停查看时药水不能使用，但仍可悬停阅读。新增非伤害药水按`Prep Usable`允许准备阶段使用，护盾仍限交锋。说明框不拦截鼠标，移出物品后关闭，位置自动限制在屏幕范围内。
在遗物或药水资源的 Icon 属性指定图片后，按钮会自动用图片替换文字。
修改数值后也请同步修改 Description，以免悬停说明与参数不一致。
正式整局中由 RunHUD 挂载；F6 单独运行战场时自动补充物品入口，不会重复生成。

## 检查入口

使用 `card_framework_test_runner.gd`，参数 `--items-regression` 验证效果与跨战斗状态，
参数 `--items-ui-regression` 验证真实鼠标点击、库存、单一 HUD 和暂停。
参数 `--potion-visuals-regression` 验证特效配置保存重读、单次与循环播放、暂停、移动和阶段清理。
为界面检查追加 `--capture-items`，可在有显示的运行中保存地图与战斗悬停截图到 `.maintenance/checks/item-tooltips/`。

新增 MAX_ENERGY 遗物类型：Amount 增加整局附加能量上限，不受基础10点封顶影响。即时抽牌遗物仍只增加本轮可用能量。
