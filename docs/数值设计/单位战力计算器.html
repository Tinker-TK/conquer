统一比较环境

公式与口径

每击伤害 = max(floor(攻击 × 技能倍率) − 对手防御, 1) 有效生命 = 生命 × 来袭单击伤害 / max(来袭单击伤害 − 防御, 1) / (1 − 有效闪避率 × 可闪避来袭占比) 等效输出 = DPS + 有效 HPS × 治疗折算权重 本体战力 = 100 × sqrt(有效生命/基准有效生命 × 等效输出/基准等效输出) 总战力 = 本体战力 + 召唤贡献 征召战费比 = 总战力 / (该阶段征召费用 + 退场加费) 总能量效率 = 总战力 / (征召费用 + 退场加费 + 额外强化耗能) 费用预算 = 100 × 征召费用 × (1 + 费用溢价 × (征召费用 − 1))

成长计算

自定义属性(n) = floor(当前属性 × (1 + 每阶增长率)^n + n × 每阶固定增长 + 一次额外强化) 训练：每阶攻击/防御增长取所分配能力点，生命不自动增加。 阶段 0 只使用当前属性；阶段 ≥1 才加入一次额外强化。 闪避限制为 0～100%；生命至少 1，攻击/防御/征召费用至少 0。

参考来袭伤害下的防御估价会在减伤达到每击 1 点时封顶。毒、眩晕、移速、仇恨、死亡爆炸、地形和幸存结算扣血尚未折成战力。治疗、范围与召唤系数都是可校准假设。

士兵剑矢：分别计算近战与远程窗口，远程只施放射程足够的技能，再按远程占比加权；远近普攻共用冷却。所有单位开场技能就绪。
