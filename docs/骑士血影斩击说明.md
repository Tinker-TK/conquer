# 骑士血影斩击与鲜血回归

| 效果 | 未强化 | 强化一次 |
| --- | --- | --- |
| 上场抽牌 | 成功打出征召牌后立即抽1张。 | 基础1张＋额外2张，共抽3张。 |
| 血影斩击 | 原斩击改名并开放给基础骑士，保持150%攻击力伤害，冷却10秒；每次命中叠1层流血。 | 保持叠层与伤害，冷却改为8秒。 |
| 防守反击 | 保持20%闪避及原反击动作、两次120%伤害。 | 反击命中附加2秒眩晕，后续命中刷新。 |

每层血影流血每秒固定造成1点伤害，无视防御。每名骑士对每个目标独立记录自己的层数；叠层保留原秒跳进度。未指定自然到期，流血持续本场战斗，目标死亡或清理状态时解除；骑士死亡后既有流血仍有效，停止回血。

骑士每累计6秒有效战斗时间触发鲜血回归，将上次回归后自身血影流血实际扣除的生命值回复自己。准备阶段和游戏暂停时冻结计时；普通攻击、其他流血、护盾吸收量、超出目标剩余生命的伤害不计入。多个目标的伤害合计返还，多名骑士独立计算。回复受最大生命和禁疗限制，不转护盾；每轮记录返还或被禁疗拦截后清空，不重复结算。

鲜血回归直接使用实验室 `shadow_priest_vampiric_psalm`（Vampiric · Psalm）完整五次反向光束配方和原 `VAMPIRIC_PSALM` 视觉。6秒回归不附加实验室预览的0.42秒施法等待；光束从贡献流血伤害的目标返回骑士，跟随双方，目标已死亡则使用最后记录的位置。回血由战斗系统一次结算，视觉不重复造成伤害或治疗。

训练、存档和牌面按具体卡牌等级读取。复制单位具有相同技能配置，但不继承原骑士的流血归属、已累计回血量与计时。上场抽牌仍只由成功打出征召牌触发，直接添加单位、复制与收回不抽牌；禁抽、牌不足和弃牌堆洗回沿用原规则。

回归：`python tools/maintenance/run_checks.py --checks knight-blood knight-draw counter status-effects card-description`。图形运行追加 `--knight-blood-regression --capture`，输出 `.maintenance/knight-blood/vampiric-psalm.png`。
