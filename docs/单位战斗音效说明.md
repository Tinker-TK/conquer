# 单位基础战斗音效

已接入所有现有兵种的基础战斗音效：挥击、弓弦、火球、冰晶、法术、野兽和史莱姆攻击，实际受击、防守闪避、死亡，以及治疗与召唤施法。
正式战场与独立怪物测试场使用同一套播放逻辑。

## 试玩和调节

Godot 打开 `scenes/testing/monster_test.tscn`，按 F6，布置双方单位后点击开始战斗。
可先试听步兵对兽人、弓箭手对骷髅、法师对史莱姆；主菜单「设置」中的主音量控制全部声音并保留原有保存方式。

打开 `data/audio/combat_sounds.tres`，在 Inspector 调整：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| Enabled | 开启 | 关闭全部单位战斗音效 |
| Volume Db | -6 dB | 战斗音效整体增益，叠加主音量 |
| Max Voices | 24 | 启动时创建的固定播放器数量 |
| Max Distance | 2600 像素 | 相对当前镜头中心的听觉距离 |
| Category Interval | 0.035 秒 | 全场同类出招/受击的最短播放间隔 |
| Pitch Variation | 0.055 | 每次播放的轻微音调变化幅度 |

各类别的音频数组可以直接拖入 WAV/OGG 替换或增加变体。
同一单位、同一类别 0.09 秒内的重复事件合并；死亡声可替换已占满池的普通攻击声。
全部音效走 `CombatSFX` 总线，附带限幅器；出招、受击、死亡另有分层增益，受击声较轻。

## 默认匹配

| 类型 | 攻击 | 受击/死亡 |
| --- | --- | --- |
| 步兵、骑士、斧兵、枪兵、剑士、兽人近战 | 挥击 | 撞击；人类倒地或怪物死亡 |
| 弓箭手、骷髅弓箭手 | 弓弦 | 箭矢命中声 |
| 法师 | 火球发射、冰系施法 | 火焰命中、冰晶破裂 |
| 死灵法师 | 魔法施放、召唤 | 重撞击 |
| 蝙蝠、狼人、熊人 | 短促兽声 | 撞击、怪物死亡 |
| 骷髅 | 武器挥击 | 木质撞击和散落声模拟骨架 |
| 史莱姆 | 湿润弹动 | 湿润受击、散落 |
| 牧师 | 近战、治疗施法 | 撞击、倒地 |

单位资源的 `Combat Sound Profile` 留空按兵种自动选择，或填写 `human`、`monster`、`beast`、`undead`、`slime` 覆盖受击与死亡音色。
技能资源的同名字段默认 `auto`，可选择具体出招音色；`silent` 只关闭此技能出招声。
新兵种默认会使用基础近战和人类反馈，可再覆盖音色。

## 触发时机与生命周期

- 出招声在技能管理器的真实命中/发射帧播放，连击按各命中帧触发，反击也使用相同入口。
- 受击声在 `UnitBase.get_hurt` 确认命中后播放；友军、尸体、无效攻击和闪避不会播放普通受击声。
- 弓箭/火球在发射时保存音色，在实际撞到目标时播放命中声。发射者死亡或切换技能不会改变旧弹的音色。
- 死亡声只在第一次 `die` 播放，单位节点释放后仍可由池中的播放器播完。
- 切入回合结算时停止普通声音，保留已开始的死亡尾音；进入下一轮准备、胜负阶段、切场或退出场景时停止全部声音。
- 暂停时继承场景树暂停，不新增战斗声音；独立音频 RNG 不消耗闪避、抽牌或奖励的随机数。
- 环境持续伤害沿用原来的伤害逻辑，致死会播放死亡声；本次没有新增脚步、背景音乐或 UI 音效。

播放服务在 `autoload/combat_audio.gd`，配方结构在 `data/audio/combat_sound_bank.gd`。
单位通过 Node 接口取得服务，避免单位/技能/界面脚本形成编译引用环。

## 素材与导出

收集自 Kenney 的 RPG Audio、Impact Sounds，rubberduck 的 80 CC0 RPG SFX，以及 artisticdude 的 Battle Sound Effects（采用其 CC0 选项）。
共 30 个原始文件，原包路径和 SHA256 见 [素材清单](../assets/audio/combat/manifest.json)，作者与许可见 [来源说明](../assets/audio/combat/CREDITS.md)。
音频由 `.tres` 直接引用，Windows/Mac 导出自动包含；一键打包的第三方说明同时附带音效来源和 Kenney 原许可。

## 验证

```text
python tools/maintenance/run_checks.py --checks combat-audio wizard-fire-ball skeleton-archer counter bloodthirst summon battle monster-test resources
python tools/maintenance/audit_paths.py
```

`combat-audio` 回归使用真实单位、动画帧和投射物，检查素材哈希/时长、不同音色、准备与暂停、闪避、死亡去重、发射者释放后的命中、同源/全场限频、固定池、死亡优先、随机数隔离和阶段/场景清理。
还通过 AudioEffectCapture 读取音效总线实际混音，要求采样非空且幅值非零；测试在退出前停止声音并等待混音释放。
普通 headless 逻辑回归关闭播放，避免 Godot 在立即 quit 时报告尚未释放的音频流；仍会加载并校验音效资源。图形试玩按正常设置播放。
