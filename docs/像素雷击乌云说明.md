# 像素雷击乌云

参考：[从几个椭圆到雷击乌云｜《五星地牢》像素特效拆解 06](https://www.bilibili.com/video/BV1bCYc6BE1b/)。依据视频展示的椭圆层叠、像素化、噪声扰动、三色明暗、翻滚和云内闪光重新实现乌云；落雷通过独立实例复用现有 `pixel_lightning.tscn`。

**原来的落雷脚本、场景、预览及测试文件均未修改。** 效果本身保持独立、无伤害逻辑；雷云药水已通过实例复用它，玩法和专用试玩见 [雷云药水说明](雷云药水说明.md)。

## 运行独立预览

Godot 打开 `examples/scenes/pixel_thunder_cloud_demo.tscn`，按 **F6**。

- 左侧放大观察乌云轮廓、灰色明暗、翻滚与云内闪光。
- 右侧展示乌云、落雷和骷髅尺寸参照。骷髅仅播放已有贴图动画，不创建实际单位。
- 下方展示翻滚待机、云内蓄光、放电落雷、余光恢复四个时刻。
- 右侧侧栏可调整云宽、高度、翻滚、边缘噪声、像素颗粒、闪光、配色及落雷类型。侧栏可滚动。

**空格** 暂停 / 继续；**R** 新放电，重新选择云内出雷点；**Enter** 重播当前周期；**→** 暂停并前进 1/60 秒。拖动时间轴可定位当前周期任意时刻，保留这一周期的出雷点与雷线。将播放速度调到 0.1–0.3 倍，可观察短暂的云内闪光与雷击。

可以分别开关云内闪光、落雷和触地火花；落雷下拉框支持单雷和树状落雷。分层查看支持完整效果、椭圆结构、像素遮罩、三色明暗、云内闪光和流动噪声。

## 新增资源

| 文件 | 用途 |
| --- | --- |
| `scenes/effects/pixel_thunder_cloud.tscn` | 乌云与落雷的独立组合场景 |
| `scripts/effects/pixel_thunder_cloud.gd` | 云团参数、本地时钟、放电选点、落雷同步与信号 |
| `shaders/pixel_thunder_cloud.gdshader` | 椭圆层叠、像素噪声、三色明暗、翻滚与局部闪光 |
| `examples/scenes/pixel_thunder_cloud_demo.tscn` | F6 预览入口 |
| `examples/scripts/pixel_thunder_cloud_demo.gd` | 控制面板、时间轴、同步对照与四阶段拆解 |
| `tests/pixel_thunder_cloud_render_test.tscn` | GPU 渲染与预览交互检查 |

组合根节点是 `PixelThunderCloud`，原点 **(0, 0) 为固定落点**。子节点 `Cloud` 显示乌云，`Lightning` 是原落雷场景的一个独立实例。所有落雷参数只设置在此实例上，不写回原资源。

默认乌云形态参数为 112 × 58，位于落点上方 156 像素，由 11 个前景椭圆云团和 2 个后方暗云团组成。轮廓与内部明暗在像素栅格中填色，透明区域保留透明；默认只使用暗部、主体、亮部三种灰色。云团的位置、半径和噪声随本地时间缓慢变化。

默认 2.4 秒一个放电周期，0.65 秒开始落雷。落雷前约 0.18 秒出现短促云内蓄光；落雷显现与峰值阶段，靠近出雷点的云团同时亮起，附近云团较弱，随后恢复灰色。每周期生成一次云内出雷点与雷线，播放期间保持固定。主干末端始终保持在原点，云团本身继续翻滚。

默认提供单雷，可在根节点选择树状落雷。原落雷的劈落、亮片、分支和触地火花继续由原组件负责；新控制器只驱动它的时间、摆放与实例参数。

## 后续取用

雷云药水已复用此场景；其它用途也可独立实例化：

```gdscript
var thunder = preload("res://scenes/effects/pixel_thunder_cloud.tscn").instantiate()
thunder.auto_start = false
thunder.loop = false
add_child(thunder)
thunder.global_position = desired_ground_position
thunder.trigger()
```

- `Playing` / `Playback Speed`：暂停或控制整个组合的本地时钟。
- `Auto Start`：加入场景后是否自动开始放电。关闭时乌云可以继续翻滚，等待 `trigger()`。
- `Loop` / `Cycle Duration`：是否循环放电及周期长度。默认开启，便于独立预览。
- `Strike Delay`：每周期中开始落雷的时刻。
- `trigger()`：生成新的随机放电序列，从第一周期开始。不会擅自修改 `Playing`。
- `restart()`：重播当前随机序列；`reset_sequence()` 恢复当前种子对应的起始序列。
- `seek(seconds)`：定位组合画面，不发送击中 / 完成信号。循环模式可传入跨周期的总时间；同一时间与种子得到同一形状。静态检查时将 `Playing` 关闭。
- `get_elapsed()` / `get_cycle_time()`：读取总时间 / 当前周期时间。
- `get_discharge_position()`：读取相对根节点的出雷点。
- `get_lightning()`：读取组合内部的原落雷实例。
- `struck`：自动播放的主干触地时发出，每次放电一次；关闭落雷不发送此信号。
- `finished`：自动播放的落雷完全消退时发出，每次放电一次。单次模式随后停止放电，乌云保留并继续翻滚；节点不会自动销毁。

信号只供未来接入使用，不自动扣血或产生任何玩法效果。建议整体使用整数倍 `Scale`，以保持像素清晰。
