# 商店节点

默认十层地图的第 3、8 层各有一个商店分支。地图上的钱袋图标表示商店，与其他节点共用深棕色手绘图集；进入后点击商品购买，点击“离开商店”才完成节点、插旗并开放下一站。

打开 `examples/scenes/shop_example.tscn` 按 F6 可直接体验商店，演示提供 449 金币，不改变正式开局配置。

商店内容默认按 88% 比例显示，帐篷背景铺满窗口。选中 `ShopPanel` 可调整 `Content Scale`；地图节点使用 88 × 88，图例使用 64 × 64，圈选与完成旗帜也随节点重新定位。

## 商品与费用

`data/shops/caravan.json` 配置商品池、每种商品价格和陈列数量。每店随机抽取最多 3 张征召牌、4 张功能牌、3 件遗物、3 瓶药水，并为一张征召或功能牌打五折。同一商品只出售一次，已持有和已停用遗物不会上架。

征召牌和功能牌购买后永久加入本局卡组；遗物与药水加入真实库存，沿用现有战斗效果。金币不足时显示缺少金额，不扣费。查看地图、卡组或返回商店不会刷新库存或折扣。

删牌需要选择一张具体牌并确认，取消不扣款。每店限一次，每局首次 75 金币，后续每次加 25 金币。保留至少一张牌；同名牌只移除选中的那一张。开始新局清空商店库存与删牌涨价次数。

## 自定义地图

Godot 顶部“地图工坊”和 `tools/map_editor/index.html` 都支持添加“商店”。地图 JSON 中商店的 `type` 为 **5**，宝箱仍为 4，其余编号不变。

```json
{
  "id": "floor_03_shop",
  "title": "旅途商队",
  "type": 5,
  "event_id": "",
  "shop_catalog": "res://data/shops/caravan.json",
  "floor": 3,
  "map_pos": {"x": 0.5, "y": 0.7},
  "next": ["floor_04_01"]
}
```

`shop_catalog` 可省略，默认使用 caravan.json。新增配置请放在 `data/shops/` 下；导入地图时会校验商品资源类型、价格与陈列数量。

已导入的旧路线需要在工坊添加商店并重新导入，或在主菜单切回默认路线。已有路线不会自动替换节点。
