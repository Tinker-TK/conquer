# 装甲斧手技能

未强化和强化后均保留普通攻击、劈砍攻击、旋转攻击。训练属性按原有规则分配。

| 技能 | 未强化 | 强化一次 |
| --- | --- | --- |
| 旋转攻击 | 原范围内敌军受到80%攻击力伤害，向远离自身方向击退200像素。冷却3秒，攻击动作第5帧结算。 | 保留击退；命中本层地形或通用实体障碍时提前停止，并眩晕2秒。 |
| 劈砍攻击 | 第4、7帧各造成120%攻击力伤害，冷却8秒。 | 首刀出手时清空自身护盾并记录数值S，本次两刀各额外造成S伤害。 |

旋转释放时，在斧手自身播放 Eslabong 实验室“奥术 · 祈祷”的原 `ArcanePrayer` 特效；范围伤害与击退由正式战斗系统结算。

护盾只在有效目标的首刀出手时消耗一次，两刀使用同一数值快照。加伤并入普通攻击伤害包，按原有防御等规则结算。没有护盾时额外伤害为0；首刀前被打断不消耗护盾，首刀后被打断取消第二刀且不返还护盾。快照只属于该单位本次施法，结束或中断即清除。

击退按0.3秒连续物理步推进，以完整身体扫描碰撞，防止穿墙。其它单位不作为撞墙眩晕的障碍；隔层墙体不参与碰撞。地表边缘会停止击退，但不作为墙体触发眩晕。战斗阶段结束、目标死亡或控制中断时停止旧位移并清除移动锁。

测试场：打开 `scenes/testing/monster_test.tscn`，使用装甲斧手的普通添加与“强化1次”按钮分别验证。护盾可由强化牧师的溢出治疗提供。

回归：`python tools/maintenance/run_checks.py --checks armored-axeman`；图形模式追加 `--armored-axeman-regression --capture`，在 `.maintenance/armored-axeman/` 保存释放与撞墙截图。
