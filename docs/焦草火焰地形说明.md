# 焦草与火焰地形

火焰区域保留草地烧焦的纹理，叠加焦褐色斑块、干黄过渡、贴地卷动的橙红燃烧薄片、稀疏余烬和实验室「灼烧 · 地面」的火星。焦痕用 `blend_mul` 直接与已绘制的地面相乘，不读取屏幕，不替换草地贴图。火焰从焦草上燃起，人物保持可见；火星继续在上方飘散。

火焰地形入口仍是 `scripts/effects/burn_ground_zone.gd`。伤害、范围、阵营、重叠期限和战斗结束清理由卡牌区域管理；本效果不创建碰撞或伤害节点。

- 独立场景：`scenes/effects/pixel_burned_ground.tscn`。
- 地面 Shader：`shaders/pixel_burned_ground.gdshader`。
- 燃烧层：`scripts/effects/ground_burning_layer.gd` 和 `shaders/ground_surface_burn.gdshader`。以单个透明画布绘制不规则的扁平燃烧斑块：沿斑块前后边缘生成卷起的火焰薄片，内部透出焦草，流动噪声侵蚀尖端与空洞。大小、燃烧时长和相位由位置与种子计算，不创建多个火焰场景或使用玩法 RNG。
- 燃起约0.5秒，燃烧2.6～5.3秒，再熄灭0.4～1.2秒；各处交错循环。火焰基准高度12～20像素，由流动噪声进一步起伏，小范围随半径缩小。邻近斑块取最大覆盖率合成，透明度不会因叠加而不断加深；原通用 `pixel_flame.tscn` 保留独立使用。
- 火星来源：`assets/effect/eslabong_vfx/source/Scenes/VFX/BurnGroundVFX.tscn` 的 `Particles` 节点，接入脚本为 `scripts/effects/burn_ground_sparks.gd`。已核对素材目录及技能组合中的 `volcanic_eruption` 引用。
- 保留原始30粒、0.8秒寿命、0.5随机分散、向上重力、10～30初速、2～5像素大小及原始大小曲线、黄橙渐变。仅按区域半径拓展发射范围，不放大单粒火星。
- `radius` 控制范围；`burn_amount` 控制焦黑程度；`flame_density` 控制燃烧斑块的分布密度；`flame_opacity` 控制火焰不透明度（默认0.42），使底层焦草纹理更清晰；`spark_density` 控制原火星数量倍率（1为原始30粒）；`pixel_size` 同时控制焦痕与燃烧层的像素颗粒。
- 原场景的地面多边形、碰撞和秒数删除逻辑不进入战场。原生粒子节点构造时按 Godot 标准行为取一次初始种子，之后使用固定种子；持续播放和定格不再消耗玩法随机数。
- 焦痕、燃烧薄片、余烬、粒子共用区域物理时钟，使用 `request_particles_process()` 驱动源粒子，跟随游戏暂停和战斗倍速；`seek()` 支持定格复现。

原熔岩保留为独立素材 `scenes/effects/pixel_lava.tscn`，火焰地形现使用焦草方案。

## 视频参考

已下载并逐帧查看用户指定的[《程序化燃烧特效，这TA大佬太牛了！》](https://www.bilibili.com/video/BV1dyJi62E5A/)。公开预览约37秒，演示球面上的 Surface Field Mask、Ember Layer、Alpha Layers 与粒子分层。1～5秒与31～35秒为完整效果，16～23秒展示沿不规则表面边缘发亮、卷动的燃烧层。

本项目将其沿面燃烧边缘、焦黑内部、向上侵蚀的薄片和火星分层转为2D像素画布。保留用户要求的小火焰、连续分布与0.42透明度。参考文件与抽帧位于 `.maintenance/flame-reference/BV1dyJi62E5A.mp4` 和 `burn-reference-overview.jpg`，仅供本地分析；运行时不依赖视频素材。

## 验证

```text
python tools/maintenance/run_checks.py --checks zone combat-card --label burned-ground-sparks
Godot --path . --fixed-fps 60 res://tests/burned_ground_render_test.tscn -- --no-mcp-server
Godot --path . --fixed-fps 60 --script res://tests/card_framework_test_runner.gd -- --no-mcp-server --zone-regression --capture-fire-zone
```

GPU 检查使用项目实际草地纹理，验证范围外像素不变、原纹理对比保留、人物绘制层级、源粒子参数与资源一致、燃烧前沿在画面中的燃起与熄灭、焦草保留、火焰范围、暂停、定格复现、材质隔离和播放随机数隔离。截图与定格帧位于 `.maintenance/burned-ground/`，实战截图位于 `.maintenance/fire-zone-preview.png`。

实现核对了 [Godot CanvasItem 混合模式](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/canvas_item_shader.html)。
原生粒子的手动推进、重播和初始种子行为核对了 [Godot 4.6 CPUParticles2D 实现](https://github.com/godotengine/godot/blob/4.6/scene/2d/cpu_particles_2d.cpp)。
