# 第一章路线事件实装

已接入《路线事件设计》的 20 个路线事件，另调整开局援军、旅人的药剂和旧圣匣。20 张新插画使用内置 image_gen 生成，以已有援军和圣匣插画为风格参考；图片、事件资源和生成提示词均已保存在项目内。

## 游戏内行为

- 第一层固定「岔路的援军」：征召牌三选一、战术牌三选一、回复生命或离开，只能选一项。
- 后续奇遇统一显示「旅途奇遇」，进入后按楼层、权重、队伍条件抽取。第一章池含 20 个新事件和低权重的旅人药剂。
- 同局不重复抽取正式事件；直接遗物事件最多 1 次，复制事件最多 1 次，删牌事件最多 2 次。配额按遇见事件计数，离开也占用这次事件配额。
- 空池回退「遗弃兵营」：25 金币与 6 点治疗，始终可以离开。
- 所有 16 条完整路线均为 3–4 次奇遇、至少 3 场普通战斗、1–2 次篝火；普通战斗节点总数仍为 9，节点位置与连线保留。

## 选择与结算

- 成本直接显示在选项上；金币不足、生命不足或没有合法目标时按钮置灰并解释原因。
- 生命成本至少留 1 点，最大生命成本至少留 10 点。增加最大生命会同时增加等量当前生命，再结算额外治疗。
- 删牌与复制共用牌组网格，支持类别筛选和取消。不能删掉最后一张牌；复制保留训练、强化、士兵分支与永久增益，副本独立。
- 随机强化只抽还能强化的战术牌，抽取不同的具体牌实例；兵种的升级仍使用训练。
- 铁匠熔炼先选择要移除的牌，再选择另一张战术牌强化，最后统一结算。取消不支付成本，也不丢牌。
- 赌局先支付注金，获胜返还选项标注的总金额。例如押 30、返还 90，实际净收益为 60；失败净损失 30。界面明确写出概率和返还规则。
- 结算显示实际生命、最大生命与金币变化；奖励只能领取一次。失败时恢复交易快照。

## 存档与兼容

- 开局冻结事件正文、选项和事件池。工坊编辑不改变进行中的本局内容。
- 首次进入地点固定事件及奖励随机种子。查看地图、牌组、取消后重选、保存再继续均不重抽。
- 未完成的奇遇在读档后锁定到原节点，完成后恢复路线选择。
- 存档保存已见事件、完成事件、类别计数与选择前后资源日志；旧存档缺少这些字段时补默认值，继续沿用旧路线。
- 旧 `effect`、两组五选一、篝火和旧插画路径继续兼容。正式教学事件改为只领一张牌，旧圣匣改为生命换遗物并退出随机池。

## 编辑入口与文件

| 位置 | 用途 |
| --- | --- |
| `data/run/game_map.json` | 正式第一章运行路线 |
| `data/levels/第一章 ·  翠绿原野.json` | 相同布局的工坊路线 |
| `data/events/act1_*.tres` | 20 个事件及楼层、标签、条件、选项配方 |
| `data/events/pools/act1.json` | 第一章权重与投放范围 |
| `data/event_recruits/` | 棕熊及三种亡灵的事件专用己方配方，原敌方资源保留 |
| `assets/ui/events/illustrations/` | 20 张独立插画；`route-prompts.json` 保存提示词与风格参考 |
| `scripts/events/` | 候选、成本、抽池、预览副本及原子结算 |
| `outputs/route_events_20261018/` | 插画总览、运行截图、测试日志与修改前源文件备份 |

事件工坊新增「路线抉择」模板，可在 JSON 配置中编辑成本、复合效果、楼层与条件，并直接预览、试玩、撤销、保存。地图工坊的事件绑定列表新增「第一章随机奇遇池」。

`tools/maintenance/build_route_events.py` 可从设计正文和明确的配方映射重新生成资源与路线；执行会覆盖这些生成文件，手动调数值后不要直接重跑。`tools/maintenance/route_art_contact_sheet.py` 可重新制作插画总览。

新路线在新开一局时生效。数值按设计稿接入；收益与通关平衡仍需后续实际战斗试玩观察。
