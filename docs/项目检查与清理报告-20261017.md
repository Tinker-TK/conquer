## 已处理的问题

- 修正局部变量遮蔽节点属性、内置方法和外层变量的问题；只改局部标识符，保留节点名、字典键、资源路径和方法名。
- 为未使用的接口参数加下划线；移除拖牌代码中未使用的来源变量和返回值赋值，保留原施放调用。
- 显式初始化原本默认即为 `null` 的局部变量；为枚举变量和混合类型条件表达式补全等价的类型表达。
- 移除测试中的无效 `await`，以及单位 `_ready()` 最后一行没有后续操作的物理帧等待。后者能消除部分退出时的悬挂对象警告，初始化副作用和顺序保持原样。
- 移除隐藏框选控件时无用的尺寸清零；实际拖选每次仍先计算完整矩形，避免初始化阶段的锚点尺寸警告。
- 修复雪天演示和项目导航页中的旧树木路径，使用现存 `tree01.tscn`。
- 修正并行新增地图绘制脚本的一处 API 参数顺序：`draw_texture_rect_region(texture, rect, source)`。
- 修复 `Preview.ogg` 中不符合 Vorbis 注释格式的编码器元数据，并重新导入。所有音频数据包保持逐字节一致，记录见 `ogg-metadata-fix.json`。
- 修正死亡退场测试对“立即起烟”的旧假设，等待既有死亡动画完成；保留死亡只结算一次、暂停、取消攻击和最终释放等断言，并在烟雾未创建时避免空引用。
- 修正关卡扫描把楼层连接组件当作完整战场的误报；完整战场的实体层与 UI 检查仍保留。
- 修正开局抽牌测试对固有手牌数量的旧假设，计入配置中的 `starts_in_hand`。
- 波次拖动测试先放大预览，避免大地图全景下多只单位落入同一个拾取半径；仍检查指定坐标、撤销、重做和保存回读。
- 河流集成测试在内存建立固定河床，避免依赖作者正在编辑的关卡布局；不保存到正式关卡。
- 路径审计区分预期不存在的测试夹具、嵌入资源 `::` 后缀、按需生成的输出目录和可选输入。
- 回归运行器现在记录警告，便于发现退出清理等问题；仍要求成功标记、正确退出码及无错误日志。

119 条初始警告中，94 条通过等价改写或冗余清理处理。其余 24 条整数除法提示对应 23 条刻意取整的语句，保留原运算并逐处加注解；另 1 条是由其他脚本发送和订阅的信号被误报为未使用，也采用局部说明。没有全局关闭警告。

## 保留的失败与警告

1. **`battle-speed`：途中切换倍速并暂停时，持续效果战斗的事件序列不同。** 初始基线已经失败，清理后仍稳定复现。固定 1/2/3 倍速的结果和事件一致；切档案例中的胜负、扣血与幸存生命相同，但事件数量为 14，固定速度为 15。没有修改这条断言或调整战斗时序来消除失败。
2. **`game_session_smoke`：脚本入口存在自动加载依赖编译错误。** 修正固有牌数量后，该烟测继续暴露 `Global` / `SignalBus` 依赖错误及后续脚本失效。现会检测失败并立即以退出码 1 结束，避免持续逐帧报错和 60 秒超时。独立对该入口调用 `--check-only` 时还触发过 Godot 4.6.2 的 signal 11；完整资源加载与主菜单启动检查正常。没有改动生产代码的初始化或资源缓存策略。
3. **快速退出时的 ObjectDB 警告仍有残留。** 无界面主菜单及部分测试会在退出时保留音频播放对象；关卡模板的详细日志已确认包含 `AudioStreamWAV` / `AudioStreamPlaybackWAV`。这与已消除的空等待悬挂对象分开记录，仍需后续处理音频退出时机。
4. 敌方初始牌过滤、非法药水特效和波次写入冲突测试会主动触发警告，以验证拒绝与草稿保护路径；这些不是正式配置失效。
