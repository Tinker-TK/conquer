# 雨天效果配置说明

雨天已经接入 `scenes/battle/battle_scene.tscn`。继承战场的战斗关卡自动获得雨滴、积水、单位/场景精灵倒影、落雨水花与移动脚步波纹。场景 Settings 使用 `rain_default.tres`；正式第 1 关的 `data/levels/level_001.tres` 当前覆盖为 `rain_reference.tres`。

参考：[Mushreb《2D游戏中的雨天效果 DEV LOG.02》](https://www.bilibili.com/video/BV1s6rDBpEvo/)。实现沿用演示中的噪声积水、翻转物体倒影、独立水波纹理和屏幕纹理折射思路。项目里单位使用多种动画图集，因此通过独立 SubViewport 同步当前精灵帧来绘制倒影；不复制单位脚本、碰撞、血条或技能。

## 完整视频核对与本次修正

完整视频已保存为 `.maintenance/rain-reference-video-0.mp4`，时长 126.85 秒。按时间顺序检查了从开头到结尾的画面和字幕，并保留每 0.5 秒的连续帧，位于 `.maintenance/rain-video-review/`。

| 视频位置 | 效果流程 | 项目处理 |
| --- | --- | --- |
| 0–19 秒 | 成品展示、落雨和落地水花 | 雨滴粒子与有数量上限的水花事件 |
| 19–33 秒 | 静态噪声切出积水，再在内侧水边采样移动细节 | 主体阈值固定，移动噪声只改变窄亮边，不再改变干湿区域 |
| 34–49 秒 | 独立水波视口、走入积水的脚步波纹 | 雨滴与脚步共用事件，波纹受水面遮罩裁切 |
| 50–83 秒 | 翻转物体倒影、叠加天空、轻微扭曲 | 当前精灵帧倒影视口，加实际天空纹理的云形 |
| 84–107 秒 | 可见波纹与柔和扰动分通道，折射地面和倒影 | R 绘制细环，G 绘制较宽高度场；仅环附近折射 |
| 107–126.85 秒 | 用静态噪声控制透明度，成品走动展示 | Depth Opacity 控制浅边透明度，远处倒影淡出可调 |

之前的移动噪声参与了整个水洼阈值，又叠加全局正弦扭曲，因此有流水感。现在主体遮罩和深浅透明度固定，仅水面的天空颜色层缓慢流动，默认跟随雨天风向。之前显示遮罩还读取导航烘焙后的凸多边形，导航的 agent_radius 和图块碰撞轮廓产生直线切口；现在按实际地表纹理 alpha 绘制，导航只继续负责游戏寻路。

## 最快配置方法

1. 正式第 1 关：打开 `data/levels/level_001.tres`，查看 **Weather Settings**，当前引用 `data/weather/rain_reference.tres`。
2. 双击这份天气资源，在 Inspector 修改参数并保存，F5 进入第 1 关查看。
3. 单独 F6 预览战场：打开对应战场场景，选中 **RainWeather → Settings**；这个入口沿用场景资源。
4. 可在第 1 关 **Weather Settings** 中切换天气资源，比较 `rain_reference.tres` 的暗绿灰与 `rain_storm.tres` 的强天空倒影效果。

### 天空移动与更明显的落雨

当前第 1 关可直接编辑 `data/weather/rain_reference.tres`：

| 参数 | 当前值 | 调节 |
| --- | --- | --- |

| Sky Wind Speed Scale | 0.02 | 云纹慢速倍率；风越大流动越快，0 冻结，0.03~0.04 更明显 |
| Sky Use Scene Clouds | 开启 | 从 `Level/decrition` 的 Clouds 精灵读取原始云形与颜色，随机排布为水面独立云层 |

| Sky Cloud Count / Size | 6 / 0.65 | 每个循环图块的云朵数量 / 图片基础大小倍率 |

| Wind | 337.5 | 近雨水平方向的实际渲染像素/秒；正数向右，负数向左，0 竖直下落 |

### 水面云朵随风流动

默认开启 **Sky Use Scene Clouds**。雨天节点的 **Cloud Source Path** 默认为 `../Level/decrition`，读取其下 `Clouds*` 精灵使用的原始图片，去除重复图片后随机选形、随机大小并分布在独立循环云图中。先随机使用一轮不同云形，再允许重复。当前默认每个循环图块 6 朵，大小倍率 0.65；Random Seed 相同时可复现相同选形和排布。修改种子可以换一组分布，运行中不会逐帧重新选图。

场景内原有 Clouds 精灵的图片、位置、材质与动画保持原样；这些背景云朵不进入角色/树木的物体倒影视口。水面专用副本会先遮掉原图片下方的半透明深色阴影，保留浅色云体的颜色层次和边缘透明度，再上下翻转形成镜像；不修改原图片或精灵的 Flip V。只有新云图在水面中平移，跨越循环边缘的云朵会从另一侧连续接出。角色与树木的倒影最后合成，保持清晰。关闭 Sky Use Scene Clouds，或来源容器没有 Clouds 图片时，回退到 Sky Texture 的天空云纹。

**Sky Cloud Strength** 现在直接控制场景云图的不透明度，已由 0.20 提高到 0.65，并取消与 Sky Strength 的额外相乘，避免云形过淡。需要更实用 0.75~0.85，更淡用 0.40~0.50，0 隐藏独立云图。Sky Strength 继续控制天空背景颜色层，Wetness / Depth Opacity 继续控制整个水面的透明度。

默认开启 **Sky Follow Wind**。云纹速度为 `abs(Wind) × Sky Wind Speed Scale`，单位是世界像素/秒；云层只沿画面水平方向左右移动，正风向右，负风向左，与雨滴的下落速度和倾角无关。Wind=0 或倍率=0 时停止。云纹位移逐帧累积，改变风速、风向或重新应用配置时延续当前位置。

当前参考预设 Wind=337.5、倍率=0.02，对应约 6.75 世界像素/秒，默认镜头下速度向量为 `(6.75, 0)`，向右缓慢流动。想更快流动可将倍率调为 0.03~0.04；想云朵更实可将 Sky Cloud Strength 调为 0.75~0.85。

只移动云纹颜色，积水主体、深浅透明度、角色/树木倒影不随云层平移。暂停战斗时云纹也暂停。需要原来的手动方向时，关闭 Sky Follow Wind，再设置 Sky Scroll Speed。

此前雨滴纹理宽度写死为 2 世界像素，窗口拉伸和镜头缩小会把它压成亚像素；数量/长度参数无法控制宽度。纹理整条都做正弦透明渐变，雨滴还被阴天 CanvasModulate 染暗，发射范围又包括屏幕下方。现在尺寸由新参数控制并补偿绘制缩放，核心保持较亮、只淡出两端，独立着色器保持雨色，粒子从镜头上方窄带落下且生命周期足够穿过底端。

### 斜向直线下落与地面接触

雨丝现在用实际速度对齐长轴，取消随机偏角、随机速度和重力，近雨与远雨各自沿同一方向匀速直线移动。此前用 Node2D 的角度符号设置 ParticleProcessMaterial，使雨丝和移动方向倾斜相反，产生侧飘感。现在自动对齐，不需要手动设置粒子角度。

Fall Speed / Wind 已从世界像素/秒改为实际渲染像素/秒，与 Streak Width / Length 的单位一致。原先 640×360 窗口显示 1920×1080 场景时，速度 1600 只移动约 533 屏幕像素/秒，雨丝长度却仍为 79 像素；现在缩放不会再减慢落雨。当前第 1 关设为 2400 / 337.5，保留原先约 8° 的倾斜幅度，远雨速度为近雨的 82%。倾角由 `atan(Wind / Fall Speed)` 决定；希望加速时维持倾角，应把两个参数按相同比例增大。

地面接触由有效落点驱动：先绘制朝落点直线移动的最后一段雨丝，碰地时出现扁亮点，随后三粒水珠向上、向两侧溅起并落回。干燥草地和露出的河床也有水花；积水与河流落点额外产生原有水面环和局部折射。雨滴尚未碰地时不会提前产生水面扰动。天空洞、悬崖和地图外不会成为落点。

地面水花有独立尺寸、透明度与短寿命，水面环继续使用 Ripple Lifetime / Radius；阴天染色不再遮暗水珠。雨滴末段与水花锚定世界落点，镜头平移时不会像蒙皮贴在屏幕上。

### 更明显的物体镜面倒影

`rain_reference.tres` 与场景默认的 `rain_default.tres` 已加强物体倒影。关卡预设保持现有积水分布，主要通过降低地面透出、减弱远端渐隐与波纹扭曲，保留完整的物体轮廓。

| 参数 | 关卡 rain_reference | 场景 rain_default | 效果 |
| --- | --- | --- | --- |
| Reflection Opacity | 当前 0.94 | 0.90（原 0.10） | 提高物体倒影的混合强度 |
| Reflection Fade | 0.08（原 0.30） | 0.10（原 0.30） | 倒影远端保留更多颜色与轮廓 |
| Wetness | 0.98（原 0.90） | 0.95（原 0.70） | 减少原地面透出造成的倒影冲淡 |
| Depth Opacity | 0.18（原 0.55） | 0.20（原 0.65） | 避免浅水区域把倒影过度变透明 |
| Distortion | 0.35（原 0.80） | 0.40（原 1.20） | 保留落雨波纹，同时减少物体轮廓变形 |
| Reflection Gap | 0（原 2） | 0（原 2） | 让倒影从脚底连续接出 |
| Reflection Height / Resolution | 1 / 1 | 1 / 1（原 0.72 / 0.75） | 保留完整镜像高度和纹理细节 |

倒影仍只出现在有效水面上；物体脚底附近没有积水时，可另外增加 Puddle Coverage。若还需要更平静的镜面，可将 Distortion 降到 0.15～0.25；需要更通透的浅水时再增加 Depth Opacity。

第 1 关资源当前还设置了 `Snow Weather Settings = snow_default.tres`，雪天启用时会优先关闭雨天。要从这个入口预览雨天，在 `level_001.tres` 中清空 Snow Weather Settings，或使用 Enabled 关闭的雪天预设；Weather Settings 保持 `rain_reference.tres`。

默认场景引用 `data/weather/rain_default.tres`。直接修改这份资源会改变所有沿用它的关卡。只修改某一关时，在该关的继承场景中选中 RainWeather，将 Settings 设为“独立化 / Make Unique”，或加载/另存为另一份 `.tres`。

## 按关卡资源配置

双击 `data/levels/level_001.tres` 等 BattleLevelConfig 资源，在 Inspector 的 **天气 → Weather Settings** 槽指定预设。

- 此项为空：沿用该战场 RainWeather 节点的 Settings。
- 指定天气资源：进入战斗前覆盖场景预设，第一帧就按此资源显示。
- 指定 `weather_clear.tres`：此关为晴天。

地图直接引用 `scenes/levels/battles/battle_00x.tscn` 时，可直接编辑对应继承场景的 RainWeather。关卡模板和正式场景共享同一套接入方式。

## 参数对应表

表内默认值指 Settings 脚本的初始值，天气预设可以覆盖它们。当前第 1 关雨天预设的 Sky Strength 为 0.65；想保留更多草地细节，可降低到 0.30~0.45。`rain_storm.tres` 的 Sky Strength 为 0.90，天空颜色更强。物体倒影在 `rain_reference.tres` / `rain_default.tres` 中分别为 0.94 / 0.90；调参时应修改实际加载的预设。

| Inspector 参数 | 含义与建议 |
| --- | --- |
| Enabled | 整体开关；关闭会停止天气更新、粒子和离屏渲染 |
| Intensity | 雨量 0~1；0 停止落雨，积水仍由 Wetness 控制 |
| Atmosphere Tint | 战场阴天颜色；雨量越高，场景越接近此色；独立 CanvasLayer UI 不参与 |
| Random Seed | 固定积水形状、云朵选形排布与水花随机序列；云层使用独立随机序列，重新应用相同种子不会闪换云形 |
| Rain Amount | 最大粒子数；实际数量还乘以 Intensity。默认 560，性能优先可用 250~350 |
| Fall Speed | 雨滴下落速度，默认 1800 实际渲染像素/秒；远雨乘 0.82，上限 6000 |
| Wind | 水平风速，默认 -250 实际渲染像素/秒；负数向左、正数向右；会同时改变雨滴倾斜角 |
| Rain Opacity / Rain Color | 雨滴透明度与颜色，类默认 0.60 / 淡蓝白；颜色 Alpha 会乘透明度，雨色不受阴天染色 |
| Streak Width / Streak Length | 雨丝实际渲染像素的宽/长，类默认 3 / 22；不因窗口缩小、镜头拉远变细；远雨尺寸为近雨约 70% / 65% |
| Puddles Enabled | 积水开关；可只保留雨滴与落地水花 |
| Puddle Coverage | 噪声阈值控制的积水数量，0 关闭积水；不是精确的地表面积百分比 |
| Puddle Scale | 积水斑块的尺度；数值越大，斑块越大 |
| Edge Softness | 水边渐变宽度；像素风建议 0.015~0.035 |
| Edge Noise Scale | 独立移动水边噪声的细节尺度，默认 24 世界像素；越小边缘越细碎 |
| Edge Noise Strength | 仅扰动内侧亮边的宽度与碎片，默认 0.10；0 为连续固定亮边，水洼主体始终固定 |
| Edge Noise Speed | 噪声采样的移动速度，默认 `(12, -8)` 世界像素/秒；`(0, 0)` 冻结边缘细节 |
| Edge Width | 内侧亮边宽度，默认 3 世界像素；参考细边可用 2，0 隐藏亮边 |
| Edge Color | 水边轮廓颜色与透明度；默认淡蓝灰，Alpha 为 0 时隐藏亮边，可调成白色观察噪声轮廓 |
| Wetness | 积水合成强度；0 不显示水面，默认 0.7 |
| Depth Opacity | 静态噪声对深浅透明度的控制，默认 0.65；0 为均匀透明度，越高浅边越通透 |
| Water Tint / Sky Strength | 天空倒影色调与混合量；暗绿灰预设使用 `(0.19, 0.28, 0.27)` / 0.65，需要更明显地面细节时再降低混合量 |
| Sky Texture / Sky Scale | 天空背景贴图 / 天空及循环云图的重复世界尺寸；默认 `assets/tilemap/sky.png` / 800 世界像素 |
| Sky Use Scene Clouds / Sky Cloud Count / Sky Cloud Size | 默认 true / 6 / 0.65；随机使用 Cloud Source Path 下的 Clouds 精灵图片，只复制绘制图片 |
| Sky Follow Wind / Sky Wind Speed Scale | 默认开启 / 0.02；云纹仅左右流动，速度由风大小决定，0 风或 0 倍率冻结 |
| Sky Cloud Strength | 独立云图不透明度，默认 0.65，越大越实；场景云图不再额外乘 Sky Strength，物体倒影另用 Reflection Opacity |
| Sky Scroll Speed | 关闭随风流动时使用的自定义方向与速度，默认 `(4, -1)` 世界像素/秒；`(0, 0)` 冻结 |
| Distortion | 雨滴/脚步环附近的地面与倒影折射幅度，默认 1.2；没有水波事件时地面和物体倒影保持静止 |
| Reflections Enabled / Reflection Opacity | 物体倒影开关与透明度 |
| Reflection Fade | 倒影从脚底到远端的衰减，默认 0.30；0 不淡出，1 远端完全透明，替代原先固定的 0.85 |
| Reflection Resolution | 两个离屏纹理的分辨率比例，默认 0.5；低配 0.25，近距离清晰度优先 1.0 |
| Reflection Height | 倒影纵向压缩比例，默认 0.72 |
| Foot Offset / Reflection Gap | 镜像轴在单位原点下方的偏移与倒影起点间隙，默认 12 / 2 世界像素 |
| Max Reflections | 最多同步的精灵数量，默认 128；优先处理战斗单位，再处理装饰物 |
| Splash Rate | 满雨量时每秒尝试的落地水花数，默认 72；只在当前镜头内的有效地面/河床落点生成 |
| Splash Size / Splash Opacity / Splash Lifetime | 地面水珠的大小倍率、透明度、持续秒数，默认 1.0 / 0.9 / 0.22 |
| Ripple Lifetime / Ripple Radius | 波纹持续秒数与最大半径，默认 0.7 / 14 |
| Max Ripples | 同时存在的水花/波纹上限，默认 96 |
| Footsteps Enabled / Step Distance | 单位走过积水时产生脚步波纹；默认每移动 22 世界像素一次 |

先调整 Intensity、Puddle Coverage、Wetness、Reflection Opacity，通常就能获得所需观感。积水固定在世界坐标中，镜头平移、缩放不会使积水贴着屏幕滑动。雨滴发射区域自动跟随镜头。

移动水边使用独立细噪声改变内侧窄亮边的宽度和碎片。水洼主体、透明度和脚步干湿判断不受该噪声影响。原来的 Edge Softness 只控制过渡柔和程度，像素风细边可用 0.01；调整移动细节请使用“移动水边”参数。修改后保存天气资源并重新运行；脚本修改时调用 `apply_settings()`。

## 地形与脚底对齐

RainWeather 的 **Terrain Root Path** 默认是 `../Level/NavigationRegion2D`，只用这个节点查找 TileMapLayer，不读取导航多边形。**Ground Terrain Set / Ground Terrain Id** 默认为 0 / 0，对应当前草地的 main terrain；未标为地表的悬崖、装饰图块不会生成积水。遮罩按选中的图块实际 alpha 合并，保留天空洞、像素轮廓、纹理偏移和翻转，并支持图块跨单元边界的绘制。

新增不同地表时，可修改上述 terrain 编号；也可在 TileSet 增加 bool 类型的自定义数据 `rain_ground`，逐图块明确地表 true / 非地表 false。若有该自定义层，它优先于 terrain 编号。修改地形后调用 `apply_settings()` 或重新运行即可刷新积水，游戏寻路仍按原有方式烘焙导航。

四层战场会按楼层分别生成积水遮罩，在本层地形之上、单位之下绘制，自动跟随楼层系统的 Floor Z Stride。Layer01～Layer04、各层的子瓦片层与附属楼梯均按楼层系统的归属处理。每个有地表的楼层使用独立倒影与水波视口；单位切层时倒影和脚步水花同步切层，桥下单位不会倒映到桥上。河流继续共用第一层纹理，河床不会裁掉上方桥面的积水。

**Entities Path** 默认 `../Entities`，收集其阵营容器中的 UnitBase 主 AnimatedSprite2D。**Scenery Path** 默认 `../Level`，收集装饰物精灵；跳过天空 Parallax2D、TileMapLayer、UI 和 `assets/tilemap/Clouds/` 下的背景云朵图片。**Cloud Source Path** 默认 `../Level/decrition`，为独立水面云层读取 Clouds 精灵的图片；不会移动原精灵。其他背景节点或分支可添加 bool 元数据 `rain_reflection_exclude = true`，或加入同名分组，排除物体倒影；节点本身照常显示。

不同角色图集的脚底位置可能不同。若某单位的倒影有间隙或穿过脚底，可在该单位根节点 Inspector 底部“元数据 / Metadata”中添加浮点数 `rain_foot_offset`，覆盖全局 Foot Offset。此偏移按单位根节点的本地坐标计算。树木等装饰物同样可在精灵父节点添加此项，例如脚底原点已经正确的树木可设为 0。

独立演示或没有 TileMapLayer 的场景可以关闭 **Use Terrain Mask**，手动填写 **Ground Rect**（世界坐标矩形）。开启地表遮罩但没有匹配地表时，只显示空中雨滴。旧的 Use Navigation Mask / Navigation Region Path 已替换为以上地表配置。

水面需要画在地面上、单位下。正式战场已经配置：天空 Z=-30，地面 TileMapLayer Z=-20，地面快照 Z=-11，积水 Z=-10，水花 Z=-8，远雨 Z=-5，单位沿用原有 Y 排序，近雨 Z=8。新增自定义战场时，请沿用此层次，并只保留一个控制同一画布的 CanvasModulate。

## 运行中控制

```gdscript
var weather := $RainWeather as RainWeather

# 两秒内渐变到大雨；跟随战斗暂停。
weather.set_rain_intensity(1.0, 2.0)

# 切换预设；传入资源会复制，运行中的改动不会写回共享预设。
weather.configure(load("res://data/weather/rain_light.tres"))

# 改动其他外观字段后重新应用。
weather.settings.puddle_coverage = 0.6
weather.settings.reflection_opacity = 0.4
weather.apply_settings()

# 整体开关。
weather.set_enabled(false)
weather.set_enabled(true)
```

天气节点属于本场战斗；查看地图/卡组时随战斗暂停，离开战斗时一并释放。没有新增 AutoLoad 或输入绑定。
