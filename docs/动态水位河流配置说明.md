# 河流 TileSet：绘制地图与配置水位

第 1 关的 **Rivers → River** 现在是原生 **TileMapLayer**，挂载 `RiverTileMap` 脚本。地图布局保存为场景的 `tile_map_data`；你画什么格子就显示什么格子，运行游戏不会重新铺一条固定河流。

已有流水、动态水位、露出的碎石河床、浅深水色、岸线、焦散、折射和雨天波纹继续使用。

## 在第 1 关画河流

1. 在 Godot 打开 `scenes/levels/battles/battle_001.tscn`。
2. 在场景树选择 **Rivers → River**，切到 **2D**。
3. 打开编辑器底部 **TileMap** 面板，选择 **Terrains / 地形** 标签。
4. 选择 **河道（细河）**，再选择 **Connect / 连接** 画刷。左键拖动绘制，自动选择直线、转弯、末端、三通和四通。建议沿上下左右相邻的格子画路线。
5. 选择 **水域（湖泊与宽河）**，用画笔或矩形工具填区域，自动选择外岸与内角。中间留空一格就是岛，原来的地面会显示出来。
6. 右键拖动擦除；**Ctrl+Z** 撤销；**Ctrl+S** 保存。擦除后若使用 Tiles 标签直接指定了固定岸边图块，可用 Connect 在附近重新刷一下以修复连接。

**Path / 路径** 只连接同一次拖动画出的路线，适合两条相邻但不相通的细河。**Connect** 会连接相邻的同类地形，适合分支河流。两套地形各自自动拼接；细河与宽水域之间需要特定河口时，可以在 **Tiles / 图块** 标签手选开口图块调整接缝。

不需要手选拐角也能画常规河道。想精确控制每格形状时，Tiles 标签仍提供完整图集：

| 图集 | 图块数 | 尺寸 | 用途 |
| --- | --- | --- | --- |
| `river_channel.png`，Source 0 | 16 | 128×128 | 四方向连接，包括孤立水塘、末端、转弯、直线和分支 |
| `river_water.png`，Source 1 | 47 | 128×128 | 宽河和湖泊的边、角、内岸与满水区域 |

尺寸与现有地图地面图块一致。新增河流层时保持 Position 为 `(0, 0)`，即可与关卡地面格子对齐；图块中心由 TileMap 自动定位。

原生 TileMap 操作参考：[Godot 官方 TileMap 绘制与 Terrain 连接说明](https://docs.godotengine.org/en/stable/tutorials/2d/using_tilemaps.html#handling-tile-connections-automatically-using-terrains)。

## 在其他地图新增河流

1. 在战场 **Rivers** 节点下实例化 **`scenes/effects/river_tilemap.tscn`**，重命名为你想要的名字。
2. 选中这个实例的根节点，用底部 TileMap 的地形画刷绘制。这是空河流层，直接画就可以。
3. **Settings** 配置水位与外观；每个河流层都可以引用不同资源。
4. **Weather Path** 默认 `../../RainWeather`，适用于 `战场/Rivers/河流层`。放在其他位置时，改为同一战场 RainWeather 的相对路径；独立场景可留空。

也可以新建 TileMapLayer，指定 `data/water/river_tileset.tres`，并挂载 `scripts/world/river_tilemap.gd`。只指定 TileSet 会显示静态图块预览，挂载脚本后才有动态水位和流水。

建议为河流使用独立图层。默认 **Z Index = -14**，处于地面之上、单位之下。脚本自动设置 **Self Modulate** 的 Alpha 为 0，用内部水面显示动态效果；这个设置不影响 TileSet 画刷面板，也不要手动恢复 Alpha，否则会叠画静态预览。

内部水面依据当前已绘制图块生成，不保存额外布局，不出现在普通场景树中。绘制、擦除或移动图层后，会更新水面和关联天气遮罩；运行时直接修改原生 cells 最迟约 0.25 秒刷新，需要立刻显示时调用 `rebuild()`。

## 配置水位和外观

选中河流 TileMapLayer，在检查器展开 **Settings**。

| 参数 | 配置方式 |
| --- | --- |
| Water Level | `0~1`；默认 `0.66`。0 完全干涸，河床仍保留；提高水位会向河岸扩展 |
| Tide Enabled / Amplitude / Period | 开启自动涨退水；振幅与周期秒数 |
| Flow Velocity | 本地像素/秒；默认 `(18, 4)`，`(0, 0)` 冻结流水、焦散和岸线动画 |
| Shallow / Deep Color | 浅水、深水颜色 |
| Shallow / Deep Opacity | 降低数值可显示更多水下河床 |
| Foam Width / Color | 水边亮线宽度和颜色；宽度 0 隐藏亮线 |
| Caustics Strength | 水下亮纹强度；0 关闭 |
| Refraction | 折射强度；0 关闭 |
| Bank Slope | 河岸到低河床的距离；越大浅滩越宽 |
| Bed Texture / Scale | 可选无缝河床贴图及平铺尺寸；为空时生成碎石细节 |
| Bed Color / Bank Color | 程序化河床与高岸颜色 |
| Pixel Size | 风格化像素大小，默认 2 |
| Height Resolution | 整个河流层高度图的最长边上限，默认 512；较大布局可提高到 1024，或分成多个河流层 |
| Reflection Opacity | 物体倒影强度；需要连接并启用 RainWeather 的倒影 |

只修改这一层时，先在 Settings 资源菜单选择 **Make Unique / 独立化**，避免其他引用相同 `.tres` 的图层一起改变。运行时会自动复制设置，不污染原始资源。

已有 `river_default.tres`、`river_flood.tres`、`river_dry.tres` 可作常态、涨水、干涸预设。

## 单独配置某一格的水位

选中河流层，在 **Cell Water Levels** 字典中添加条目：

- **Key** 类型为 `Vector2i`，填写 TileMap 格子坐标，例如 `(4, 6)`。
- **Value** 为 `float`，填写 `0~1`，例如 `0.25`。
- 没有条目的格子跟随 Settings 的水位和潮汐；删除条目即可恢复跟随。

这是固定的单格覆盖：设置为 0 的格子保持干涸，其他格子仍可涨水。格子坐标可以在 TileMap 编辑器指向对应格子时查看；代码中也可用 `local_to_map(to_local(世界位置))` 获取。

不同区域需要独立流速或独立潮汐时，用多个 RiverTileMap 图层，并各自指定 Settings。

## 关卡资源覆盖

`data/levels/level_001.tres` 的 **河流 → River Settings** 可以统一覆盖本关各个河流层的外观配置。为空时使用场景中各层自己的 Settings。

关卡配置不会修改你绘制的 cells，也不会清除 Cell Water Levels。**F5** 进入游戏会读取关卡资源；**F6** 单独运行场景只使用场景自己的设置。现有雨天和雪天配置仍由关卡天气资源控制。

## 运行中绘制和控制

```gdscript
var river := $Rivers/River as RiverTileMap

# 画一段会自动连接的细河。Terrain Set 0 = 河道；1 = 宽水域。
var cells: Array[Vector2i] = [Vector2i(3, 6), Vector2i(4, 6), Vector2i(4, 5)]
river.set_cells_terrain_connect(cells, 0, 0, false)
river.rebuild()

# 擦除一格；使用地形连接 API 能同时重算相邻岸边。
river.set_cells_terrain_connect([Vector2i(4, 5)], 0, -1, false)
river.rebuild()

# 整层两秒涨水；跟随游戏暂停。
river.settings.tide_enabled = false
river.set_water_level(0.9, 2.0)

# 单格水位，不影响其他格子。
river.set_cell_water_level(Vector2i(4, 6), 0.25)
river.clear_cell_water_level(Vector2i(4, 6))

# 改外观后应用。
river.settings.flow_velocity = Vector2(35, 0)
river.apply_settings()

# 切换预设，不改变布局。
river.configure(load("res://data/water/river_flood.tres"))

# 世界坐标干湿查询，用于脚步波纹。
var wet := river.is_water_point(unit.global_position)
```

## 更换图块素材

TileSet 位于 **`data/water/river_tileset.tres`**。配套图集在 **`assets/tilemap/river/`**，包含预览图与同布局的灰度高度图：黑色低、白色高，Alpha 0 表示没有河床。

RiverTileMap 读取 TileSet 的 `river_height_atlases` 元数据，按 Source ID 找到高度图；读取图块的 `river_tile` 自定义数据确认它参与水面。水位按高度阈值裁切，所有格子共享连续水纹坐标，避免每格重启动画。

**Settings → Height Texture** 属于原 Polygon2D 版本；TileMap 版本使用配套高度图集。替换素材时请保持预览图和高度图的位置、尺寸对应，保留 Terrain peering bits 和 `river_tile` 标记。首次使用不需要调整这些数据。

素材生成工具：`tools/water_tiles/build_river_atlases.py` 与 `build_river_tileset.gd`。`build_river_examples.tscn` 是手动重建示例的工具，运行会覆盖示例布局，正常游戏不会调用。
