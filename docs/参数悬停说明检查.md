# 参数悬停说明检查

检查日期：2026-10-10。

已检查项目的 168 个 GDScript 脚本，并逐项核对各配置工具的输入入口。41 个脚本包含 319 项业务导出参数，现已全部带有中文悬停说明；本次新增 275 项说明，完善 8 项已有说明。上一轮补充的雪天参数说明继续保留。

说明依据实际读取和结算逻辑填写，包含参数用途、单位、概率表示方式、正负方向、关联参数与生效条件。例如单位闪避率按 0～1 填写，胜利奖励掉落概率按 0～100 填写；技能命中帧从 0 开始。当前不再生效的兼容字段，以及仅部分效果类型使用的字段，也标明了实际情况。

同时补充了配置入口的提示：

- **游戏配置**：表头、可编辑格、只读关联资源和新增行列的输入项。
- **数据表格编辑器**：表格、详情字段名及输入控件，支持继承参数说明。
- **事件工坊、波次编辑器、地图工坊**：资源参数和工具专用参数。
- **批量特效导入器**：帧切分、动画命名、播放和输出参数。
- **网页配置合集**：表头、可编辑格及只读关联资源；已刷新 `docs/game_config_catalog.html`。
- **独立网页地图编辑器**：49 个可编辑参数及其标签。

本检查统计业务脚本的可见导出参数，不重复维护 Godot 自带属性的引擎文档。维护脚本、测试夹具和由天气系统自动传入着色器的内部渲染数据不作为策划配置入口。

## 查看方式

在 Godot 检查器中，把鼠标停在参数名称上即可查看说明。在配置表或工坊中，把鼠标停在字段名或输入控件上查看。

如果已打开的检查器仍显示旧说明，保存脚本后重新选择资源；游戏配置面板可点击“重读”，网页工具可重新读取配置或刷新页面。

## 后续维护

资源和场景脚本在 `@export` 声明的紧邻上一行使用 `## 中文说明`，多行说明连续使用 `##`。普通 `#` 注释不会成为检查器参数说明。

`addons/shared/script_property_help.gd` 统一读取脚本及其基类的文档，并同步给原生配置工具。配置合集新增字段时，填写的说明会以 `##` 写入资源脚本，供检查器和配置表共同使用。
