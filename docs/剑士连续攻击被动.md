# 剑士：愈战愈勇

> 此页记录已替换的旧特性。剑士当前使用[七伤与吹风三连击](剑士七伤与吹风三连击.md)。旧技能资源作为通用可选配置保留，已不在正式剑士技能列表中；以下为历史实现说明。

现有 `swords_man`（剑士）增加常驻被动，未强化与强化一次时均生效。

每次成功命中同一敌人后攻击力增加 1，下一击生效。三连击、六连刺的各次命中分别计数，切换主动技能但仍攻击同一敌人时继续累计。增益没有层数上限，伤害沿用各技能倍率、防御与战术效果规则。

选中另一个敌人时立即清零，新目标的第一击使用没有连击加成的攻击力。普通攻击动画结束、技能冷却或短暂眩晕不会误清零；目标死亡、退场、变为友军，以及剑士死亡、退场或战斗结束都会清除。闪避、友军拒绝命中和毒、区域直接伤害不计数。

在 **游戏配置 → 技能配置 → 剑士 → 愈战愈勇** 中调整「每次命中攻击加成」；资源为 `data/skills/swords_man_consecutive_attack.tres`。默认解锁强化等级为 `[0,1]`，如为剑士配置更多强化等级，可在此数组中增加对应等级。

卡牌说明与单位详情读取技能配置。战斗状态显示当前次数、攻击加成与目标。每名剑士独立记录，原牌、共享资源、复制品和重新部署的单位不会继承临时层数；连击与庇护、狂化组合时分别撤销、重算贡献。

验证入口：`python tools/maintenance/run_checks.py --checks consecutive-attack game-config-editor`，覆盖正式部署、实际普攻与连击动画、换目标首击、闪避与效果伤害、目标死亡、复制收回、强化等级、独立测试场及数值配置。
