# 事件工坊

Godot 顶部增加「事件工坊」页签，插件已经在项目设置中启用。打开中的编辑器如果尚未显示新页签，重新打开项目即可。

工坊会占满主编辑区的可用高度，左侧已配置事件列表使用按钮下方的剩余空间。拖动列表与配置区、配置区与预览之间的竖向分隔条，可调整三栏宽度；配置区优先获得较宽的编辑空间，长表单独立滚动。

## 制作事件

1. 在左侧选择「新建随机遗物事件」「新建随机药水事件」或「新建两组选牌事件」。
2. 填写唯一编号、标题、事件描述、奖励选项、离开选项及领取后的叙事。
3. 插图填写项目图片路径，例如 `res://assets/ui/events/relic_ruins.svg`。留空显示默认插图。
4. 勾选可抽取的奖励资源。全部不勾选时使用项目对应目录的全部有效资源。
5. 保存到 `data/events/事件编号.tres`。编号需要字母、数字、下划线或短横线。
6. 右侧显示实际事件布局；「试玩当前事件」打开实际游戏界面，支持选牌和结算，但不会向正式本局发奖。

支持撤销、重做与恢复草稿。切换未保存事件时会提示。保存前检查配置，磁盘文件被其他工具修改时拒绝覆盖；改成新编号可以另存为。

## 事件模板

- **随机遗物**：从遗物池随机获得一件。排除已拥有的遗物和已停用的旧主堡防御遗物。没有可获得的遗物时显示原因，仍然可以离开。
- **随机药水**：从药水池随机获得一瓶。同种药水可以拥有多瓶，进入现有背包系统。
- **两组选牌**：第一排五张兵种卡选一张，第二排五张效果卡选一张，共获得两张卡。两组各需要至少五种不同的有效资源。确认前可以重新选择，两组都选好才能领奖。
- **篝火**：「休憩整备」按最大生命百分比回复；「训练」选择已有兵种卡并分配攻击 / 防御能力点；「强化」选择已有非兵种卡。每次只能选择一项。回复比例在工坊配置，能力点与可强化次数在游戏配置表配置。详见 [篝火配置说明](篝火配置说明.md)。

候选在一次事件中固定，查看地图/牌组后返回不会重抽。领取只执行一次，结果界面点击「继续前进」后才完成地图地点。离开不获得奖励。

## 绑定地图

1. 打开「地图工坊」，选择一个事件节点。
2. 在属性区的「事件工坊已配置事件」列表选择已保存事件。事件和篝火节点都可绑定。
3. 事件工坊保存后，切回地图工坊会自动刷新列表和已绑定节点的内容；也可点击「刷新事件列表」。
4. 保存/导出地图，在主菜单导入后开始新局。

绑定模式下描述、选项、插图和奖励池来自事件工坊，节点中的事件控件只读。「在检查器打开绑定事件」可查看资源。同步变化可撤销，随地图保存；工坊标题变化会同步到原有事件标题，自定义地点名称会保留。切回「节点内编辑」会保留最新快照与奖励字段；资源缺失时仍可保留已有快照。旧地图中的金币/回血事件继续可用。

内置十层路线已加入三种事件。玩家此前导入的路线会继续使用原节点配置，需要在地图工坊绑定后重新导入。开局后使用事件内容快照，编辑工坊资源不会改变已经开始的地图。

## 扩展位置

- 配方：`data/events/event_definition.gd`
- 效果注册、奖励池检查与发奖：`scripts/events/event_rewards.gd`
- 一次事件的候选及结算状态：`scripts/events/event_session.gd`
- 事件界面：`scripts/map/event_panel.gd`
- 编辑器：`addons/event_editor/`

后续增加事件效果时，在配方模板和奖励注册点添加类型，并补充配置校验与对应表单，旧资源保持可用。

## 验证

`tests/event_system_test.gd` 检查三种奖励、候选固定、两组约束、重复领奖保护、预览隔离、表单编辑与草稿恢复；原地图编辑器及本局场景测试用于兼容性验证。`tests/event_editor_layout_test.gd` 检查主屏幕高度分配、拖动两条分隔条、宽窄窗口的列宽及长表单滚动，可通过维护检查命令的 `--checks event-editor-layout` 执行。

本次另外补充「行军戒指」「旅人护符」「储能水晶」三件遗物，使用已有的抽牌奖励、生命上限和最大能量效果。当前开局配方已赠送旧遗物，新遗物保证默认开局也有可掉落对象。
