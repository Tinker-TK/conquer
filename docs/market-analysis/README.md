# conquer 立项数据分析（2026-10-19）

针对 `conquer`（卡牌构筑 × 小队自走棋）的同类游戏与市场盘子分析。
方法参考 B 站 [《独立游戏立项前必须要看！否则就白做了》](https://www.bilibili.com/video/BV1MjpX6QEVY) 后半段的立项数据流程，拆成 6 步并固定口径。

> 核心判断：`conquer` 的核心是**卡牌构筑 + 自走棋战斗**；四层地形是战场战术层，不是玩法核心，也不是本报告用来讲差异的卖点。

## 一句话结论

**有条件立项。** 按 `$19.99 / ¥58`、24 个月 / `¥388,000` 预算推进；标准回本线 **14,866 份**，位于成熟样本 **P66**（约前 34%）。目标 **2 万份 / 500 条评论 / 净收入 ¥52 万**。

三个 Gate：

1. **M3**：100 人测试，≥60% 能说出「这副牌为什么赢」；demo 中位时长 ≥30 分钟。
2. **M9**：Next Fest 后愿望单 ≥8,000，且周增 ≥300。
3. **M12**：发售前愿望单 ≥15,000；否则延期或降价，不「先发了再说」。

## 定位要点

- 同类的核心组合并不稀缺：The Last Flame、Hadean Tactics、9 Kings、Monster Train 都在做「卡牌/单位 + 自动战斗」。
- 真正要比的是**卡牌对战场的干预深度**：征召、强化、能力牌是否直接改变单位、站位与战场规则，而不是只加数值。
- 第二个指标是 **Build 复玩性**：61 张卡、67 件遗物、41 瓶药水、24 个事件能否撑出足够多的流派。
- 四层地形是战术纵深，不是品类差异；它可以放大 Build，但不能替代 Build。

## 数据口径

- **样本池**：Gamalytic Steam 游戏库 API，标签 `Roguelike Deckbuilder` 全集 **949 款**；剔除免费、未发售、价格 < $4.99 后 **766 款**。
- **成熟样本**：2021–2024 年发售的 **250 款**付费产品，用于分位、命中率、回本判断；2025–2026 只用于观察供给与竞争。
- **价格 / 发售**：Steam Store API（`cc=cn`，简中），取中国区原价与发售日。
- **评论**：Steam appreviews API，全部语言、全部购买类型；**140 款**随机样本用于评论→销量校准。
- **销量**：Gamalytic `copiesSold` 模型估算，单款误差可能 ±30–50%，用于分位与量级判断，不作财务承诺。
- **净收入**：`销量 × 售价 × 0.75（平均实收）× 0.60（开发者分成）`，即 0.45。
- **评论→销量**：`copies = 10^(0.914 + 1.265 × log10(reviews))`，R² = 0.940；仅用于设定评论 KPI。
- **深度对标 48 款**：人工挑选的「跑出来的产品」，存在幸存者偏差；成功率一律以成熟样本为准。

## 数据文件

`data/` 内保留了生成报告所需的中间数据，便于复算：

- `gama2_Roguelike_Deckbuilder.json`、`gama2_Auto_Battler.json`：Gamalytic 抓取原始记录
- `details/`：48 款对标的 Steam 商店 / 评论 / SteamSpy 原始响应
- `comps.csv`：48 款对标的扁平表
- `review_sample.json`：140 款评论校准样本
- `report_data.json`：报告与工作簿共用的汇总数据
