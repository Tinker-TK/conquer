# 卡牌动效

战斗界面已接入参考视频中的浅圆弧手牌和青绿色可用光效，沿用项目现有卡面美术。

- 抽牌：从左下抽牌堆逐张缩放飞入，剩余手牌平滑让位。
- 弃牌：未使用牌错开时间，沿弧线缩小并收进右下弃牌堆。
- 使用：拖动时隐藏来源卡面，成功后卡面冲向真实世界落点；征召牌在落点消散，强化和能力牌继续飞向弃牌堆，消耗牌飞向消耗牌堆。
- 悬停：卡面抬高、放大、扶正并置顶，邻牌稍微让开；鼠标移开后恢复。
- 拖放失败：能量、目标或部署位置不满足规则时，同一张原牌从鼠标位置飞回手牌，不扣费。
- 可用提示：只有出牌阶段且当前能量支付得起实例费用的牌发光；能量不足立即熄灭。零费牌在零能量时仍可发光，单位退场后累计增加的费用也计入判断。是否存在有效施放目标仍由正式出牌入口验证。

手牌变化保留已有卡面，不再重建整手。动画不延迟战斗结算；连续抽牌、弃牌和下一轮发牌可以重叠。牌堆查看仍使用原来的只读暂停面板。

## 调整外观与节奏

打开 `scenes/ui/card_ui.tscn`，选择 `Hand`，在 Inspector 中调整 `hand_presenter.gd` 的导出属性，无需接线。

| 属性 | 默认值 | 作用 |
| --- | --- | --- |
| Hand Scale | 0.74 | 常态卡面大小 |
| Card Spacing | 158 | 少量手牌的中心间距，牌多时自动缩小 |
| Max Hand Width | 1180 | 最左到最右卡牌中心的最大跨度 |
| Arc Radius | 1550 | 越小圆弧越明显 |
| Max Fan Angle | 18° | 两边最大倾斜角 |
| Bottom Inset | 137 | 中间卡牌中心距窗口底部的距离 |
| Hover Scale / Lift | 1.04 / 132 | 悬停大小与抬高距离 |
| Draw Duration / Stagger | 0.42 / 0.085 秒 | 飞入时间与逐张间隔 |
| Discard Duration / Stagger | 0.34 / 0.045 秒 | 飞向牌堆时间与逐张间隔 |
| Play Duration | 0.20 秒 | 使用牌冲向落点的时间 |

光效颜色和外围柔光由 `shaders/card_playable_glow.gdshader` 控制，不需要开启全局 Bloom。

## 验证

Godot 4.6.2 的动画专项验收：

```powershell
& 'D:/Godot4/Godot_v4.6.2-stable_win64_console.exe' --headless --path . --fixed-fps 60 --script tests/card_framework_test_runner.gd -- --card-motion-regression
```

将最后一个参数改为 `--card-motion-preview` 并移除 `--headless` 可保存实际渲染的圆弧、悬停和十二张手牌截图到 `.maintenance/card-motion-*.png`。

专项测试覆盖原卡面复用、零费光效、点击拖动命中、失败回弹、相机变换后的落点、弃牌与消耗去向、随机出牌及动画重叠清理。合成视口事件不会移动操作系统鼠标，因此落点验证向正式接收区传入同一个事件坐标，再发送松开事件结束拖放。
