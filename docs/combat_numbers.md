# 战斗跳字

伤害、治疗与护盾的显示统一通过 `scripts/effects/combat_numbers.gd`，颜色在 `COLORS` 中配置。

| 来源 | 颜色 | 示例 |
| --- | --- | --- |
| 普通近战、普通射击、剑矢 | 白色 | 12 |
| 技能、反击、爆炸、龙卷风 | 金色 | 24 |
| 流血 | 红色 | 4 |
| 中毒 | 紫色 | 6 |
| 火焰区域、火焰药水 | 橙色 | 8 |
| 闪电链、闪电药水、雷云 | 黄色 | 16 |
| 七伤的额外真实伤害 | 粉紫色 | 30 |
| 生命恢复、吸血、治疗 | 绿色 | +20 |
| 新增护盾、溢出治疗转盾 | 蓝色 | +15 |

伤害显示本次实际扣除的生命与护盾之和，只跳一次数字；致死伤害按剩余生命与护盾封顶。治疗只显示实际恢复值；例如缺5点血时接受14点溢出转盾治疗，会分别显示绿色“+5”和蓝色“+9”。无效治疗、禁疗、闪避及零变化不生成数字。

伤害、回血与新增护盾数字统一从人物身体中心弹出、上浮并淡出，数值变化时确定世界坐标，之后不跟随人物移动。连续数值横向散开，避免起点被推到头顶。同一单位的连续数字按确定性位置避让，不使用战斗全局随机数。数字挂在战场下，致死一击不会随单位退场提前消失；动画使用固定物理步，遵循暂停和战斗倍速。每个战场最多192条活动数字，0.95秒后释放，空闲时停止处理。

技能通过 `SkillBase.combat_number_kind()` 区分普通攻击与技能，兼容旧资源未保存普攻标记的情况。延迟伤害在发射时保存来源，命中时传给 `UnitBase.get_hurt()` 的末尾参数。持续伤害通过 `take_effect_damage()` 的第三个参数指定来源。

回归：`tools/maintenance/run_checks.py --checks combat-numbers`。

实机截图：Godot 运行 `tests/card_framework_test_runner.gd -- --no-mcp-server --combat-numbers-preview`，输出到 `.maintenance/combat-numbers/`。
