# 冒险图鉴

游戏顶部「设置」或 **Esc** → **图鉴**。暂停菜单为「继续 / 设置 / 图鉴 / 保存并退出」。图鉴退出后回到暂停菜单，再次继续才恢复游戏；从已经暂停的卡组等界面打开时保留原暂停状态。

## 浏览

书本右下角悬挂五枚带文字的书签：**遗物、己方单位、敌方单位、药水、事件**。点击书签通过翻页切换分类；当前分类书签上提并提亮。翻页沿用独立实验中的纸面弯曲、空白过渡页、整本书挤压、平移、缩放和落页回弹。

- 书本铺满页头下方的主要区域，每张纸页放 **3 个词条**，左右展开共 6 个；末页不足时留空。每个词条的图片、属性、技能放在一起，同一条目只出现一次。
- 点击左页向前翻、点击右页向后翻；「上一页 / 下一页」位于纸面下角，也支持拖动与 **← / →**。书外不显示页码、按钮或底部提示。
- 长技能、事件选项等在各自词条内用滚轮阅读；固定保留名称与基础属性，不复制词条生成续页。正文使用 20 像素字体、840 × 740 纸面纹理与高分辨率书本绘制，避免低清文字拉伸。
- 单位技能来自实际配置，去掉征召卡中重复的技能摘要与正文前重复的技能名；同名强化版本标明生效等级。骑士上场抽牌和士兵剑矢等额外能力单独保留。
- 顶部搜索按当前分类的名称、属性、说明与技能内容筛选；「目录」定位到包含该条目的书页，跳转同样播放翻页动画。
- **Esc** 优先关闭目录，再返回设置。翻页过程中退出会清理未完成的跳转，不会改动游戏数据。

主界面移除了旧「遗物图鉴」按钮和「药水带 n/n · 右键丢弃」文字；顶部库存、图标悬停、药水使用与丢弃功能继续保留。

## 内容来源

| 分类 | 当前条目 | 来源与展示 |
| --- | ---: | --- |
| 遗物 | 66 | 正式有效遗物池；名称、图标、品质、流派、完整效果及触发限制 |
| 己方单位 | 15 | `data/units` 与 `data/event_recruits` 中的 `team_a`；基础属性、费用、技能及强化生效等级 |
| 敌方单位 | 33 | 单位配置中的 `team_b`；基础属性、等级与技能 |
| 药水 | 40 | 正式有效药水池；品质、效果、目标方式及使用规则 |
| 事件 | 24 | 事件配方；插图、剧情、全部选项、效果摘要及结果文案 |

分类数量由配置计算，不在界面写死。遗物显示已有的发现记录，但全部条目均可阅读；查看不会增加发现记录。敌方缺少卡面时，只读取打包场景中的待机图帧作为肖像，不实例化战斗单位。图鉴不领取物品、不执行事件选项、不训练或召唤单位，也不修改征途存档。

## 维护与验证

- 正式界面：`scenes/ui/encyclopedia.tscn`、`scripts/ui/encyclopedia.gd`。
- 数据与分页：`scripts/ui/encyclopedia_catalog.gd`。
- 纸面绘制：`scripts/ui/encyclopedia_page.gd`。
- F6 预览：`examples/scenes/encyclopedia_demo.tscn`，不开始新征途。

只为当前和相邻展开页创建最多 6 个纸面视口，分类跳转短暂多保留一对。关闭图鉴后停止书本绘制。满版动画根据卷曲页与书签的范围调整整体取景，保留挤压、平移、缩放，同时避免放大回弹遮住页头或把纸面裁掉。独立像素书本实验仍使用原来的默认分辨率、比例和动画。

```text
python tools/maintenance/run_checks.py --checks encyclopedia settings-pause settings-controls items-ui relics potion-catalog --label encyclopedia
python tools/maintenance/run_checks.py --graphical --checks encyclopedia --label encyclopedia-visual
```

图形检查使用真实顶部入口、分类书签、左右纸面点击与页内按钮，覆盖每页三条、不重复、长文完整性和滚动、满版动画边界、搜索、目录、阵营分类、图片读取、有限缓存、退出清理、嵌套暂停及只读状态。截图位于 `.maintenance/encyclopedia/`。
