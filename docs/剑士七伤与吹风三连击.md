# 剑士：七伤与吹风三连击

剑士原「愈战愈勇」攻击成长替换为七次伤害计数；普通攻击、六连刺保留，三连击按下列流程改造。

| 效果 | 基础 | 强化一次 |
| --- | --- | --- |
| 七伤 | 每造成7次攻击伤害，对第7次受伤目标追加最大生命 `(3+x)%` 的真实伤害，计数清零。 | 基数改为5，即 `(5+x)%`。 |
| 三连击 | 后撤300像素，开始原三连击动画。第3帧向前发一道风，并前突300；第6、12帧分别造成原70%近战伤害。 | 后撤300，三个伤害帧依次发上30°、下30°、正前方的风；第三道风后再前突300，没有额外近战帧。 |
| 吹风 | 每道风对路径上每名敌人造成160%攻击力伤害，同一道风对同一敌人只命中一次。 | 相同；不同风分别结算伤害和七伤计数。 |

升级三连击的顺序已由用户确认：三个伤害帧依次释放三道风，最后前突。技能保留原3秒冷却，后撤与前突归属于一次施法。方向在开始时锁定，上下30°相对该方向；面向左侧时镜像角度。被墙或本层地表边界阻挡时位移提前停止，不穿墙或越过地表缺口。

`x` 是出场时原征召牌的当前费用，即牌的基础费用加本场退场加费。战友减免、免费随机打出以及临时0费都不改变x。出场时保存费用快照；例如原费用3、退场加费2、实际0费召唤，x仍为5，基础真伤为8%，强化为10%。直接在 `monster_test` 生成的剑士使用本身配置费用。复制品保留出场原牌费用，但独立从0开始计数；重新部署使用该原牌当时的新费用。

普通攻击、三连击近战、六连刺各伤害帧、吹风命中的每名敌人分别计数；切换目标不清零。闪避、拒绝友军伤害、完全由护盾吸收而未扣生命的攻击不计数，毒／流血／区域直接效果伤害也不计数。第7击原攻击已经致死时仍清零，额外真伤不在死者身上重新结算。真伤按目标最大生命乘以比例向下取整，至少1点，忽略防御与伤害倍率，仍遵守护盾规则；它不作为新攻击递归计数或再次触发反击、攻击上毒。

每个剑士独立保存进度。死亡、交锋清理、技能等级失效或战斗结束时清空，不写入共享资源、训练或存档。状态显示当前次数、x和实际比例；卡面显示按本张牌费用计算后的实际真伤比例。

特效先匹配实验室原条目并复用：后撤为 `holy_step`（神圣 · Step）的金色残影、HolyWarp及原视觉配方；吹风为 `lord_of_the_storm`（Lord · of · the · 风暴）的原 `MediumTornadoProjectile` 素材；前突为 `dash`（冲刺）的原残影配方。演示角色的移动和原伤害逻辑不控制实战单位。已经释放的风继续飞行；动作受眩晕、死亡或阶段切换打断后不再释放后续风和位移，冷却保留。

默认后撤0.15秒，前突0.2秒；吹风速度360、距离760、碰撞半径28。所有参数可在「游戏配置 → 技能配置」中调整。基础／强化三连击分别为 `swords_man_muti_attack.tres`、`swords_man_wind_combo_upgraded.tres`；七伤分别为 `swords_man_seventh_strike.tres`、`swords_man_seventh_strike_upgraded.tres`，各等级只装配对应版本。

回归：`python tools/maintenance/run_checks.py --checks sword-wind card-cost card-description`。图形运行追加 `--sword-wind-regression --capture`，实际截图位于 `.maintenance/sword-wind/holy-step.png`、`base-wind.png`、`upgraded-winds.png`。旧通用连续命中技能保留显式配置回归 `consecutive-attack`，不再装配给正式剑士。
