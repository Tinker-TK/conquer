# 圣殿骑士强化：庇护光环

> 此页记录已替换的旧效果。圣殿骑士当前使用[嘲讽攻击与反击破甲](圣殿骑士嘲讽攻击.md)，原光环场景用于嘲讽期间的视觉。旧技能资源作为通用光环配置保留，但已不在圣殿骑士正式技能列表中；以下为历史实现说明。

圣殿骑士卡强化一次后解锁驻场技能「庇护光环」。圣殿骑士存活时，光环内的己方单位攻击力提升2；默认包含圣殿骑士自身。同类光环重叠取最高加成，不重复叠加。离开范围、来源死亡、收回或退场后撤销；复制品在自己的位置重新计算庇护，不永久复制攻击加成。准备阶段和交锋阶段均生效，眩晕不撤销存活来源的光环。

打开 Godot 的「游戏配置 → 技能配置」，搜索「庇护光环」或「圣殿骑士」。资源为 `data/skills/knight_templar_protection_aura.tres`，已加入 `data/units/knight_templar.tres` 的技能列表。可以配置：

- **解锁强化等级**：默认 `[1]`，仅强化一次生效；需要强化两次仍生效时改为 `[1,2]`，沿用现有精确等级规则。
- **光环半径 / aura_radius**：默认200，单位为世界像素。特效环的半径同步使用此值。
- **庇护攻击加成 / aura_attack_bonus**：默认2。
- **光环包含自身 / aura_include_caster**：默认启用。
- **驻场光环特效 / aura_effect**：默认 `assets/effect/godot_vfx_library/effects/magic/magic_aura.tscn`，即截图中 `vfx_demo` 的「魔法光环」。可在资源 Inspector 替换场景。

更改后保存并应用，再重新运行场景。该技能是驻场被动，不使用施法动画、命中帧、攻击倍率或冷却；这些继承字段用于其他主动技能。光环不会抢占原有攻击和反击动作。卡面强化说明、单位技能详情、庇护状态提示均按实际配置显示。

正式战场复用现有抽牌、强化和存档流程。独立验证可打开 `scenes/testing/monster_test.tscn` 按F6，点击圣殿骑士的「强化1次」，添加其他己方单位，观察范围内的庇护状态。`--checks protection-aura` 覆盖真实训练部署、边界、敌我筛选、重叠、死亡/收回、范围配置、狂化组合、复制、存档和测试场清空；图形模式添加 `--protection-aura-preview` 导出 `.maintenance/protection-aura-preview.png`。
