# 回合扣血特效

战斗结束后，胜方幸存单位依次发射带拖尾的光弹，命中败方真实血量栏时扣除该单位的结算伤害。稍大的回合光弹随后命中，扣除回合基础伤害。血量栏闪光、冲击环、伤害数字及总扣血提示全部播放完，才清场、回收征召牌、增加 Round、回复能量、抽牌并提前刷新下一轮敌阵。正常结算约 1.9～2.3 秒。

己方胜利使用青色光弹，敌方胜利使用红色光弹。玩家扣血落在常驻顶部生命栏，敌方扣血落在战斗血条；F6 单独运行战场时使用临时玩家生命牌，数值仍直接读取 RunManager。平局显示短暂提示，双方不扣血。致命伤害也先完成全部特效，再显示原有胜负面板。

结算期间显示“结算中”，禁止出牌、开打和镜头移动。查看地图或卡组会暂停特效，返回后继续；地图查看时结算层隐藏。离开或强制结束战斗时取消特效，旧命中回调不会扣血或推进回合。

伤害公式保持“回合数 + 全部存活单位 hp_damage_value”，回合末毒和死亡爆炸先结算，光弹使用最终幸存者快照。回合管理器仍是唯一伤害入口，玩家 HP 仍由 RunManager 保管。

## 调整节奏

打开 `scenes/effects/round_damage_effect.tscn`，选择根节点，在 Inspector 调整：

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| Windup Duration | 0.24 秒 | 光弹发射前的蓄力 |
| Flight Duration | 0.62 秒 | 单位光弹的飞行时长；回合光弹额外 0.1 秒 |
| Aftermath Duration | 0.72 秒 | 最后命中后的收尾；最少 0.7 秒，保证血条动画与数字淡出完成 |

光弹错开发射最多累计半秒，单位多时也不会长时间等待。无需新增 Autoload、手动接信号或补战场节点。
