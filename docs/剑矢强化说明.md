# 士兵远近普攻：剑矢

己方士兵未强化时即可使用弓箭和近战。首次强化需要在斩击、飞弹中选择一个分支；飞弹保留远近普攻，斩击放弃弓箭。详见 [士兵斩击与飞弹说明](士兵斩击与飞弹说明.md)。

- 普攻射程300，复用弓箭手普通射击的投射物、贴图和弹道。
- 目标进入原近战范围80时使用近战普攻；出箭帧之前近身也会切为近战。
- 射箭播放 `attack_03`，在帧索引7发箭；近战沿用原动作和命中帧。
- 远近攻击沿用原普攻倍率与同一个冷却计时器，切换不会重置冷却。
- 斩击分支仅保留80范围近战普攻，特殊斩击施法距离350。
- 飞弹分支保留300范围远近普攻，同时获得独立冷却的飞弹。

测试：`python tools/maintenance/run_checks.py --checks sword-arrow soldier-branches campfire monster-test`。
