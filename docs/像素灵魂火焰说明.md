# 像素灵魂火焰

参考：[让火焰烧起来《五星地牢》开发日志 04](https://www.bilibili.com/video/BV1vGaT6FEMB/)。按视频关键帧展示的“固定轮廓 → 向上流动的两层噪声 → 侵蚀 → 五色分层”重新实现，未使用视频中的源代码或素材。

## 打开预览

在 Godot 打开 `examples/scenes/pixel_flame_demo.tscn`，按 **F6**。左侧展示独立火焰和骷髅背焰，底部同时展示四种配色，右侧实时调参。

- **空格**：暂停 / 继续所有火焰与示范角色。
- **R**：恢复默认参数。
- **1–4**：切换青色灵魂火、橙火、毒焰、紫焰。
- 下拉框切换圆润 / 修长轮廓，以及完整效果、遮罩、两层噪声、热度分层。

正式游戏入口、单位资源、技能、战场和自动加载配置均未接入此效果。示范骷髅仅播放已有贴图中的动画，不创建实际单位，也不启动战斗或新一局。

## 独立资源

| 文件 | 用途 |
| --- | --- |
| `scenes/effects/pixel_flame.tscn` | 可独立实例化的 Node2D 火焰 |
| `scripts/effects/pixel_flame.gd` | 编辑器参数、本地动画时钟、独立材质 |
| `shaders/pixel_flame.gdshader` | 程序轮廓、双层噪声、侵蚀与五色着色 |
| `examples/scenes/pixel_flame_demo.tscn` | F6 预览入口 |
| `tests/pixel_flame_render_test.tscn` | GPU 渲染与预览交互检查 |

效果原点在底部，默认画布 64 × 80；画布包含透明留白，实际火焰小于画布。默认灵魂火为圆润轮廓，`Shape` 可切换修长轮廓。调整根节点 `Scale` 可整体放大；`Flame Size` 改画布大小；`Pixel Size` 控制局部像素颗粒，1 表示一个本地像素。

`Intensity` 为 0 时完全透明，0–1.5 改变火焰大小和透明度。`Flow Speed` 控制上升速度，0 冻结画面；`Distortion` 调整火苗摆动；`Erosion` 调整边缘破碎；`Wind` 为 -1 到 1；`Animation Fps` 默认 18，保留像素动画的离散帧节奏。火星默认开启，柔和光晕默认关闭。光晕是效果画布内的透明着色，不会照亮其他对象。

`Palette Preset` 提供四套颜色；启用 `Use Custom Palette` 后，`Custom Palette` 应包含从暗到亮的五个颜色。可选 `Shape Mask` 支持透明背景的白色或灰度轮廓贴图，以红通道 × alpha 作为遮罩；不设置时无需外部纹理。

每个实例拥有独立材质和本地时钟。`Playing = false` 暂停；`restart()` 重播；`seek(seconds)` 指定时间。脚本在编辑器中也会预览。未来需要使用时，可自行实例化此场景并设位置、缩放与配色；本次未添加任何玩法调用。
