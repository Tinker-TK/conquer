# 雪天效果配置说明

已将参考视频 [《2D游戏中的雪天效果 DEV LOG.05》](https://www.bilibili.com/video/BV18DYt6mE24) 的制作思路接入当前 **Godot 4.6.2 / GDScript** 项目：随机像素雪花图集、远近两层飘雪、固定噪声生成的像素雪斑、随覆盖度堆积和融化，以及树木等静态精灵的覆雪。

## 马上查看

1. 打开 `examples/scenes/snow_weather_demo.tscn`，按 **F6**。右上按钮切换小雪、正常雪、暴雪；“停雪并逐渐融化”演示融雪，滑块手动设置积雪。示范树和士兵只存在于演示场景。
2. 按 **F5** 从主菜单进入新游戏，默认路线左侧起点对应 `level_001`，已开启正常雪。若使用自定义路线，进入引用 `data/levels/level_001.tres` 的节点查看。
3. 直接打开 `scenes/levels/battles/battle_001.tscn` 按 **F6** 也可看雪。这个场景只使用节点预设；从地图进入则读取关卡 `.tres` 的波次和天气设置。

看不到飘雪时，先确认当前关卡的 **Snow Weather Settings** 引用了启用的雪天预设，且 **Intensity > 0**。直接 F6 则检查场景的 **SnowWeather → Settings**。`level_001.tres` 和 `battle_001.tscn` 当前均明确引用 `snow_default.tres`；资源引用为空或指向 `snow_disabled.tres` 会关闭雪花。修改磁盘配置后先停止正在运行的游戏，再重新运行。演示场景独立加载正常雪，不依赖正式关卡选择的天气。

## 给某个关卡配置雪天

在 Godot FileSystem 打开对应关卡资源，例如 `data/levels/level_001.tres`。展开 Inspector 的 **天气 → Snow Weather Settings**，将下面的预设拖入该槽。

| 预设 | 效果 |
| --- | --- |
| `data/weather/snow_light.tres` | 小雪，初始积雪 0.30，轻风 |
| `data/weather/snow_default.tres` | 正常雪，初始积雪 0.68，缓慢继续堆积 |
| `data/weather/snow_blizzard.tres` | 暴雪，初始积雪 0.88，更多雪花与更强风 |
| `data/weather/snow_disabled.tres` | 关闭雪天，隐藏地面和树木上的雪 |

**雪天启用时优先于雨天**，即使关卡的旧 **Weather Settings** 保留雨天预设，也会关闭雨滴、积水和雨天色调。切回雨天时将 **Snow Weather Settings** 改成 `snow_disabled.tres`，并在 **Weather Settings** 选择原有雨天资源；晴天再将 **Weather Settings** 改为 `weather_clear.tres`。

两个天气槽都为空时沿用战场节点设置。清空雪天槽且已有明确的雨天/晴天配置时，按原有雨天/晴天配置运行。第一战场的 SnowWeather 节点本身也引用了正常雪，因此要可靠关闭它，直接指定 `snow_disabled.tres`。

仅修改某一关：右键预设另存为新的 `.tres`，或在 Inspector 选择 **Make Unique / 独立化** 后另存为，再配置该关。直接修改共享预设会影响所有引用它的关卡。运行中的调参只改变资源副本，不写回文件。

## 主要参数

选中关卡的 **Snow Weather Settings** 资源，或战场的 **SnowWeather → Settings**。

| Inspector 参数 | 用途与建议 |
| --- | --- |
| `Enabled` | 总开关；关闭后雪花、地面积雪、树冠覆雪一起隐藏 |
| `Intensity` | 雪量 0～1；0 停止飘雪，原有积雪仍能逐渐融化 |
| `Atmosphere Tint` | 世界场景的冷色调；屏幕上的手牌和 HUD 保持原来的颜色 |
| `Snow Amount` | 两层雪花的总预算，正常雪 700；暴雪 1000；实际可见数量受雪量和视野影响 |
| `Fall Speed` | 下落速度，世界像素/秒，默认 70 |
| `Wind` | 水平风速，负值向左、正值向右，默认 -22 |
| `Flake Scale` | 三像素雪花的放大倍数，正常雪 2.4；缩放镜头仍保持清晰的雪花尺寸 |
| `Snow Opacity / Snow Color` | 飘落雪花的透明度和颜色 |
| `Ground Snow Enabled` | 是否绘制地面积雪，可关闭后只留飘雪和树冠雪 |
| `Initial Coverage` | 进入关卡时的积雪覆盖控制值；0 无雪，1 全覆盖；中间值控制噪声阈值，面积百分比随种子变化 |
| `Automatic Accumulation` | 自动堆积和融化；关闭后积雪保持固定，可用代码控制 |
| `Accumulation Rate` | 每秒覆盖度增加量 × 当前雪量；默认 0.012，例如雪量 0.65 时每秒增加约 0.0078 |
| `Melt Rate` | 雪量为零时每秒覆盖度减少量，默认 0.035；从全覆盖融尽约 29 秒 |
| `Patch Scale` | 雪斑的世界尺寸，默认 140；大值形成更大连片雪地 |
| `Pixel Size` | 雪斑边缘的像素网格，默认 3；调大更有颗粒感 |
| `Random Seed` | 雪斑布局种子；固定种子保证积雪不随时间漂移 |
| `Snow Tint / Snow Shadow` | 积雪亮色和阴影色 |
| `Ground Detail` | 保留原草地明暗的比例，默认 0.30，避免覆盖后只剩一片纯白 |
| `Scenery Snow Enabled` | 是否为 Level 下树木等静态精灵生成覆雪层 |
| `Scenery Coverage` | 物体覆雪强度，乘以当前地面积雪控制值 |
| `Scenery Snowline` | 精灵允许覆雪的高度范围，默认 0.8，树干底部保留原色 |
| `Max Scenery` | 覆雪精灵数量上限，默认 128 |

自动堆积达到 1 后保持全覆盖。停止降雪用 `Intensity = 0`；总开关 `Enabled = false` 会直接隐藏所有雪，不播放融化过程。战斗暂停、查看地图或牌组时，飘雪、堆积和融化一起暂停。

## 地形与树木

`SnowWeather` 已作为 `scenes/battle/battle_scene.tscn` 的子节点接入，所有继承战场都能使用它。独立战场可实例化 `scenes/effects/snow_weather.tscn`，加载启用的雪天预设，再设置来源路径：

- `Terrain Root Path`：地表 TileMapLayer 容器，默认 `../Level/NavigationRegion2D`。
- `Scenery Path`：树木等物体容器，默认 `../Level`。排除天空、TileMapLayer、UI 和 UnitBase，战斗单位保持原材质与受击闪白。
- `Rain Weather Path`：同战场 RainWeather 节点，默认 `../RainWeather`，用于互斥和共用场景色调。
- `Ground Terrain Set / Ground Terrain Id`：默认 0 / 0，对应当前草地 terrain。

地面积雪按图块**实际绘制像素**裁切，不使用导航多边形，因此不会覆盖天空洞、悬崖或空白，也不会因导航烘焙的边距而少一圈雪。新 TileSet 可添加 bool 自定义数据 `snow_ground`，地面 true、立面 false；其优先于 terrain 编号。未配置 `snow_ground` 时可沿用现有 `rain_ground`，最后才使用 terrain 编号。

四层战场会为 Layer01～Layer04 分别生成积雪遮罩，在本层地形之上、单位之下绘制，并自动跟随楼层系统的 Floor Z Stride。子瓦片层和附属楼梯沿用所属楼层。覆盖度、自动堆积、融化、地面积雪开关和雨雪切换同时作用于所有楼层；上层悬崖仍可遮住下层积雪。

不使用 TileMap 的场景可关闭 `Use Terrain Mask`，用 `Ground Rect` 指定矩形地面。地形或预设改动后重新运行，或调用 `apply_settings()` 刷新。

把树木场景放到 Level 下即可自动覆雪；覆雪会跟随原图集、朝向、可见性和遮挡透明度。若某个静态物体不应接雪，在节点的 Metadata 添加 `snow_exclude = true`。覆雪使用额外的显示层，不替换原精灵材质。

当前使用程序化覆雪，根据纹理明暗和朝上轮廓生成雪斑。如果某个道具需要精确到每根枝条的专用雪贴图，可另外制作美术覆雪图；当前系统的雪斑位置由程序计算。第一层河流绘制在本层积雪之上，桥面积雪按上层地表独立绘制；雪天不改变河流水位、冻结状态、导航或伤害规则。

## 运行中控制

```gdscript
var snow := $SnowWeather as SnowWeather

# 切换预设，自动关闭同战场的雨天。
snow.configure(load("res://data/weather/snow_blizzard.tres"))

# 用两秒过渡到大雪。
snow.set_snow_intensity(1.0, 2.0)

# 停雪，已有积雪按 Melt Rate 逐渐融化。
snow.set_snow_intensity(0.0, 1.0)

# 手动控制覆盖度：先关闭自动堆积，再用五秒铺满。
snow.settings.automatic_accumulation = false
snow.set_snow_cover(1.0, 5.0)

# 修改形状/颜色参数后统一刷新；刷新会恢复 Initial Coverage。
snow.settings.patch_scale = 200.0
snow.apply_settings()

# 立即晴天。
snow.set_enabled(false)

# 切回雨天，雨天控制器也会自动关闭雪天。
$RainWeather.configure(load("res://data/weather/rain_light.tres"))
```

这些控制在节点入树前也可使用，且不会污染共享预设。积雪保存在当前战场的运行状态中，离开战场后回收，下次进入按 `Initial Coverage` 开始。

## 参考与验证

原视频的 720p 参考文件保存在 `.maintenance/references/snow/BV18DYt6mE24.mp4`，关键帧与逐帧联系图在同目录，仅作本地分析。当前游戏使用原创程序化雪花和自己的地形/树木纹理。

```powershell
# 天气逻辑与真实战场集成
& 'D:/Godot4/Godot_v4.6.2-stable_win64_console.exe' --headless --path . res://tests/snow_weather_test.tscn

# GPU：固定雪斑、融化、地表透明洞、移动镜头、雪花运动
& 'D:/Godot4/Godot_v4.6.2-stable_win64_console.exe' --path . res://tests/snow_surface_render_test.tscn

# GPU：四层积雪、单位/悬崖遮挡、堆积/融化、切换与正式第 5 关
& 'D:/Godot4/Godot_v4.6.2-stable_win64_console.exe' --path . res://tests/snow_floors_test.tscn -- --no-mcp-server

# 战场截图（需要图形渲染）
& 'D:/Godot4/Godot_v4.6.2-stable_win64_console.exe' --path . res://tests/snow_weather_test.tscn -- --capture
```

主体脚本：`scripts/world/snow_weather.gd`；图块遮罩：`scripts/world/weather_ground_mask.gd`；着色器：`shaders/snow_ground.gdshader`、`snow_scenery.gdshader`、`snow_flake.gdshader`。雪花由两组 GPU 粒子绘制，遮罩只在配置刷新时生成，物体扫描每 0.5 秒一次并受数量上限约束。

多层积雪逻辑可通过 `tools/maintenance/run_checks.py --checks snow snow-floors` 验证；同一 `snow_floors_test.tscn` 在图形模式额外验证实际像素，并导出 `.maintenance/snow-floors/battle-005-fixed.png` 与关闭高层积雪时的对比图。headless 下会明确跳过 GPU 检查。
