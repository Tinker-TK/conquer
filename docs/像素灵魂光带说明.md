# 像素灵魂光带

参考视频：[一条灵魂光带是怎么做出来的《五星地牢》开发日志 02](https://www.bilibili.com/video/BV1x4hk6CE7S/)。根据公开视频介绍与关键帧，独立重写二次贝塞尔路径、加速飞行、延迟尾迹、尖尾圆头、三段配色、低分辨率像素化和尾迹吸收。没有使用视频中的源代码或素材。

## 打开预览

Godot 打开 `examples/scenes/pixel_soul_ribbon_demo.tscn`，按 **F6**。

- 主画面循环播放完整飞行与吸收过程，下方展示生成、飞行、吸收三个固定时刻。
- 右侧调整飞行时长、尾迹保留时长、加速幅度、前端宽度、尖尾收束、像素颗粒与弧线高度。
- 拖动动画进度条会暂停到指定时刻，能向前、向后观察尾迹变化。
- 打开“显示路径”，可直接拖动 **A 发射点 / B 控制点 / C 吸收点**；B 是曲线控制点，光带无需经过 B。
- **空格**暂停 / 继续，**R**恢复全部默认，**1–3**切换青色、金色、紫色配色。“重新播放”从发射点重播。

本次效果和演示均未接入正式游戏。未修改游戏入口、回合结算、单位、技能或战场资源。所有预览调参只保留在本次运行中，不保存到场景或游戏配置。

## 独立效果

| 文件 | 用途 |
| --- | --- |
| `scenes/effects/pixel_soul_ribbon.tscn` | 可独立实例化的 Node2D 效果 |
| `scripts/effects/pixel_soul_ribbon.gd` | 曲线、带状几何、播放时钟、像素画布 |
| `examples/scenes/pixel_soul_ribbon_demo.tscn` | F6 预览场景 |
| `examples/scripts/pixel_soul_ribbon_demo.gd` | 预览控件、进度拖动、路径编辑 |
| `tests/pixel_soul_ribbon_render_test.tscn` | GPU 渲染与交互验证入口 |

`Start Point`、`Control Point`、`End Point` 都使用效果根节点的本地坐标。可以移动或缩放根节点，改变整个效果的位置与尺寸；路径支持负坐标。

`Flight Duration` 控制前端到达 C 的时间；`Acceleration` 为 1 时按均匀参数前进，大于 1 时由慢到快。`Trail Delay` 是尾端跟随前端的时间差，所以到达 C 后尾迹仍继续前进。尾迹宽度同时收束，最终完全消失；完整时长为 `Flight Duration + Trail Delay`。

`Head Width` 为圆头直径；`Taper` 控制从尾端到圆头的宽度曲线。尾迹由暗色、青色主体和浅色圆头三段多边形构成。低分辨率透明 SubViewport 以最近邻放大，实现整个轮廓与色带的实际像素化，`Pixel Size = 3` 表示三个本地像素一个显示方格。可选光晕在同一个像素画布中绘制，不需要项目开启 Glow。

每个实例有独立的 SubViewport、纹理和时钟；静止时仅按需重绘，常规轮廓使用 3 个主体多边形与 1 个圆头，开启光晕时另加两层透明多边形。极短或折返轮廓会回退到有效三角形，避免生成与消失阶段的退化多边形错误，无需外部贴图或着色器。`Curve Samples` 控制曲线精度，默认 64。`Palette Preset` 有三套配色；`Use Custom Palette` 配合三个从尾到头的颜色可自定义。

## 后续可用接口

本次没有添加任何玩法调用；独立节点提供以下接口，方便后续决定用途：

```gdscript
# 所有路径点相对效果自身。
effect.play(Vector2.ZERO, Vector2(20, -300), Vector2(760, -40))
effect.playing = false  # 暂停
effect.seek(1.0)        # 指定时间，不触发到达/完成信号
effect.restart()        # 重播当前路径
```

`arrived` 在前端到达时发出；`finished` 在尾迹完全被吸收后发出。默认 `Autoplay` 开启、`Looping` 关闭，自动播放一次后停止；不会自动删除节点。若初始化时希望静止，可在实例加入树前设 `autoplay = false`。编辑器预览自动循环，不发运行信号。`Loop Delay` 为循环之间的空白间隔，默认 0.45 秒。
