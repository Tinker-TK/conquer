# 牧师护盾与咏唱

## 治疗选择与强化

牧师从本战场存活友军中选择当前生命/最大生命比例最低者，包含自身。同一比例优先近处；死亡、待删除、无效最大生命或其他战场单位不参与。

`monster_test` 等独立练兵场没有正式战场的 `battle_owner` 标记；索敌先检查标记是否存在，无标记时只查询同一个队伍容器，普通治疗、自疗和强化护盾照常生效。使用 `--checks monster-test-priest` 检查这一独立路径。

基础治疗倍率仍为0.6，全体友军满血时使用攻击。强化后以1.4倍攻击力治疗；全员满血时改为选择当前生命值最高的友军，同值优先近处。治疗在原动画命中帧结算，超出目标缺失生命的部分按1:1累加为护盾。例如攻击10、目标95/100，治疗14点后生命100、护盾9；满血时14点全部转为护盾。禁疗同时拦截该次治疗和溢出转盾。

护盾不改变单位基础属性，无单独时限和上限，先于生命抵扣后续伤害。普通攻击先计算防御和伤害倍率，再扣护盾；固定伤害、毒和环境伤害也先扣护盾。护盾耗尽、单位死亡或离开交锋时清除，状态图标显示剩余数值。

有护盾时直接调用实验室原版 `ShieldBubbleVFX`（目录名“护盾 · 罩”），罩随单位移动，持续到护盾清除。重复加盾只更新数值，不额外叠罩。

基础与强化治疗资源分别为 `data/skills/priest_healer.tres`、`data/skills/priest_healer_upgraded.tres`，使用强化等级 `[0]`、`[1]` 分别装配。

## 咏唱系统

| 单位技能 | 咏唱时间 |
| --- | --- |
| 牧师单体攻击 | 0.3秒 |
| 牧师治疗（含强化） | 0.7秒 |
| 巫师火球 | 0.5秒 |
| 巫师霜暴（含强化） | 1.5秒 |

`SkillBase.chant_duration` 配置前置咏唱，默认0，其他技能保持即时进入动作。技能管理器在单位头顶生成进度条，以物理时钟推进；咏唱中不能移动、开始技能动作或触发命中，走满才播放原配置动画，沿用原命中帧释放效果。

成功咏唱在开始技能动作时启动冷却。咏唱期间新施加的眩晕、睡眠、混乱、流血、虚弱、减速、禁疗、卡牌负面状态或中毒会取消本次施法，立即进入完整冷却；外部眩晕、策反、反击、目标死亡/退场、动作被替换及阶段结束也取消咏唱。没有附带异常状态的普通伤害不打断。中断后旧命中帧不会释放技能。

暂停冻结进度；战斗倍速统一推进咏唱、动画、冷却及技能效果。技能详情和配置表显示咏唱秒数。

## 验证

运行 `tools/maintenance/run_checks.py --checks priest-chant-shield wizard-frost-storm wizard-fire-ball targeting status-effects skill-unlock card-description unit-details game-config-editor`。

图形模式共用入口追加 `--priest-chant-shield-regression --capture`，截图在 `.maintenance/priest-chant-shield/`，包括护盾罩、牧师治疗咏唱和巫师霜暴咏唱。
