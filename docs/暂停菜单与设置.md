# 暂停菜单与设置

游戏中点击顶部「设置」或按 Esc 打开暂停菜单，包含「继续 / 设置 / 图鉴 / 保存并退出」四个按钮。菜单打开时暂停战斗并遮挡背景操作。从卡组、只读地图等已经暂停的界面打开，再关闭会恢复原来的暂停状态。

「图鉴」打开书本式的遗物、己方单位、敌方单位、药水和事件档案，右下角书签切换分类；图鉴返回时继续保持暂停。详见 [冒险图鉴](冒险图鉴说明.md)。

「设置」只提供视频和音频两个页签。设置页的返回按钮或 Esc 回到暂停菜单，再按 Esc 继续游戏。主菜单的设置也使用同一个面板。

## 视频设置

| 选项 | 作用 |
| --- | --- |
| 全屏模式 | 在全屏和窗口间切换；全屏时窗口尺寸和缩放选项禁用 |
| 显示器选择 | 枚举本机显示器，把游戏窗口移到所选显示器 |
| 窗口化分辨率 | 1280×720、1600×900、1920×1080、2560×1440、3840×2160；超过显示器可用区域时限制到屏幕内 |
| 画面宽高比 | 16:9、16:10、4:3、21:9；按所选比例显示画布，窗口比例不一致时留黑边 |
| 窗口缩放 | 允许或禁止手动拖动窗口边框改变大小 |
| 垂直同步 | 关闭、开启、自适应；实际支持由图形驱动决定 |
| 帧数上限 | 无限制、30、60、90、120、144、165、240 |
| MSAA | 关闭、2×、4×、8×，应用于 2D 视口；项目默认 Forward+ 支持，OpenGL Compatibility 暂不支持 2D MSAA |
| 重置 | 恢复视频默认值：窗口模式、显示器1、1920×1080、16:9、允许缩放、自适应同步、60帧、2×MSAA |

## 音频设置

全局、音乐、音效、环境音各自支持 0～100% 音量，0% 完全静音。菜单声音和现有战斗音效已经接入音效总线。音乐、环境音总线可供后续对应播放器指定；当前没有新增音乐或环境音素材。

「在后台时静音」在切出整个游戏应用时静音，返回后恢复玩家设置的音量，不暂停游戏进度。所有偏好即时生效并保存到 `user://game_settings.cfg`；旧主菜单的总音量会自动迁移。原有减少动效偏好仍由切场管理器读取。

## 保存并退出

成功写入 `user://saved_run.tres` 后返回主菜单，主菜单出现「继续征途」。保存包含血量、金币、独立卡牌配方和永久训练/强化、遗物及其进度、剩余药水、路线快照、已完成地点和地图滚动位置。加载时不再次应用获得遗物的奖励。

未完成的战斗、商店、宝箱或事件，从进入这个地点前的快照继续，重新选择当前地点。这也会还原该地点内的消耗和收益；避免领取一半的奖励在重开时重复发放。每场战斗的临时退场加费不进入存档。保存失败时保留当前界面并显示原因。

## 验证

```text
python tools/maintenance/run_checks.py --checks settings-pause comic-ui game_session_smoke camera combat-audio battle-rewards --label settings

# PowerShell：图形检查也指定独立的测试用户目录。
$env:APPDATA = Join-Path (Get-Location) '.maintenance/settings-visual-userdata'
Godot --path . --script res://tests/settings_pause_test.gd -- --no-mcp-server
```

独立图形检查在项目默认 D3D12 / Forward+ 下完成，截图写到 `.maintenance/settings/`，包括暂停菜单、视频、音频、4:3布局和战斗暂停。测试使用独立 APPDATA，不修改玩家真实存档和偏好。可用同一个测试用户目录再运行 `--verify-saved-run` 检查游戏进程重启后的数据恢复。
