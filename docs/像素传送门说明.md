# 像素传送门（独立效果）

参考：[《五星地牢》从一个椭圆到像素传送门｜特效拆解 07](https://www.bilibili.com/video/BV1NiHa6sEMH)。按视频展示的门环、门内旋涡、环绕碎片和地面光斑四层重新实现；未使用视频的代码或素材。

## 打开预览

在 Godot 打开 `examples/scenes/pixel_portal_demo.tscn`，按 **F6**。

- 左侧放大显示完整效果，右侧以 1×、3×、5× 显示，并用棋盘格检查透明边缘。
- 底部同时显示四层；侧栏的图层开关只改变上方完整预览，保留四张拆解卡方便对照。
- 可切换青蓝、紫色、金色和绿色配色，比较 3 / 6 / 12 秒循环；默认六秒、14 帧/秒。
- 实时调整速度、门环宽度、轮廓流动、旋涡强度、碎片数量和像素颗粒。侧栏可滚动，底部有恢复默认按钮。
- **空格**暂停/继续；拖动时间轴暂停并定位到单帧；**R**恢复默认；**1–4**切换配色。

本次没有添加游戏调用。正式入口、单位、技能、战场和自动加载配置保持原有内容；预览不创建实际单位，也不开始新一局。传送门本身是纯视觉效果，没有碰撞、传送、目标选择或场景切换。

## 可复用资源

| 文件 | 用途 |
| --- | --- |
| `scenes/effects/pixel_portal.tscn` | 可单独实例化的 Node2D 特效 |
| `scripts/effects/pixel_portal.gd` | 编辑器参数、逐实例材质、局部循环时钟 |
| `shaders/pixel_portal.gdshader` | 四层像素绘制及周期运动 |
| `examples/scenes/pixel_portal_demo.tscn` | F6 预览入口 |
| `tests/pixel_portal_render_test.tscn` | GPU 渲染与预览交互验收 |

特效原点在地面光斑中心。默认透明画布为 **32 × 48** 本地像素，门环约 **19 × 34**，从暗蓝到淡青分成五个色阶。改变根节点 `Scale` 可以整体放大，整数倍缩放最适合保持像素边缘。`Draw Size` 与 `Portal Size` 分别控制画布和门体大小；调整门体时为碎片和光斑留出空间。

`Pixel Size` 默认为 1。`Ring Width`、`Distortion`、`Swirl Strength`、`Fragment Count` 控制外观；四个 `Enabled` 参数独立开关图层。柔和光晕默认关闭，开启后仅在自身画布内增加透明亮色，不会照亮其他对象。`Brightness = 0` 会隐藏全部图层。

`Palette Preset` 提供四套颜色；启用 `Use Custom Palette` 后可指定从暗到亮的五个 RGBA 色阶。每个实例的材质、颜色、时间和播放状态独立。

`Playing = false` 暂停，`Playback Speed = 0` 冻结；`restart()` 从头播放，`seek(seconds)` 定位效果内部时间。`Loop Duration` 默认 6，`Animation Fps` 默认 14。全部运动由同一个周期相位驱动，不使用全局 `TIME`；循环帧数取整，任意时长都能首尾连续，指定时间可精确复现。`seek()` 不乘播放速度；速度只影响自动播放。

脚本支持 `@tool`，可在编辑器里预览。以后决定用途时，再实例化特效并接入玩法即可。
