# 音频资产规范（AI 生成 / 程序合成）

本规范约束 `tools/audio/ai/` 流水线产出的全部音频。目标不是“听起来像 AI”，而是**同一场战斗里连续播 20 次也不出戏**：起音一致、响度一致、命名一致、许可可追溯。

## 1. 三条产线

| 产线 | 用途 | 当前方案 | 备注 |
| --- | --- | --- | --- |
| 音效 SFX | 攻击、受击、爆炸、抽牌、UI | ElevenLabs Sound Effects；无 key 时用程序合成占位 | 单次 ≤2.5s，要求干声、单声道 |
| 背景音乐 BGM | 战斗 / 营地 / 地图 / 胜利 | Suno 免费档手动出稿；付费后可接 ElevenLabs Music API | 需要循环与情绪分层 |
| 环境音 Ambience | 篝火、森林、集市、雨 | Suno 手动出稿 + 程序合成占位 | 循环接缝优先于音色华丽 |

Suno 没有公开 API，免费档输出仅限非商用；它在这条流水线里是“人工出稿 + 自动入库”，不是自动生成。

## 2. 目录与命名

```
assets/audio/ai/<provider>/<category>/
```

- `provider`：`elevenlabs` / `suno` / `procedural`
- `category`：`ui` / `card` / `ai_combat` / `music` / `ambience`

命名规则（全小写，只用 `a-z0-9_`，不用空格、中文、大写）：

```
sfx_<domain>_<action>_vNN.ogg     例：sfx_combat_sword_swing_v01.ogg
bgm_<mood>_<theme>_vNN.ogg        例：bgm_battle_ember_v01.ogg
amb_<place>_<weather>_vNN.ogg     例：amb_forest_day_v01.ogg
```

- `domain`：`combat` / `card` / `ui`
- 变体号固定两位，从 `v01` 起；同一提示词的多条结果只改变体号，方便 A/B 后只保留一条。
- 中文标题只写在清单 `title` 字段，不进文件名。
- 文件名即资源 id，改名等于换素材，必须重新入清单。

## 3. 风格底色

像素中世纪奇幻 + 卡牌 roguelike，偏原声、干燥、近场。

| 项 | 内容 |
| --- | --- |
| 材质词表 | wood, leather, iron, parchment, stone, cloth, coin |
| 听感要求 | close-miked, dry, clean transient, game-ready one-shot |
| 禁止项 | reverb / room tail / music bed / vocals / crowd / modern synth |
| 提示词模板 | `<动作与材质>. <材质词表>. <听感要求>. <禁止项>.` |
| 长度上限 | 450 字符（ElevenLabs 接口限制） |

提示词先写“什么动作、什么材质、多长”，再交给模板补风格词；不要写“史诗感”“电影感”这类会引入混响和音乐床的词。

## 4. 混音与格式

| 类别 | 采样率 | 声道 | 峰值 | 时长上限 | 循环 |
| --- | --- | --- | --- | --- | --- |
| ui | 44.1 kHz | 单声道 | −1.5 dBFS | 1.2 s | 否 |
| card | 44.1 kHz | 单声道 | −1.5 dBFS | 2.0 s | 否 |
| ai_combat | 44.1 kHz | 单声道 | −1.0 dBFS | 2.5 s | 否 |
| music | 44.1 kHz | 单声道 | −1.0 dBFS | 45 s | 是，RMS ≈ −20 dBFS |
| ambience | 44.1 kHz | 单声道 | −1.5 dBFS | 40 s | 是，RMS ≈ −22 dBFS |

- 统一转 OGG Vorbis；短音效保留干净起音，不做母带式压缩。
- 单声道是为了让 Godot 做 3D 衰减和声像；需要立体声的环境音后续单独开一条产线。
- 循环类先按 RMS 对齐再限峰值，避免“峰值一样、听感一响一轻”。

## 5. 循环规则

- 只对 `music` / `ambience` 做循环：尾巴等功率交叉淡入到开头，BGM 2.0 s、环境音 1.2 s。
- 接缝跳变（首尾样本差）要求 ≤ 0.02，超过记告警。
- 循环类**不做淡入淡出**，否则每次循环都会掉一下音量。
- 循环长度至少 4 s；太短会被听出周期。

## 6. 自动分类与质检

流水线按 `category` 自动分目录，再按音频特征补标签：

| 维度 | 取值 |
| --- | --- |
| 播放形态 | `one-shot` / `loop` |
| 起音 | `percussive`（≤15 ms）/ `soft-attack` |
| 亮度（频谱质心） | `dark`（<1.2 kHz）/ `balanced` / `bright`（>3 kHz） |
| 动态 | `spiky`（波峰因数 >18 dB）/ `compressed`（<9 dB） |

硬性检查：单声道、最短 50 ms、不超过类别上限、峰值不越界、循环接缝。告警默认不阻断，`--strict` 时阻断。

## 7. 授权与合规

| 许可标记 | 含义 | 能否商用 |
| --- | --- | --- |
| `CC0-1.0` | 程序合成占位音，项目原创 | 可以 |
| `AI-ELEVENLABS` | ElevenLabs 免费档生成 | 内部试听；商用需付费订阅并遵守其条款，免费档通常要求署名 |
| `AI-SUNO` | Suno 免费档生成 | **不可以**，仅内部试听 |

- 每条成品都带 sidecar JSON（提示词、provider、生成时间、SHA256、处理参数），作为来源证据链保留。
- Steam 2026 年起要求披露玩家可见/可消费的 AI 生成内容；国内发行还需遵守生成合成内容标识要求。
- 不要用提示词模仿在世艺人声线、知名 IP 或具体受版权保护的作品。
- 免费档素材在正式发行前必须逐条替换或补授权，不能直接进包。

## 8. 工作流

```text
# 无 key：先用程序合成占位音打通全链路
python tools/audio/ai/pipeline.py --provider procedural

# 有 key：ElevenLabs 批量生成（先 --dry-run 看额度）
python tools/audio/ai/pipeline.py --provider elevenlabs --dry-run
python tools/audio/ai/pipeline.py --provider elevenlabs --only ui_click_primary combat_sword_swing

# Suno：看提示词 → 网页出稿 → 放进收件箱 → 入库
python tools/audio/ai/ingest_suno.py --list
python tools/audio/ai/ingest_suno.py
python tools/audio/ai/pipeline.py --provider suno --skip-generate

# 试听与回归
python tools/maintenance/run_checks.py --checks audio-library
```

Godot 打开 `res://examples/scenes/audio_library.tscn`，按 F6。分类里的 `界面 · 交互`、`卡牌 · 抽打`、`战斗 · AI 候选` 就是本规范的新增产物。底部“循环”开关可循环播放 BGM / 环境音，直接听接缝。
