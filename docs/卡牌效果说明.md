# 卡牌效果说明

统一采用“目标、效果、期限”的简短句式，数值以实际效果配置为准。手牌、拖放预览、牌堆、奖励、商店共用 `CardInstance.get_description()`。

征召牌只显示当前强化等级生效的技能；效果牌按当前实例的效果数值显示，读档后同样有效。消耗牌标注“消耗”，持续效果写明回合、本场战斗或本局永久。

下表为2026-10-18默认配置。50张效果/能力牌均可强化一次（含新增23张）；同名牌分别记录，强化可由篝火或临时进化触发。费用、效果数值、期限及策反目标规则都会随强化同步更新，永久升级可保存并在读档后恢复。新增自定义效果继续使用资源中的 `card_discription`。

配置字段：`CardDefinition.upgrade_cost_change` 为基础费用增量（最低0费）；`CardEffect.upgrade_amount` 为主数值增量，`upgrade_lasting_rounds` 为回合期限增量，`upgrade_can_convert_elite` 表示强化后可策反精英。`RETAIN_ALLIES.amount` 为阵亡原牌加费。狂化吸血直接按实际伤害的20%/30%计算，整数回复向下取整。

沿用交锋出牌规则：在自动交锋阶段施放的单位普通强化和地面区域只持续当前回合；泥潭2→3回合对应准备阶段施放。
