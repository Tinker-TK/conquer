# 三类卡牌配置说明

圣殿骑士的连续攻击与驻场庇护已替换为「嘲讽攻击」：半径200，基础3秒、强化5秒，冷却10秒，复用原光环作为嘲讽特效；强化期间按瞄准自身的敌人数增加防御。防守反击新增每次防御-1，详见[嘲讽配置说明](圣殿骑士嘲讽攻击.md)。

现有士兵卡强化一次后自动获得「剑矢」效果：远程普攻射程 300，近身使用近战普攻，共用冷却，箭矢复用弓箭手素材。详见 [剑矢强化说明](剑矢强化说明.md)。

现有骑士（`knight`）征召牌成功布置到场上时立刻抽 1 张牌；这张卡强化后改为抽 2 张，多次强化仍为 2 张。准备阶段与交锋中出牌、随机免费部署、收回原牌后再次部署都按此规则结算；预览、失败出牌、单位复制、直接生成或跨回合留存不会触发。抽牌沿用原有禁抽、弃牌堆洗回、牌不足和遗物计数规则；禁抽或无牌可抽时仍可正常部署骑士。强化记录按每张卡独立保存，卡面及强化摘要显示上场抽牌说明。

全部卡牌的卡面与悬停说明统一使用简短效果描述，并随本张牌当前强化状态切换。骑士未强化显示“上场时，抽1张牌。”，强化后显示“上场时，抽2张牌。”，同时只展示当前等级生效的技能。手牌、牌组查看、奖励、商店和拖放预览使用同一说明入口，读取存档后也按实际效果显示。完整文案见 [卡牌效果说明](卡牌效果说明.md)。

初始牌组以 `data/run/run_start_data.tres` 的 Cards 数组为准；新建卡牌资源不会自动加入牌组。项目入口与完整配置导航见 [项目架构](project_architecture.html)。

## 先做一张攻击强化牌

1. 在 Godot 文件系统中新建资源，选择 **CardDefinition**，保存为自己的 .tres。
2. Category 选 ENHANCEMENT，Target 选 ALLY。
3. 填写 Card Name、Card Discription、Card Cost 和图片。
4. 展开 Effects，增加一个元素，新建 **CardEffect**。
5. Kind 选 ATTACK_UP，Amount 填 5。
6. 打开 data/run/run_start_data.tres，在 Cards 数组增加一个元素，把自己的卡牌拖进去。
7. F5 开新局。抽到后拖到己方单位附近松开，该单位本场攻击力增加 5。目标无效或能量不足，不扣费、不丢牌。

也可以打开 **examples/data/card_examples.tres**：Cards 数组内有下表的十四个示例，顺序与表格一致。展开某个子资源，使用资源菜单“另存为”保存为独立 .tres 再修改。相同资源的引用共享配方；做独立变体时，先“设为唯一”或另存为。

## 每张牌需要配置什么

| 字段 | 含义 |
| --- | --- |
| Category | RECRUIT 征召、ENHANCEMENT 强化、ABILITY 能力。类别不等于结算规则。 |
| Target | NONE 不指定单位；ALLY 己方；ENEMY 敌方；ANY_UNIT 任意单位；POSITION 战场位置。 |
| Card Cost | 消耗的能量。 |
| Rarity | COMMON 普通蓝框；RARE 稀有金框。 |
| After Use | DISCARD 结算后弃牌；EXHAUST 本场消耗；PERSIST 常驻至战斗结束，可在“常驻卡牌”入口查看。总卡组仍保留，下场恢复。 |
| Retain In Hand | 固有：回合结束不弃置未使用的此牌；使用后仍按 After Use 处理。 |
| Starts In Hand | 每场首轮先将此牌发入手牌，再进行常规抽牌；不额外生成卡牌，不计入遗物抽牌次数。 |
| Summon Unit | 只有征召牌使用，拖入兵种的 UnitData。 |
| Effects | 按列表顺序执行。征召牌不混合此列表；骑士等兵种的内置上场效果在成功部署后独立结算。 |

不指定单位的牌也需拖入战场松开。单位目标使用鼠标附近 65 像素内最近的合法单位；合法目标已有绿色预览提示。

旧 UnitData 仍可直接放进初始牌组，自动作为征召牌。新征召 CardDefinition 的 Target 需设为 POSITION。普通效果使用 Battlefield Rect；征召只在实际导航多边形的己方半场，Deployment Rect 为兼容字段。

十张战术卡目前统一使用狂化的红色插图 `assets/ui_redrawn/UI/cardUI/artsource/01.png` 占位；后续可分别替换各资源的 Card Image。

| 卡牌 / 资源 | 费用 / 品质 | 效果 |
| --- | --- | --- |
| 虚弱 / weakness.tres | 1 / 普通蓝框 | 单个敌军攻击 -2，可叠加；当前回合结束清除。 |
| 易伤 / vulnerability.tres | 2 / 普通蓝框 | 单个敌军易伤 20%，不叠加；攻击伤害按 `(攻击力 - 防御) × 1.2` 结算，当前回合结束清除。 |

| 狂化 / frenzy.tres | 2 / 稀有金框 | 对一名己方单位施加。本场己方存活 ≥3 时攻防 70%；2 个时 100%；独存时攻击 150%、防御 130%、技能 CD 80%，吸血回复实际伤害的20%（强化后30%）。随人数实时变化。 |
| 鸣金收兵 / retreat_draw.tres | 1 / 普通蓝框 | 回合末毒与连锁死亡结算后，每名己方存活单位使下回合额外抽 1 张牌；只兑现一次。多次使用可累计。 |
| 合理搭配 / diverse_army.tres | 3 / 稀有金框 | 常驻到本场结束。己方存活兵种按 Unit Type 去重，≥3 种时全体攻击 +2；不足立即撤销，重新达标即恢复。 |

| 审判者 / judger.tres | 3 / 稀有金框 | 对一名己方单位施加。本场每击杀一名敌人攻击 +2；实际致死攻击及带来源的毒伤害计入，重复死亡不重复激励。 |

怪物配置表新增 **怪物等级 / Monster Rank**：普通 NORMAL、精英 ELITE、首领 BOSS、传说 LEGENDARY；`elite_orc.tres` 标为精英，其余未指定资源默认普通。基础策反仅允许 NORMAL，强化后也允许 ELITE；始终不能策反 BOSS 或 LEGENDARY。等级独立于兵种和波次数值成长，敌方单位详情也显示等级。

战术数值在 CardEffect 的“阵容与战术效果”字段中配置。易伤 Amount 为增幅百分数；麻痹 Amount 为眩晕秒数、Interval 为触发间隔；狂化 Amount 为实际吸血百分数，20 对应实际伤害的20%。合理搭配使用 Required Unit Types；保持距离使用 Minimum Attack Percent 和 Distance For Max Bonus，远端百分数使用 Amount。

虚弱、恐吓可叠加；易伤、麻痹、狂化、审判者在同一单位上不重复叠加，合理搭配和保持距离在同一场不重复启用。重复状态或非法目标会拒绝出牌并保留费用与卡牌。单位战术状态随该单位退场清除；与不灭军势搭配留存时，狂化与审判者继续保持到战斗结束，四种当回合减益仍正常清除。复制单位不会烘焙或继承单体战术状态，新复制品仍实时享受全场效果。

所有攻击伤害向下取整并沿用最低 1 点；攻防百分比按整数属性四舍五入，实时刷新不会反复累乘。吸血按实际扣除生命计算，排除过量伤害并受最大生命限制。全场加法增益先进入单位属性，再计算狂化；保持距离在技能攻击倍率后、扣防御前计算，易伤最后计算。

## 当前规则与边界

- **战友**（`data/cards/comrade.tres`）：3费、稀有金框、能力牌，常驻本场。成功打出一张当前费用≥6（强化后≥5）的牌后，下次打出的单位牌变为0费；其它手牌单位同时显示0费供选择，成功打出其中一张后，未打出的其它单位恢复费用。无效落点、能量不足等失败操作不消耗减免，非单位牌也不消耗减免。减免只保留一次，不因连续高费出牌累积多次；未使用的减免跨回合保留。该原单位牌在场上及收回手牌期间仍为0费，回弃牌堆时恢复基础费用和此前累计加费，并沿用普通单位退场加费（默认+1，不灭军势生效时+2，强化后+1）。按减费后的卡面费用判定高费触发，0费单位不会自触发。重复启用战友会拒绝出牌，不扣费。
- **进化**（`data/cards/evolution.tres`）：1费（强化后0费）、普通蓝框、强化牌。拖入战场打开“其它手牌”选择面板，战斗暂停；仅显示可按现有训练/强化规则升级的其它手牌。单位牌由玩家分配全部攻击、防御能力点，并预览升级结果；非单位牌沿用费用、效果数值、期限及策反目标的强化配置。确认前不扣费、不修改原牌，取消可继续战斗。下次实际成功使用目标时，按升级数据生成单位或结算效果，再撤销此次临时升级；保留原品质、此前永久训练和正常加费，场上已生成单位及已施加效果仍保留本次升级数值。未用目标即使被弃置仍保留此次进化，直到使用或本场结束；本场临时升级不会写成存档永久训练。已达现有升级上限或已进化的牌不可重复进化。未配置升级增量的旧效果牌沿用原来的升级配置，不擅自增加效果数值。
- **运筹帷幄**（`data/cards/master_strategy.tres`）：0费、普通蓝框、能力牌，立刻抽2张牌（强化后3张），使用后进入本场消耗牌堆，不参与弃牌堆洗回；未使用时具有固有保留。正式新局在原10张初始牌组之外加入两张独立的运筹帷幄。每场开局先将这两张发入手牌，再常规抽5张，首轮共7张；后续每轮按关卡抽牌数正常抽牌，不重复赠送。新场战斗重新恢复消耗牌并优先发入手牌；固有牌在本场结束时正常回收。自定义 RunStartData 或关卡抽牌配置仍按其实际牌组和张数执行。

- **不灭军势**（`data/cards/undying_army.tres`）：5 费、金框稀有能力牌，无单位目标，使用后进入常驻区。本场每轮结算毒、爆炸和 HP 伤害后，己方活单位留在场上进入下一轮，保留当前生命、位置、状态和原牌绑定；包括复制品和技能召唤物。尸体和敌方单位仍清场，幸存单位不弃牌也不加费。启用后，阵亡原征召牌每次回弃牌堆增加2费（强化后1费）；此前的加费不追溯，重复使用不叠加为 3 费。战斗结束清除常驻状态与加费，下场恢复默认规则。此牌已进入战斗奖励候选和旅途商队商品池（120 金币），不自动加入初始牌组，可篝火强化一次；多张常驻时使用较低阵亡加费。
- 默认每轮先结算毒、连锁死亡和存活单位 HP 伤害，再清空双方单位。幸存征召牌回弃牌堆，下一轮抽牌可重新抽到；清场退场不触发死亡爆炸或伤亡光环。单位临时强化随退场清除，原牌永久强化在重新征召时恢复。不灭军势生效时，己方幸存单位按上述留存规则处理。
- 下一轮敌人在准备阶段提前刷新并待机，玩家可查看阵型并对合法敌方目标施放卡牌；点击开打后双方才开始自动战斗。
- 默认单位死亡或每轮清场回到弃牌堆时，对应的原征召牌费用增加 1 点；不灭军势生效后阵亡原牌改为增加2点，强化版为1点。本场每次退场都会累加，再抽到时按新费用显示和扣费。每张牌独立计算，进入下一场战斗恢复基础费用；未使用的手牌弃置、强化/能力牌结算弃置、收回单位到手牌及无原牌的复制品不会加费。
- 攻击、防御、淬毒、死亡宣告支持 Lifetime：BATTLE 本场、ROUNDS 指定回合、RUN 本局永久。永久强化记录在对应牌实例，不修改共享资源。能力光环仍属于本场。
- 回复按最大生命计算，向上取整，不超过上限。
- 上毒按实际伤害命中触发，不在挥空或闪避时触发；多段攻击可多次叠毒。攻击者必须仍能被本场系统识别。
- 毒在一方战斗单位全灭、回合结算开始时结算：伤害等于当前层数，无视防御，不触发反击或再次上毒。默认不衰减，死亡或退出本场清除。先结算毒和连锁死亡，再统一判断平局与 HP 伤害，每轮只结算一次。
- 死亡宣告无视防御，可连锁引爆；重复施加会增加一份爆炸。尚无正式爆炸特效或状态图标。
- 复制保留当前生命、攻击、防御等单位属性，使用原兵种场景；不复制毒层数、淬毒、死亡宣告、冷却或动画。复制品重新获得本场光环，不重复计算原单位的光环加成。复制不增加总牌组、没有原牌，死亡不产生弃牌。
- 区域使用圆形覆盖区，不修改 TileMap。Lifetime 支持 BATTLE 或 ROUNDS，Lasting Rounds 设置回合数，不再使用 Duration 秒数。伤害区每 Interval 秒结算；泥潭普通移动减速在部署时也生效，离开恢复，多个泥潭取最强减速。直接驱动坐标的冲刺 Tween 不受普通移动速度控制。
- 禁抽只持续当前打牌回合；下轮先解除，再常规抽牌。牌不足沿用原来的洗弃牌堆和不足提示。
- 支付生命使用 RunManager.hp；默认不能支付到零。出牌前验证总生命费用和禁抽状态，避免先扣血后失败。
- 额外能量从下一打牌回合生效；多个来源叠加为固定额外能量，不是每回合继续递增；本场结束清除。
- 伤亡光环计算本场累计己方死亡，包括临时复制品，不包括收回。获得光环前的死亡也计入，新召唤的单位同样获得加成。
- 随机出牌从抽牌堆随机选择，免能量但仍支付生命等费用，自动选择合法目标；整个连锁最多成功 32 次。具体失败与禁抽规则由运行器统一验证。
- 收回的是绑定单位的原征召牌，直接回手牌；不触发死亡、爆炸或死亡统计。临时强化不保留到重新征召，没有原牌的复制品不能收回。
- 随机出牌和收回必须放在效果列表最后；每张牌最多配置一次复制。费用与目标预先验证，自定义效果也应遵守先验证后执行。

## 扩展新效果

继承 CardEffect，将 Kind 设为 CUSTOM，同时重写 validate(context) 和 execute(context)。前者只检查，返回错误文字或空串，不能扣费或改变状态；后者执行。context 包含 runtime、card、position、target、depth。仅选择 CUSTOM 而不实现脚本，会明确拒绝出牌，不会吞牌。

新增状态应放在运行器，不要把可变层数或单位引用写入共享 .tres。新增复杂组合需要补测试。
