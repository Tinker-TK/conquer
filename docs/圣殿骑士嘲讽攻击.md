# 圣殿骑士：嘲讽攻击与反击破甲

| 效果 | 基础 | 强化一次 |
| --- | --- | --- |
| 嘲讽攻击 | 替换原连续攻击。在自身周围200像素释放嘲讽，持续3秒，冷却10秒。 | 持续5秒，冷却仍为10秒。 |
| 嘲讽防御 | 无。 | 嘲讽释放期间，每名当前瞄准自己的敌人增加1点防御，实时计算；结束后撤销。 |
| 防守反击 | 沿用原配置，未强化不解锁。 | 保留20%闪避和150%反击伤害；每次成功反击使目标防御下降1点，可叠加。 |

普通攻击保留。原庇护光环不再为圣殿骑士或友军增加攻击；根据用户指定，复用其原始 `magic_aura.tscn` 特效，半径随嘲讽范围配置，随释放者移动，只在3秒／5秒的嘲讽期间显示。

嘲讽在动作的第3帧释放，使用原 `attack_03` 动作，不再结算原连续攻击的两次伤害。释放瞬间选取范围内的存活、可索敌敌人，不影响其他战场。被选中的敌人在持续时间内优先攻击释放者；即使离开初始范围，也保持至时间结束。后进入范围的敌人不会自动追加。

多个嘲讽按目标与各有效释放者的当前直线距离择近；距离变化时会切换。各来源分别计时，其中一个到期、死亡、收回、隐身或变成友军后，剩余有效来源继续生效。嘲讽更换正在攻击的目标并保留已消耗的冷却；不会让治疗技能以敌人为目标，也不会绕过眩晕、睡眠、混乱或强制位移。已经飞出的投射物保留其原目标。

强化防御只统计敌方当前技能锁定的攻击对象，包括接敌中的目标及正在攻击／反击的目标，不使用历史攻击记录。不是简单统计范围内人数；瞄准其他单位、死亡或脱离战场的敌人不计数。防御加成先作为基础加法，再计算狂化等百分比；复制品不继承原单位的临时嘲讽防御。

反击破甲在反击真正命中时生效，一次反击即使有多个命中帧也只减少1防御；持续当前交锋，跟随技能状态清理恢复原防御。不改写共享资源、原牌训练或永久属性。防御可降到负数，沿用当前伤害公式。复制品剥离破甲扣减。

配置入口为「游戏配置 → 技能配置」，搜索「圣殿骑士」：基础资源 `knight_templar_power_attack.tres`，强化资源 `knight_templar_taunt_upgraded.tres`。可配置 `taunt_radius`、`taunt_duration`、`defence_per_attacker` 和 `taunt_effect`；施法距离独立由 `cast_range` 控制。反击资源 `knight_templar_dodge_attack.tres` 的 `counter_armor_break` 控制每次破甲量。

回归使用 `python tools/maintenance/run_checks.py --checks templar-taunt card-description counter status-effects`。覆盖真实释放和自动接敌攻击、双来源择近、到期、控制状态、动态防御、反击叠层、狂化组合、正式复制、训练存档与独立 `monster_test`。图形运行追加 `--templar-taunt-regression --capture`，截图保存到 `.maintenance/templar-taunt/taunt.png`。
