# 战斗状态与特效

视觉素材来自 `examples/scenes/eslabong_vfx_demo.tscn` 所用的 Eslabong 素材库。命中自动播放 `BloodImpactVFX` 和 `FireSparks`；出生与死亡使用 `SmokeVFX` 烟团。状态持续时循环播放对应动画，解除、死亡和战斗结束时清理。

## 在技能中配置

在技能资源的 `Status Effects` 数组里新建 `UnitStatusEffect`。近战、范围攻击、冲刺、吸血攻击和投射物均已接入；只有实际命中且目标仍存活才附加状态，投射物在抵达时附加。士兵的剑矢强化会继承普通攻击的状态配置。

| Kind | 效果 | Amount | Duration | 特效 |
| --- | --- | --- | --- | --- |
| BLEED | 每秒扣固定生命，无视防御 | 每秒伤害点数 | 战斗秒数 | BleedVFX |
| CONFUSION | 沿当前楼层导航随机行走，不能攻击、施法或反击 | 不使用 | 战斗秒数 | ConfusionVFX |
| MORTAL_WOUNDS | 治疗、吸血及正常生命恢复无效 | 不使用 | 战斗秒数 | MortalWoundsVFX |
| SLEEP | 无法行动，受到攻击命中才醒；持续伤害不唤醒 | 不使用 | 忽略，保持到被攻击或解除 | SleepVFX |
| STUN | 无法移动、攻击、施法或反击，立即中断冲刺与尚未完成的召唤 | 不使用 | 战斗秒数 | StunVFX |
| WEAKNESS | 降低攻击力，到期恢复 | 固定降低点数 | 战斗秒数 | WeakenVFX |

`Duration = 0` 表示持续本场。准备阶段冻结状态计时；暂停与战斗倍速沿用游戏物理时钟。同一施法者的同一技能重复命中刷新期限，不重复叠加；不同来源独立保存，流血伤害相加。刷新流血不会重置下一次每秒扣血的进度。流血不足一秒的尾段不额外扣血。

例如设置 `BLEED / Amount = 8 / Duration = 5`，会在命中后的第 1～5 个战斗秒分别扣除 8 点生命。具体哪些兵种技能附加状态、各技能的伤害和期限，由技能资源配置决定。

原有策反卡在实际换队后持续播放 `CharmVFX`；原有虚弱卡播放 `WeakenVFX`；麻痹触发眩晕的实际时段播放 `StunVFX`。技能状态与这些战术效果共存，同类动画只保留一份。

## 脚本接口

```gdscript
# 对目标施加每秒 8 点、持续 5 个战斗秒的流血。
target.apply_status(&"bleed", 5.0, 8, caster, "skill_source")
target.apply_status(&"mortal_wounds", 3.0, 0, caster)
target.apply_status(&"sleep", 0.0, 0, caster)

# 只移除指定来源；省略来源键则移除该类全部技能状态。
target.remove_status(&"bleed", "skill_source")
target.remove_status(&"sleep")
```

治疗能力应调用 `UnitBase.get_heal()`，不能直接增加 `current_health`。最大生命提升附带的当前生命调整仍属于属性调整。

## 验证与素材更新

回归入口：`python tools/maintenance/run_checks.py --checks status-effects status tactical-cards counter summon bloodthirst sword-arrow enemy-pack resources --label status-vfx`。

图形预览：运行 `tests/card_framework_test_runner.gd -- --no-mcp-server --status-effects-regression --capture`，截图保存在 `.maintenance/status-vfx-preview.png`。

Godot 原生粒子在构造时会消耗全局随机数。命中动画由 `tools/vfx/bake_combat_impacts.gd` 从 demo 中的原始血液与火花素材渲染为透明帧，运行时播放共享的压缩 SpriteFrames，避免改变闪避、抽牌等玩法随机数。更新原素材后，以图形模式和 `--fixed-fps 60` 运行此工具重新生成 `assets/effect/eslabong_vfx/combat_baked/`。其余状态与烟团直接使用原始动画资源。
