# 遗物流派实装说明

已接入设计中的60件新遗物，连同6件旧遗物共66件有效资源；旧城防继续停用。正式开局配置不额外赠送新遗物。

## 试玩与获取

- 正式游戏：普通战斗基础掉率12%，Boss必出首领遗物三选一；首件战斗遗物也提供三选一。
- 宝箱和遗物事件：未持有遗物三选一，只剩一件时直接领取；候选固定，关闭、查看地图、返回均不重抽。
- 商店：3格遗物，尚有可售稀有遗物时至少一格稀有；普通150金币、稀有200金币，首领不出售。商人印记对商品和删牌服务打8折。
- 同流派权重1.5，未持有流派0.8，铺场/单核及亡语/防守冲突再乘0.3；稀有的基础抽取权重低于普通。
- 遗物图鉴已迁入「设置 → 图鉴」的书本遗物书签，展示全部有效遗物、流派与说明，并标记已有发现记录；浏览不改变发现记录。旧 HUD 入口已移除，见 [冒险图鉴](冒险图鉴说明.md)。
- 独立试玩：打开 `examples/scenes/relic_builds_demo.tscn`，根节点 Inspector 的 **Relic Build** 选择十种流派之一，按F6进入完整套装战斗。正式开局资源不受修改。

## 配置和运行入口

`data/relics/*.tres` 保存名称、说明、稀有度、流派标签、触发器、处理器、每场/每轮上限、冷却和同事件优先级。新增资源必须显式使用 `kind = 5`（`NONE`）；旧默认 `DRAW_ENERGY = 0` 保留，避免旧十抽引擎失效。

`scripts/battle/relic_runtime.gd` 每场创建，统一维护计数、战斗随机数、每敌人冷却与消息。常规战斗信号和出牌入口驱动效果；计时使用随暂停和倍速变化的Timer，只有守护誓约每秒检查一次友军。被动属性接入原有属性刷新，距离增攻在扣防御前结算，受到伤害加成在伤害入口结算。同类正向百分比相加并封顶60%。

遗物之间不递归触发。骨灰瓮、荆棘、齐射等直接伤害不带攻击者，不触发吸血、反击和命中附毒。焚城调用公共 `create_zone`，保留独立 `relic` 来源、区域期限及原有火焰地形表现。

死亡只从正式 `die()` 入口统计，清场和撤回不算死亡。抚恤记录具体原牌的首次免加费；死亡回响移动同一张原牌；王座复活重绑原牌，不增加卡牌或部署计数，复活单位随后死亡不再次触发死亡遗物。殉道之冠对每名受益单位最多叠加3次（+6攻击）。

战斗开始早于首轮抽牌；沙盘加到首轮抽牌数，命运硬币与旗幡在首轮/每轮实际手牌建立后处理。回响水晶仅重放可合法再次结算的效果，不重复区域、召唤/复活、随机出牌、撤回或支付生命，也不再次触发出牌遗物。

炼金行囊使用施放快照，增幅伤害与秒数；以整数回合表示的期限向上取整。火焰药水原有“持续至本轮结束”规则保留。血库的溢出转盾与牧师/祈祷已有转盾只计算一次。

触发会点亮遗物图标、显示HUD提示及受益单位头顶来源；高频提示有节流，真实效果不受影响。单位状态栏展示遗物属性汇总，悬停遗物展示本场/本轮触发数和上限。图标暂复用项目现有素材。

## 存档与验证

持有遗物与旧抽牌余数沿用征途存档；每场计数不进入长期存档，新建战场重置。图鉴保存于 `user://relic_collection.cfg`。

```powershell
python tools/maintenance/run_checks.py --checks relics items shop events treasure battle-rewards tactical-cards card-cost undying-army counter expanded-cards
python tools/maintenance/run_checks.py --graphical --checks relics
```

统一入口也支持 `--relics-regression`。图形检查输出 `.maintenance/relics-choice.png` 和 `.maintenance/relics-collection.png`。数值与组合强度仍可在正式游玩中继续调优。
