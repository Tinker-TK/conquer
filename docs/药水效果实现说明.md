# 40瓶药水效果

本次实现方案中的全部40瓶能力：13普通、17稀有、10传说。旧4瓶继续使用原来的执行逻辑和伤害数值，新36瓶使用可组合的`PotionEffect`资源。

## 直接试玩

打开`res://examples/scenes/potion_effects_demo.tscn`，按F6。

- 左侧列表包含全部40瓶，支持滚动；悬停查看数值。
- 点击“开始交锋”后可用伤害、控制和圣盾。治疗、增益、抽牌、资源、召唤等也可在准备阶段使用。
- 落点或单位药水进入瞄准，左键施放，右键或Esc取消；其余点击立即结算。
- “制造阵亡”用于试复活，“玩家受伤”用于试治疗。单位默认固定位置，可取消勾选让它们作战。
- “重置实验”清空实验与限量计数；实验场不修改正式开局配置。

## 实际规则

| 分类 | 行为 |
| --- | --- |
| 场地槽 | 火焰、龙卷风、雷云、泥沼、重力井、陨石及多段闪电占槽；同时可继续使用即时药水 |
| 合法性 | 消耗前检查目标、阶段、地面、单位场景、禁抽、可强化牌、阵亡记录和生命支付；失败给出原因，不扣瓶 |
| 期限 | 秒级状态仅在交锋中推进；药水增益保留配置的3回合，绕过卡牌在交锋中缩为1回合的规则 |
| 中毒 | 叠加层数，本轮末直接伤害；净化清毒；药水催眠会被毒和火等伤害唤醒 |
| 混乱 | 药水混乱4秒内使用普通攻击攻击同阵营单位，近战与弓箭均适用；到期恢复原阵营索敌。原技能混乱保留原规则 |
| 聚怪与击退 | 重力井拉向中心；爆裂从落点向外击退；遵守地表、楼层与岩壁碰撞 |
| 召唤 | 士兵与骷髅无原征召牌，本轮结束清理；诱饵60生命、固定木桩表现、260范围同层嘲讽，最多保留2回合 |
| 复活 | 从本轮阵亡友军中选择，优先原征召单位，以50%生命生成临时单位；继承强化，不返还原牌，不撤销阵亡加费 |
| 复制 | 随机选择有原征召牌的友军，继承当前生命与强化，每项强化只计一次；临时召唤物不进入复制池 |
| 亡语 | 当前友军获得半径120、40伤害的死亡爆炸，仅伤敌人；复活时保留强化 |
| 战术 | 本轮接下来成功打出的2张手牌费用为0；非法施放不扣次数，回合结束失效 |
| 陨石 | 延迟2秒，160伤害，之后3秒内每0.5秒10伤害；有落点预警与燃烧范围表现 |
| 烟雾弹 | 跳过本轮，不结算双方生命伤害，不给本轮奖励；仍推进增益和区域期限，Boss波及Boss节点拒绝使用 |
| 限量 | 仙女之泪每局最多1瓶，致命伤前自动消耗并回复至30%最大生命；生命果实每局最多2瓶，分别增加10最大及当前生命 |
| 存档 | 使用计数随征途保存；旧存档缺少新字段时用默认值；原`Kind`编号不重排 |

40瓶均已加入正式商店、战斗奖励及随机药水事件候选池。按幕过滤为23/37/40瓶，按幕稀有度权重抽取。商店每店仍为3瓶且互不重复；当前只在第三幕商店投放传说，第二幕后期的细分投放留待地点进度规则接入。普通/Boss掉落概率继续读取原有奖励模板和地图覆盖数值。

本次范围为药水能力及可用入口。方案中的3格药水带、满格替换、丢弃、4件配套遗物、4个新事件、2张配套卡、篝火调配及开局随机药水未在本次启用。

## 配置入口

- `data/potions/*.tres`：说明、图标、稀有度、幕数、价格、目标及效果列表。
- `data/potions/potion_effect.gd`：可组合的效果资源。
- `scripts/items/potion_runtime.gd`：新能力执行与期限管理。
- `scripts/items/potion_catalog.gd`：目录、幕池及稀有度抽取。
- `scripts/items/battle_items.gd`：施放入口、瞄准与场地槽。

新增图标位于`assets/ui/potions/`，64×64透明SVG，稀有度边框由HUD绘制。共用落地扩散表现，保留旧4瓶视觉。已核对Eslabong技能与素材目录：链式闪电复用`Chain Lightning`配方的`LightningBoltVFX_Premium`和`ElectricImpactVFX`；重力井复用`Gravity Well`的`GravityWellEffect`；陨石使用`Megameteor`的`MegaMeteorImpactVFX`。寒霜、毒、治疗及状态表现使用库内对应素材，视觉不承担伤害逻辑。
