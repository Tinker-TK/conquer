# 狼人五连斩击扑击

| 参数 | 基础 | 强化一次 |
| --- | --- | --- |
| 扑击施法距离 | 350像素 | 450像素 |
| 索敌 | 施法距离内最大生命值最低的存活敌人 | 同左 |
| 扑击时长 | 0.3秒 | 0.3秒 |
| 五连伤害 | 原第7、8、9、10、11帧，各80%攻击力 | 同左 |
| 冷却 | 7秒 | 7秒；狼人击杀本次锁定目标立即刷新 |
| 眩晕 | 无 | 每刀成功命中施加或刷新2秒眩晕 |

基础狼人现在也可使用五连斩击；强化版本替换基础版本，普通攻击与月影潜行保留。索敌比较单位的最大生命值，不比较当前生命或剩余生命比例；最大生命相同则选择更近者。350/450距离内有目标时优先选择范围内最脆的敌人；没有范围内目标时，按同样规则追击，进入距离后才发动。过滤隐身、死亡、基地、友军、不经有效楼梯相连的异层目标和其它战场单位，嘲讽仍优先约束当前索敌。

扑击在施法开始时锁定一次目标，沿真实路径移动到其身边，完成位移后播放原五连斩击动画。落点默认距目标55像素，目标身边阻挡时尝试其它方向；全程使用完整身体地形扫描和地表检查，不能像旧传送那样穿墙。实际斩击距离仍为80像素，350/450像素仅是扑击距离，不能隔远对目标造成近战伤害。目标移动、隐身、换阵营或死亡不会让旧连击错误命中其他单位。

位于楼梯坡口附近时可扑向楼梯另一端的敌人，按本层导航、显式楼梯连接、目标层导航组成折线，完成位移时同步切换楼层、碰撞和避让，再在目标层执行五连斩击。跨层路线须在技能距离内，禁用或单向楼梯仍按其配置限制；中途关闭楼梯会取消扑击。详见 [楼梯位移攻击](楼梯位移攻击.md)。

强化刷新的“后排”按用户确认，指本次锁定目标。由该狼人击杀时立即停止自己的五连斩击计时器、结束旧连击并解除动作锁，下次索敌就可发动新五连斩击。不会刷新其它狼人或普通攻击的冷却。友军击杀锁定目标、杀死未锁定目标、未强化时击杀，或被打断后杀死旧目标，均不提供此刷新。

眩晕、睡眠、混乱、死亡及战斗阶段结束可取消扑击和后续斩击，恢复碰撞和导航控制；已启动的7秒冷却不会因打断消失。运行状态和击杀监听保存在每次施法独有的节点中，不写入共享技能资源或卡牌。

## 特效核对

`assets/effect/eslabong_vfx/skills/skill_catalog.json` 中同名技能为 `angel_dash`（Angel · 冲刺），原配方为0.3秒非腾空冲刺，残影颜色 `[1.0, 0.9, 0.52, 0.48]`，无附加命中素材。实战直接复用这份配方，残影截取真实狼人当前帧、缩放、朝向和实际轨迹。位移由战斗系统负责，不执行实验室演示角色的位置回调。

狼人技能资源已移除传送门引用。旧的通用 `teleport_combo_attack.gd` 与传送门素材仍可供其它功能显式使用。

## 配置与验证

基础资源 `data/skills/were_wolf_five_attack.tres`（等级0），强化资源 `data/skills/were_wolf_five_attack_upgraded.tres`（等级1）。技能配置工具可编辑 `cast_range`、`pounce_seconds`、`landing_distance`、`melee_range`、`stun_seconds`、`refresh_on_target_kill`，参数说明与实战一致。

`python tools/maintenance/run_checks.py --checks wolf-pounce were-wolf-skills card-description` 覆盖真实部署、基础与强化替换、最大生命索敌和距离边界、原Angel残影、完整五刀、强化眩晕、斩杀立刻刷新及错误归属排除、中断清理、保留冷却、无门户、导航与墙体、隐身、复制和收回、存档恢复。图形模式 `--wolf-pounce-regression --capture` 输出 `.maintenance/wolf-pounce/angel-0.png`、`angel-1.png`。
