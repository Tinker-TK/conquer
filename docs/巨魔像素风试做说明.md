# 巨魔像素风试做

在 Godot 中打开 `examples/scenes/troll_pixel_style_preview.tscn`，按 **F6**。

也可在原怪物预览场景的右上角点击“巨魔画风”进入，再点击“返回怪物预览”回去。

## 对照内容

三列的巨魔使用同一个动画时钟，所以画布、显示缩放、动作和当前帧相同。每列左侧放置现有 Orc，按正式场景原有的 4 倍精灵缩放显示；下方为 2 倍细节对照，裁去巨魔下半身，便于观察脸部与像素颗粒。

| 列 | 处理 | 观察重点 |
| --- | --- | --- |
| 原版 | 原始纹理与颜色 | 原来较细的轮廓和细节 |
| 2 像素 | 每 2×2 原像素取同一个采样值，保持原显示大小 | 颗粒加强，面部与木棒细节保留较多 |
| 4 像素 | 每 4×4 原像素取同一个采样值，保持原显示大小 | 颗粒接近旧 Orc 的 4 倍像素，细节损失更多 |

默认开启“匹配旧角色色板”，只作用于 2 / 4 像素列。关闭可单独比较像素颗粒。巨魔全部动画共有 14 种主要不透明颜色，试做按皮肤、轮廓、木棒、皮革分别对应到 13 种旧角色颜色：主要来自旧 Orc，暖棕高光使用旧 Soldier 的 `b78c61`。颜色成对映射，避免简单最近色选择把绿色阴影变成棕灰色。

实际动态对比后采用 **2 像素＋旧角色配色**，保留眼睛、牙齿、耳环和木棒的更多细节。该方案现已应用到全部 23 种新怪物及其 5 种投射物；此场景继续保留原版 / 2 / 4 像素对照。像素化不改变头身比例和造型设计。

## 操作

- **待机 / 移动**：循环播放对应动作。
- **攻击一次**：从头播放巨魔已有的完整 43 帧连击，结束后回待机；再次点击重新开始。
- **暂停 / 继续**：冻结或恢复动画，空格也可切换。
- **逐帧 → / 底部滑条**：暂停并检查具体帧。
- **转身**：检查左右朝向下的采样与轮廓。
- **半速播放**：以一半速度检查连续动画。

## 文件与范围

- `examples/scripts/troll_pixel_style_preview.gd`：对照界面和同步动画；直接读取正式巨魔的 `data/visuals/enemy_pack/troll.tres` 色板。
- `shaders/unit_pixel_style.gdshader`：帧内固定网格采样与成对色板映射。
- 原 PNG 和攻击配置保持原样；`scenes/units/troll.tscn` 已接入 2 像素材质和色板控制器，具体实现见 [全部怪物配置](EnemyPack怪物配置说明.md)。

着色器以图集当前帧的原点为采样起点，采样点限制在当前帧内，避免切换 Idle / Walk / Windup / Attack / Recovery 时串到相邻帧。主图与放大图共享各自材质，暂停、逐帧和转身时也保持相同处理。

## 验证

使用 Godot 4.6.2 / OpenGL 实际渲染检查了原版、2 / 4 像素、配色开关、待机、移动、完整连击、暂停、逐帧和转身，捕获流程完成且没有脚本或着色器错误。日志与截图位于 `.maintenance/troll_style/`。

静态对照：`.maintenance/troll_style/idle-palette.png`；关闭配色对照：`idle-original-colors.png`；连击过程：`attack-048.png`、`attack-093.png`、`attack-141.png`、`attack-215.png`。
