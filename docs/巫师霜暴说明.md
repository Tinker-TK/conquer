# 巫师霜暴

冰晶爆裂替换为霜暴，基础与强化巫师都可使用，冷却8秒，射程650。

霜暴在技能动作前咏唱1.5秒，火球咏唱0.5秒；头顶显示进度，被异常状态打断则取消本次效果并进入完整冷却。见 [咏唱与护盾说明](牧师护盾与咏唱说明.md)。

| 版本 | 单次冰晶数量 | 每颗伤害 | 强化减速 |
| --- | --- | --- | --- |
| 基础 | 3+x | 固定10点单体伤害 | 无 |
| 强化一次 | 5+x | 固定10点单体伤害 | 命中目标周围150像素内的敌军移动速度降低100，持续2秒 |

x在本次攻击动画的发射帧读取所属战场消耗牌堆的卡牌数量，不消耗这些牌。后续牌堆变化只影响下次施法；独立怪物测试场没有牌堆时按x=0处理。

每颗冰晶实际落到目标时结算伤害，固定10点不受攻击力、防御、高地或伤害倍率改变；周围单位只受到减速，不受到溅射伤害。减速区域跟随被命中的目标，后续命中刷新2秒；进入区域生效，离开、目标死亡或交锋结束后恢复。同类减速取最强值，最低移动速度为1，不改写单位基础速度。

## 特效来源

直接继承 `assets/effect/eslabong_vfx/skills/skill_player.gd` 原播放器，并独立复制 `skill_library.gd` 中 `ice_storm` 的完整配方。沿用实验室中的上方错落弹雨、0.08秒逐颗发射、0.6秒下落、冰霜拖尾、命中碎冰、风暴飘雪和持续冰霜动画。

只把原配方的25颗冰晶替换为实际的3+x或5+x，并跳过已由巫师attack_02动画播放的前摇。每一个原播放器的冰晶抵达事件对应一次10点伤害，原演示与共享配方不被修改。实战额外更新移动目标坐标，使用物理时钟，并在目标退场、策反或交锋结束时清理整套效果。

基础参数在 `data/skills/wizard_ice_crash.tres`，强化参数在 `data/skills/wizard_frost_storm_upgraded.tres`，分别按强化等级 `[0]`、`[1]` 装配。减速数值与暂定半径、时长都可在技能资源中调整。
