# 像素熔岩地形

本效果保留为独立熔岩素材；火焰地形现在使用[焦草与火焰方案](焦草火焰地形说明.md)。熔岩使用程序化 `canvas_item` Shader，包含暗色玄武岩板块、橙黄熔岩流、局部气泡和焦黑的像素岸边。

- 独立效果场景：`res://scenes/effects/pixel_lava.tscn`，可直接放入场景查看、调整参数。
- Shader：`res://shaders/pixel_lava.gdshader`。
- 火焰地形入口 `scripts/effects/burn_ground_zone.gd` 现已切换为焦草效果，不再使用该熔岩素材。
- `radius` 控制范围；`pixel_size` 控制像素颗粒；`plate_size` 控制岩块大小；`channel_width` 控制熔岩通道宽度；`flow_speed` 控制流速。
- 每个实例拥有独立材质与物理时钟，跟随暂停和战斗倍速；`seek()` 支持定格复现。纹理噪声完全由 Shader 计算，不消耗玩法随机数，不创建伤害或碰撞节点。

## 网上参考

本项目实现为自行编写的程序化方案，未引入网页贴图、噪声文件或原代码。

- miwls 的 [LAVA shader animated](https://godotshaders.com/shader/lava-shader-animated/)：参考 2D 熔岩的滚动噪声、流动扰动与热度配色思路；该页代码标为 CC0。
- niwho 的 [2D Pixel Art Water](https://godotshaders.com/shader/2d-pixel-art-water/)：参考像素化采样、流体高光与岸边分层的表现思路；该页代码标为 CC0。
- qkrooz 的 [Stylized lava](https://godotshaders.com/shader/stylized-lava/)：参考细胞状熔岩结构；原例属于 3D，本项目使用独立编写的二维岩板间距与分级调色。
- [Godot 4.6 CanvasItem 文档](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/canvas_item_shader.html)：内建 `TIME` 不随场景树暂停，因此本实现传入由节点物理步推进的 `clock_time`。
