# 书本翻页（独立预览）

参考：[B 站书本菜单拆解视频](https://www.bilibili.com/video/BV1uf8e6dEyA)，原作者 [DetFantasia](https://x.com/DetFantasia/status/2018375133145010365)。按参考的像素书皮、弯曲纸面、正反面纹理、错峰多页和投影重新实现；示例图画与文字在本项目中绘制。

## 打开

Godot 打开 `examples/scenes/book_flip_demo.tscn`，按 **F6**。这是单独的效果场景；正式「设置 → 图鉴」已复用书本组件，见 [冒险图鉴](冒险图鉴说明.md)。

- 点击左右纸面，或按 **← / →** 翻页。示例共有 8 页、4 个跨页。
- 按住纸面向另一侧拖动；超过约 22% 后松手完成翻页，不足则回弹。
- **空格**暂停/继续；拖动底部时间轴暂停到任意进度；“回到当前跨页”撤销未完成的翻页。
- 可调翻页时长、纸面弯曲、1～5 张错峰纸页和阴影。“整本书随翻页运动”控制挤压、平移、缩放及落页回弹，三种幅度可分别调整。开启“自动往返翻页”后会在书本首尾换向。
- **R**恢复默认。切出窗口会取消正在进行的鼠标拖动。

## 资源

| 文件 | 用途 |
| --- | --- |
| `scenes/ui/pixel_book.tscn` | 可复用的透明 Control 书本组件 |
| `scripts/ui/pixel_book.gd` | 分段纸面、双面纹理、动态投影、翻页状态与拖动 |
| `examples/scenes/book_flip_demo.tscn` | F6 独立预览入口 |
| `examples/scripts/book_demo_page.gd` | 示例页面内容，与书本组件分离 |
| `tests/book_flip_render_test.tscn` | GPU 与交互验证 |

纸面采用 24 段网格，逐段判断朝向与绘制深度，因此弯曲区域可同时露出纸的正面和反面。内容随纸面弯曲，不叠放固定文字。多张错峰纸页中，只有首张正面保留当前页内容、末张背面保留目标页内容，其余过渡纸面均为空白，避免图案和文字重复；单张翻页时正反面正常显示内容。每次完成仍只前进/后退一个跨页。纸张落定时与静止画面使用一致的描边和书脊阴影。

整本书的运动沿同一个翻页进度采样：起翻前轻微反向蓄力，中段横向挤压并朝翻页方向移动、缩小，随后放大回弹，最后回到原位与原尺寸。反向翻页镜像横移方向。暂停、拖动时间轴、取消翻页和鼠标拖动均使用这一进度，不启动独立 Tween，因此纸面和书本不会错拍，静止鼠标也不会受到书本自身运动的反向推动。

组件逻辑区域为 **480 × 340**，每页为 **180 × 230**；周围额外保留透明绘制空间，实际视口为 **672 × 564**，容纳放大与平移后的页面。低分辨率视口加最近邻缩放保留像素边缘，能够随 Control 大小等比居中缩放。演示内容视口只绘制一次；翻页不创建游戏单位、不读取或改变本局进度。

## 后续接入

实例化 `pixel_book.tscn` 后，将页面图片或 `SubViewportTexture` 依次放进 `page_textures`：`[左1, 右1, 左2, 右2, ...]`。应提供成对纹理；没有纹理时显示空白纸面。示例页可在确认用途后替换为图鉴、日志、卡组或其他模块内容。

主要接口为 `turn_next()`、`turn_previous()`、`preview_turn(direction)`、`seek_turn(progress)`、`finish_turn(commit)` 和 `reset()`。翻页过程中拒绝重复开始，完成后才更新 `spread_index`。`spread_changed`、`turn_started`、`turn_finished`、`progress_changed` 可供上层界面监听。每个实例的时间、内容和状态独立。

目前页面内容是渲染纹理，书本接收翻页交互；页面上的复杂按钮尚未做变形后的命中映射。确认目标模块后，再根据具体操作接入。
