# 骑兵冲锋与实验室特效

| 参数 | 基础 | 强化一次 |
| --- | --- | --- |
| 连续冲锋 | 1次 | 2次 |
| 每段速度 | 300像素/秒 | 600像素/秒 |
| 每段最大距离 | 600像素 | 600像素 |
| 初次施法范围 | 300像素 | 450像素 |
| 技能冷却 | 6秒 | 5秒 |
| 每段伤害 | 沿途敌人受到100%攻击力伤害，每敌最多一次 | 同左；第二段可以再次命中同一敌人 |

强化冲锋替换基础冲锋，不再同时装配两种版本；普通攻击、强化后的强力刺击保留。两段共用一次技能冷却，段间短暂停顿0.12秒；第二段重新选择当前战场最近的有效敌人，有嘲讽时优先朝有效嘲讽者。方向在每段起点锁定，途中不追着目标转弯。没有有效敌人时结束技能。

特效均先匹配实验室同名条目：

- `Blazing · 冲刺 · 尾迹 · 火花`：原 `BlazingDashTrailSparks.tscn`，在实际移动路径上每0.04秒生成一组原生火花。
- `Flying · Kick`：原 `flyingkick_monk` 冲刺残影及两次蓝色 `SlashImpactVFX` 命中配方。残影截取真实骑兵当前帧，保留骑兵缩放和朝向，并留在生成位置淡出；沿途真实命中后播放原命中配方。位移及伤害由战斗系统负责，不执行实验室演示角色的瞬移或额外伤害回调。

每段按实际路程/速度计时，完整身体在本层墙体前停止；逐段检查地表，不能穿过水面或地表缺口。命中判定覆盖相邻物理帧之间的路径，提速后仍能命中沿途敌人。眩晕、死亡、动作中断及离开交锋会停止当前与后续冲锋、清理特效并恢复碰撞，保留已消耗的冷却。多个骑兵的进度、命中集合、Tween和特效各自独立。

楼梯坡口附近的跨层冲锋沿已有导航和楼梯连接通过，切层时更新碰撞、导航、避让及绘制顺序；通过目标后继续沿本段锁定方向冲锋。折线路程计入600像素上限与速度计时，不会借楼梯无限延长距离。跨层命中和高地增伤沿用原战斗规则，详见 [楼梯位移攻击](楼梯位移攻击.md)。

第0帧冲锋直接在 `begin_cast` 启动，避免从待机第0帧切换时 `frame_changed` 未触发导致冲锋不生效。

「游戏配置 → 技能配置」中，基础资源为 `lancer_dash_attack.tres`（等级0），强化资源为 `lancer_dash_attack_enhance.tres`（等级1）。`dash_count`、`dash_speed`、`dash_distance`、`dash_pause` 分别配置次数、速度、每段距离与段间间隔；其他参数沿用现有配置。

回归：`python tools/maintenance/run_checks.py --checks cavalry-charge tactical-cards undying-army card-description`。图形运行追加 `--cavalry-charge-regression --capture`，实际截图位于 `.maintenance/cavalry-charge/base.png`、`upgraded.png`。
