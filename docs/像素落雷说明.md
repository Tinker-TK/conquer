# 像素落雷：单雷与树状闪电

参考：[像素落雷怎么做？从单雷到树状闪电｜《五星地牢》开发日志 05](https://www.bilibili.com/video/BV15Eaa6AEWh/)。根据视频展示的折点生成、逐段显现、峰值亮片、触地火花、余光和分支重新实现；没有使用视频源代码或素材。

## 打开预览

Godot 打开 `examples/scenes/pixel_lightning_demo.tscn`，按 **F6**。两张大卡片同步展示单雷和树状落雷，下方四张卡片固定展示同一道落雷的劈落、亮闪、余光、消退时刻。右侧可实时修改雷长、折点数量、偏折、分支展开、像素颗粒、颜色以及火花、亮片、二次闪击开关。

- **空格**：暂停 / 继续。原速效果很短，可以将播放速度调到 0.1–0.3 倍观察。
- **R / 新落雷**：生成新的随机形状并播放。
- **Enter / 重播形状**：重播当前折线，形状保持不变。
- **→ / 单帧 +1/60**：暂停并前进 1/60 秒。
- **时间轴**：暂停并定位到指定时刻。
- **显示骷髅参照**：只显示已有贴图的待机动画，可关闭。
- **分层下拉框**：完整效果、折线与折点、主干、分支、亮片、火花。

“恢复默认参数”会恢复形状序列的起始种子、参数、配色及循环播放。下方拆解卡片保持基础的四阶段，不加入可选二次闪击。侧栏在较小窗口中可以滚动。

正式游戏入口、战场、单位、技能和自动加载配置没有修改。预览不创建游戏单位、不发起新一局、不造成伤害。骷髅仅用于尺度与遮挡参照。

## 独立资源

| 文件 | 用途 |
| --- | --- |
| `scenes/effects/pixel_lightning.tscn` | 可复用的 Node2D 落雷场景 |
| `scripts/effects/pixel_lightning.gd` | 折线与分支生成、像素绘制、本地时钟与信号 |
| `examples/scenes/pixel_lightning_demo.tscn` | F6 独立预览入口 |
| `examples/scripts/pixel_lightning_demo.gd` | 两种落雷同步预览、时间轴、拆解与控制面板 |
| `tests/pixel_lightning_render_test.tscn` | 实际 GPU 渲染及预览交互检查 |

效果原点 **(0, 0) 是主干落点**，主干从 `(0, -Bolt Height)` 向下延伸。默认雷长 136、7 段折线、1 个本地像素宽，使用整数栅格绘制，没有外部纹理或着色器依赖。整体大小可修改节点的 `Scale`；整数倍缩放更清晰。

每次击发先生成并保存主干和分支，播放过程中不重新随机折点。树状模式提供落地长分支、悬空分支和更暗的短分支。主干峰值为骨白，长分支浅蓝，短分支暗蓝；分支分别在主干余光时间的 62% / 40% 消退。只有主干和落地分支的末端产生火花，悬空末端不产生地面火花。

默认劈落 0.055 秒、亮闪 0.045 秒、余光 0.24 秒，总时长 0.34 秒；火花在触地后 0.095 秒内向外弹出并分批消失。亮片集中于预选折点，只有峰值阶段显示。二次闪击默认关闭，启用后复用同一道通道。

根节点 Inspector 中可调整形状、节奏、细节、三种颜色及分层查看。`Playing` 控制本地时钟；`Playback Speed = 0` 可冻结；`Loop` 默认关闭，打开后按 `Loop Delay` 循环生成新形状。编辑器中可勾选 `Loop` 持续观察。独立预览使用同步时钟，不需要开启效果自身的循环。

## 后续调用接口

本次只提供接口，没有添加玩法调用：

```gdscript
var lightning = preload("res://scenes/effects/pixel_lightning.tscn").instantiate()
lightning.auto_start = false
lightning.lightning_type = 1  # 0 单雷，1 树状
add_child(lightning)
lightning.global_position = desired_position
lightning.trigger()
```

- `trigger()`：生成新形状，从 0 秒击发。不会擅自改变 `Playing`。
- `restart()`：重播当前形状。
- `reset_sequence()`：恢复当前 `Random Seed` 对应的第一道形状并重播。
- `seek(seconds)` / `get_elapsed()`：精确设置 / 读取时间。定位画面不发送玩法信号。
- `get_duration()`：读取实际总时长，包含可选二次闪击。
- `is_active()`：读取自动播放是否仍在进行。
- `struck`：自动播放的主干首次触地时发出，每次击发一次。
- `finished`：自动播放完全消退时发出，每次击发一次；节点不会自动销毁。

如果需要未来接入伤害或自动清理，可以自行连接信号。手动 `seek()` 的预览不会发出这两个信号。
