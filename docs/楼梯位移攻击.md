# 楼梯上的主动位移攻击

修复狼人、骑兵、熊人和剑士在坡口释放位移技能时无法完成位移攻击的问题。原先位移只扫描起始楼层，狼人和熊人还会在索敌阶段排除所有异层目标；楼梯另一端因此无法成为有效落点。

## 行为

- 狼人：楼梯附近可锁定连接另一端的目标，沿合法路线扑到身边、切层，然后执行原五连斩击。
- 骑兵：沿楼梯连接冲锋，通过目标后继续本段方向；按实际折线路程计算速度和距离上限。
- 熊人：沿楼梯跳到目标层，再结算原落地范围攻击和击退。敌群密度按候选目标所在层统计。
- 剑士：后撤可退下楼梯，前突沿已验证的退路返回原攻击位置和楼层；单向连接不能反向穿越。

坡口附近指距离连接入口不超过96像素，大体型单位按楼梯出口净空扩大。只有已配置、开放且方向允许的连接才可跨层；身体仍逐段扫描墙体与真实地表。没有楼梯的重叠平台不会成为跨层位移捷径。狼人跨层索敌的路线距离仍受350/450像素施法范围限制。原伤害、命中帧、动画、特效配方、冷却以及普通跨层命中和高地增伤规则保留。

途中到达连接点时同步 `floor_id`、导航地图、身体碰撞层、避让分组与绘制顺序；身体经过坡道时保持必要的前景显示。暂停冻结位移，眩晕、死亡、结束交锋或途中关闭楼梯可取消当前动作并恢复身体碰撞。中断保留已消耗的冷却。

## 实现

- `scripts/combat/unit_motion_path.gd`：共享完整身体扫描，提供同层路径和显式楼梯折线、按距离采样位置/楼层、反向及距离裁剪。
- `scripts/units/navigation_agent_2d.gd`：强制位移时复用坡道身体绘制顺序。
- `scripts/skills/wolf_pounce_combo.gd`、`bear_earth_shake.gd`：楼梯附近的跨层索敌与落点判定。
- `scripts/combat/wolf_pounce_motion.gd`、`cavalry_dash_motion.gd`、`bear_jump_motion.gd`、`sword_wind_combo_motion.gd`：沿共享路径连续运动，在实际到达连接点时切层。
