# 无字透明 UI 重绘素材

已对原始 59 个切片建立对应关系，交付 **167 个正式 PNG（含分层文件和 19 张组装预览）**。

打开 `index.html` 可浏览全部素材、下载 PNG，并逐层开关检查五张卡牌。

## 目录

| 目录 | 内容 |

| `cards/` | 五张卡牌，每张八个对齐图层及一张整卡预览 |
| `card_art/` | 五幅完整插画的独立主体与补全背景 |

| `_preview/` | 无文字的素材总览图，用于检查，不计入正式 PNG 清单 |

## 卡牌如何叠放

所有卡牌层都是 **768 × 1024**，左上角统一为 **(0, 0)**。按下面顺序从底向上叠放，不要裁掉各层透明留白。

1. `00_backplate.png`：完整羊皮纸卡底。
2. `10_art_background.png`：补全后的插画背景。
3. `20_art_subject.png`：完整主体及其附带特效。
4. `30_art_border.png`：独立插画边框。
5. `40_outer_frame.png`：完整外框；此前遮挡、旋转和截断已重绘补齐。
6. `50_title_plate.png`：空白标题面板。
7. `60_description_plate.png`：空白描述面板。
8. `70_cost_badge.png`：空白费用徽章，无数字。

`preview.png` 是上述八层合成结果，不应再与八层一起叠放。`card_layouts.json` 记录了图层顺序和后续文字可放置区域。主体和附带的火花/光效目前是一层，不是骨骼动画或逐粒子特效拆件。

## 其他 UI 如何叠放

`ui_layers/` 内每个子目录的图层也具有相同尺寸和原点，按文件名前缀递增叠放即可。`ui_layouts.json` 同时提供共用小图的摆放矩形，既能使用对齐大图，也能自己用小图组装。

- 血条：完整空槽 → 红色填充 → 外边框；运行时只裁切红色填充层，空槽在其下方。
- 能量：蓝色核心 → 金色边框；核心已向边框背后延展，数字需由游戏另外显示。
- 开关：补全后的轨道与滑块分别保存；移动滑块无需移动轨道。
- 卡组/抽牌/弃牌：书本、完整底板、无数字徽章分别保存。
- 皇冠：补全顶部的完整挂旗底板，与皇冠图标分离。

所有交付 PNG 都没有文字或数值；剑、十字、地图标记等图形符号仍作为图标保留。

## Godot 使用建议

正式引用 `manifest.json` 列出的纹理。像素美术使用最近邻过滤，尺寸由 UI 节点控制；不要把高分辨率 PNG 的原始尺寸当作最终屏幕显示尺寸。

在同一父节点下放置卡牌图层，保持同样的位置、缩放和锚点。动态文字、费用、生命值由 Label 或其他运行时控件负责，本批素材中不烘焙数值。

本次未修改游戏脚本、场景或项目配置；原始 `ui_extracted/` 保留。

## 对应关系与校验

- `source_mapping.json`：59 个旧切片到新文件的对应表；重复哥布林、血条、面板使用共用组件。
- `manifest.json`：正式输出尺寸、来源、生成/处理方法。
- `verification.json`：RGBA、透明像素、边缘未截断、品红残留、SHA-256 和组装校验。
- 五张卡牌以及 14 组 UI 均已从磁盘逐层重新合成，并与对应预览逐像素比较一致。
- 全部正式输出通过透明留白检查，品红色键残留检测为零；五张独立插画背景本身有意不透明。

## 生成方法与限制

使用内置 imagegen 补画和高清重绘，再使用经你授权的 Pillow/NumPy 本地脚本去背、去除色键边缘、拆层、调色和对齐。保留像素风，不是把小图简单放大。

补画是根据可见部分推断的美术重建，**不是恢复原图不存在的隐藏图层**。空白面板、框体和轮廓已规范化，细节不保证逐像素复刻。蓝、绿、金色框由同一重绘红框调色，确保尺寸一致；重复组件经过合并。

原始生成提示词保存在 `raw/*/prompts*.json`，卡画工作进程未保存逐字提示词的八项另记在 `raw/card_art/REQUESTS.md`。未调用付费 API/CLI 回退。

## 重新处理

需要 Python、Pillow、NumPy，无网络请求。先执行 `tools/process_assets.py`，再执行 `tools/build_catalog.py`。脚本只更新本目录生成文件，不改原始切片；若手动精修了正式输出，重新运行前请另存精修版本。
