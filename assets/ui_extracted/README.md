# UI 原图切片

来源：`ChatGPT Image 2026年9月5日 11_47_48.png`（1672 × 941）。

这些 PNG 是原图的矩形切片，保持原始分辨率与像素，未重绘、去背、补画或替换文字。所有素材统一位于本目录，不覆盖项目已有素材，也未修改场景或脚本。

## 浏览与定位

- 打开 `index.html` 查看分类缩略图与原图坐标。
- `manifest.json` 记录每个 PNG 的文件名、左上角 x/y、宽高及限制说明。坐标原点为原图左上角，矩形右/下边界不包含在切片中。
- `tools/extract.ps1` 可按清单再次切片，同时逐像素校验结果。只会更新此目录清单列出的 PNG。

## 使用限制

- 合成图没有原始图层：图标附近的天空、草地或面板底色仍在，不能当成已经去背的透明素材。
- 文字和数值均已烘焙在图中。血条、能量、卡牌消耗等动态 UI 在正式游戏中需要再制作无字底板，并由 Label/ProgressBar 等节点显示数值。
- 底部五张卡牌存在旋转、相互遮挡与画面截断。卡牌切片保留所见范围，包含少量邻卡；卡画也是矩形参考切片，不是校正后的完整立绘。
- 单位切片是美术参考，包含草地底色，不是带透明通道的动画精灵表。
- 同时保留完整面板和局部子元素，方便对照；它们不是互不重叠的拼图。

本批交付适合原图对照、布局拆解和后续精修；不是可直接替代全部运行时 UI 的无字透明组件库。
