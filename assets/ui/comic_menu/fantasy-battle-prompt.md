# 原创山谷讨伐战主视觉

成品：`fantasy-battle.png`。工具：内置 `image_gen.imagegen`，未使用 CLI/API 回退。

艺术方向：只取用户参考图的明亮手绘幻想氛围与色彩。新生成时未传入参考图片，重新设计山谷构图、晶角巨兽、持矛骑士、战锤矮人和法师。最终简化只编辑这张自行生成的山谷图，不使用鸟兽/石桥版本。
