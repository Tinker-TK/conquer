# 游戏配置合集

已集成到 Godot：顶部打开 **游戏配置**，入口与“波次编辑器”并列。原生表格与本工具共用数据格式和写回校验，支持新增行列、撤销重做、草稿恢复及 HTML / JSON 导入导出。详见 [Godot 编辑器说明](../../addons/game_config_editor/README.md)。以下为原 HTML 工具的使用方法。

页面：`docs/game_config_catalog.html`。按卡牌、卡牌效果明细、己方单位、敌方单位、技能、遗物和药水分成横向表格。每行对应一项实际资源，每列对应一个字段；支持搜索、直接改单元格、粘贴 Excel 的多行多列数据、修改对比和浏览器草稿。

鼠标停在表头、可编辑参数或只读关联资源上可查看中文说明。说明来自资源脚本的 `##` 文档，重新读取配置后会同步更新；新增字段的说明也会写入脚本并显示在 Godot 检查器中。

## 策划操作

1. 双击 `启动配置工具.cmd`，自动读取当前游戏配置并打开浏览器。
2. 修改现有格子；点击“新增配置行”选同类模板、填写新资源英文标识与显示名，然后编辑新行数值；或点击“新增字段列”填写字段名、类型及默认值。选择“查看修改”检查差异。
3. 点击“一键应用到游戏”。工具校验后备份原始文件，只改动对应属性，再用 Godot 回读验证。验证失败会撤销本工具的写入。
4. 重新运行游戏场景以使用新配置。编辑器里若还有未保存的资源修改，请先保存再启动配置工具，避免旧 Inspector 内容覆盖应用结果。

也可直接打开 HTML 离线编辑，点击“保存 HTML 合集”下载含修改数据的文件。浏览器不会自动覆盖原 HTML；本机草稿不等于保存后的文件。后续将保存的 HTML 路径交给 Codex，即可检查并应用。JSON 导入导出也可用于存档和交换。

现有资源的数值、说明、枚举效果类型、命中帧和动画名可编辑。卡牌内部的每条效果在“卡牌效果明细”表单独占一行；单位技能在“技能配置”表单独占一行。新增配置行会复制同类模板生成独立 `.tres`，卡牌效果新行会追加到所属卡牌的内嵌效果列表；单位新行还会复制同名 `.tscn` 场景并绑定新数据。新卡牌、技能、遗物、药水和单位仍需被卡组、场景或关卡配置引用，才会在游戏中出现。新单位也不会自动进入初始牌组或敌方波次。新增字段支持文本、整数、小数和开关，点击应用时给对应资源脚本创建 `@export var`，并给该类型的每个 `.tres` 写入数值。中文列名及说明保存在 `tools/config_catalog/custom_fields.json`，字段本身在脚本和资源中按 Godot 现有配置方式保存。己方和敌方共用 `UnitData`，新增单位字段会同时出现在双方表中。

新增字段本身只负责存储；如果希望新字段影响伤害、索敌、遗物或药水玩法，仍需修改相应游戏脚本读取它。关联资源路径只读；卡牌效果列表可通过新增效果行扩充，重新绑定技能或图片仍需在 Godot 中完成，再运行“重新读取游戏配置.cmd”。修改文案不会自动修改数值。

## 给后续 Codex 的应用约定

- 修改数据嵌入 HTML 的 `<script id="catalog-data" type="application/json">` 中。不要从页面文本猜配置，也不要执行导入 HTML 的脚本。
- `pending_columns` 保存待创建的新字段定义；对应行的 `fields` 存各行新值。`apply` 会先校验，再同时修改对应 GDScript、`.tres` 和字段中文名元数据。
- `pending_rows` 保存待创建的资源行，包含 `family`、现有资源 `source`、新资源 `id`；对应新记录的 `fields` 保存策划输入。只允许在 `data/` 的同类目录创建新资源，卡牌效果只能追加到模板所在卡牌。
- 格式标识 `ballsprite-config-catalog-v1`，`records[].id` 是资源路径（内嵌资源带 `::`），字段中 `base` 是导出时原值、`value` 是编辑值。
- 只写入 value 与 base 不同的字段。先从引擎重新获取当前字段类型、枚举与范围，发现当前值与 base 不同则拒绝冲突修改。禁止盲目整体覆盖旧快照。
- 不直接改数据里的路径、脚本、base、editable 或字段类型来绕过校验。
- 以下命令均在项目目录运行；Python 默认可用路径为 `%USERPROFILE%/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`。

```text
python tools/config_catalog/catalog.py check "保存的合集.html"
python tools/config_catalog/catalog.py apply "保存的合集.html"
python tools/config_catalog/catalog.py build
```

`check` 只显示待应用差异。`apply` 自动生成 `.maintenance/config_catalog_backups/时间戳/`，含原始 `.tres` 和 `changes.json`，成功后刷新标准 HTML。支持 JSON 输入。备份目录中的相对路径与原项目一致，可按需恢复原文件。

`GODOT_EXE` 环境变量可指定 Godot；默认使用 `D:/Godot4/Godot_v4.6.2-stable_win64_console.exe`。本地服务仅监听 `127.0.0.1` 的动态端口，应用接口检查来源与会话令牌；不需要互联网。

字段校验不能判断策划平衡性，也不会创建新的技能机制。命中帧与动画名需要匹配单位场景，范围攻击的形状仍在场景中配置。药水火焰的持续时间目前由本轮战斗结束控制，不使用 duration 参数；该参数只控制龙卷风。
